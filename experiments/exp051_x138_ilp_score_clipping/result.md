## 解釈

事前に定めた「両胚の公式combined scoreが改善し、division Jaccardが非悪化」という成功条件は満たさない。44b6ではわずかに改善したが、6bbaと全体では悪化した。既知接続の回収が喪失を上回っても、公式指標の改善は保証されない。部分注釈の未知辺は誤接続と断定しない。

旧実行の時間切れ暫定解2件について、推論コードは採用時に全制約・整数性・目的値を検査するが、詳細な監査値は旧Notebookの停止で保存されなかった。再開時は旧graph・診断stage・ログのSHAを検証した。したがって、この2 graphの最適性や制約検査の数値を事後に独立確認したとは主張しない。元の1200秒・最適解必須条件では外側評価は完走できず、提出時の全動画推論が12時間内に終わるかも未検証。

exp050でGPU計算したx138予測cacheを再利用した一方、exp051の両条件で固定後処理のDeepCenter U-NetをCPU実行した。実験内の対照と上限処理は同じCPU条件だが、過去のexp043 GPU推論とgraphが完全一致するかは未検証。exp043には同じ外側20動画の公式scoreがないため、この結果との直接の数値比較はできない。

## スコア低下の原因分析

2026-09-29、保存済み公式評価、4本の調整receipt、各graphの処理段階を再集計した。新しい推論や外側結果を使った再調整はしていない。[集計コード](../../studies/exp051_clipping_failure_20260929/analyze.py)、[動画別表](../../studies/exp051_clipping_failure_20260929/videos.csv)、[段階別表](../../studies/exp051_clipping_failure_20260929/stages.csv)、[trial表](../../studies/exp051_clipping_failure_20260929/trials.csv)を保存し、構造化した数値と生成物SHAはmetricsの`evidence.score_degradation_analysis`へ記録した。

### 直接の減点は接続精度と予測細胞数の両方

| 全20動画 | 費用調整のみ | 上限＋費用調整 | 差 |
| --- | ---: | ---: | ---: |
| 公式評価で正しく対応した接続（TP） | 10,331 | 10,325 | -6 |
| 公式評価で余分と判定された接続（FP） | 880 | 921 | +41 |
| 公式評価で見逃した接続（FN） | 705 | 711 | +6 |
| 予測細胞点数 | 474,262 | 487,219 | +12,957 |
| 細胞数補正前のedge Jaccard | 0.866986 | 0.863511 | -0.003475 |
| 細胞数補正の集約値への寄与 | -0.009476 | -0.012122 | -0.002646 |
| 分裂の加点 | 0 | 0 | 0 |

公式指標は接続Jaccardを各動画の推定総細胞数に対する予測数で補正する。今回のscore差-0.006121は、補正前の接続指標の差-0.003475と、細胞数補正の寄与の差-0.002646に分解できる。この分解は公式式の再集計であり、接続と細胞数を独立に変えた因果実験ではない。動画の重みも両条件の接続件数で変わる。増えた細胞点すべてを偽陽性と判定したものでもない。

低下は主に6bbaで起きた。正しい接続が15本減り、余分な接続が37本増え、予測細胞点が6,701点増えた。44b6では正しい接続が9本増えたが、予測数の増加による補正が改善を削り、combined scoreの改善は+0.000746に留まった。`6bba_fe670320`は接続TP/FP/FNが両条件で同一なのに、予測細胞点が158増え、細胞数補正によりscoreが0.001412低下した具体例である。

### ILPで変えた接続が固定後処理に残りにくい

| 全20動画の固定ID診断 | 費用調整のみ | 上限＋費用調整 | 差 |
| --- | ---: | ---: | ---: |
| ILP直後の既知接続 | 9,908 | 10,013 | +105 |
| relink後の既知接続 | 9,875 | 9,908 | +33 |
| 最終graphの既知接続 | 9,856 | 9,877 | +21 |
| ILP直後の既知分裂 | 0 | 3 | +3 |
| relink後・最終graphの既知分裂 | 0 | 0 | 0 |

ILP直後には既知接続と分裂の改善があるが、edge filterと接続の張り直し（motion relink）までに多くを失っている。実装の`motion_relink_edges`は移動予測と元得点を使った1対1割当を作り、`filter_output_graph`でILP由来の接続を置換する。ILPの分裂をそのまま維持する方式ではなく、分裂は後段の別処理で追加される。実際、上限処理側のILPには15,010個の分岐点があるがrelink後は0、後段の分裂修復後は342となる。これは分岐構造の件数であり、正しい分裂の件数ではない。

一方、選ぶ細胞点数への影響は残る。上限処理側はILP直後に15,285点多く、最終graphでも12,957点多い。最終差のうち11,520点は元の検出候補を多く残した差、1,437点は後処理で追加した点の差である。接続の利点が縮む一方で予測数の補正が悪化するという、処理間の噛み合わなさが観測される。

以前の「既知接続を133本回収し112本喪失、差し引き21本増」は、元の候補座標で正解との対応を一度固定した診断である。公式評価は追加・削除・座標平滑化を終えたgraphを改めて対応付けるため、公式TPの差-6本とは定義が異なる。固定ID診断の増加を公式精度の改善と読み替えない。

### 内部5動画での改善が別胚に一般化しなかった

6bbaの外側評価に使う設定は、44b6の内部5動画で選んだ。対照の内部scoreは0.952794、上限処理は0.980171で、差は+0.027376。しかし差のうち+0.025は、正しく当てた分裂が0件から1件になったことによる加点である。内部の分裂注釈自体が2件しかなく、1件の成否が比較を大きく動かした。分裂加点を除いても選択trialの接続指標は内部では僅かに良く、分裂だけを理由に選ばれたと断定はしない。

外側6bbaの分裂注釈6件は、両条件とも最終graphで正しく回収できなかった。内部で見えた分裂の利点が外側へ移らず、接続と予測数の悪化が残った。少数の分裂事例と別胚への適用に対する選択の不安定さが有力な説明である。ただし、同じデータで別の選択方法を試して改善を主張しているわけではない。

選択した分裂費用も、6bba向けでは対照の1.908611から上限処理の-0.938247へ大きく変わった。外側6bbaのILP分岐点は1個から10,075個へ増えている。この実験は費用も条件別に調整しており、上限値だけを変えた比較ではないため、この変化をclipping単独の効果とは分離できない。有効trialは各条件4～5件で、広い費用と上限の探索を十分に尽くした証拠もない。

### 狙った「別の親候補を同点にする」効果は6bbaでほとんど起きなかった

採用capは44b6向け0.440614、6bba向け0.490973だった。外側6bbaでは候補接続176,819本の得点に上限がかかった一方、複数の親が上限以上となり同点になる娘は10動画合計で6個だけだった。44b6では802個だった。

したがって6bbaでは、狙った親同士の得点差解消はごく限られた場所でしか働いていない。上限処理はそれでも接続報酬と出現・消失・分裂費用との釣り合いを変えるため、選ぶ細胞点や分岐構造は大きく変わり得る。同点化は正しい親を優先する新しい情報を加える操作でもない。この仕組みと、上の費用変更・後処理の観測を合わせると、誤親選択の改善より他の変化が大きかったと考えるのが妥当である。

### 時間切れだけでは説明できない

時間切れ暫定解を使った2動画を両条件から除いた18動画でも、対照0.900419、上限処理0.897283、差-0.003136だった。6bbaの残る8動画だけでも差-0.004475であり、最適終了したgraphだけでも低下が残る。これは保存済み結果の事後診断で、公式20動画の結果を置き換えるものではない。時間切れ2件の最適解を求めた場合にどう変わるかは未確認。

CPU/GPU差も直接原因とする証拠はない。両条件のDeepCenter後処理は同じCPU条件であり、今回の差はその条件下の比較である。GPU化でこの精度差が解消するとは言えない。

### この結果から言える範囲

今回の「別胚の内部5動画で選んだcapと費用を、既存の接続張り直し・分裂修復へ通す構成」は両胚改善を達成しなかった。ILP段階の改善は一部観測されているため、得点上限処理という操作全体が無効とまでは結論しない。原因をさらに分離するなら、費用を固定したcap有無の比較と、ILPで回収した既知接続・分裂を後処理がどの辺で失うかの比較が必要になる。これは追加検証案であり、実行や設計変更はしていない。
