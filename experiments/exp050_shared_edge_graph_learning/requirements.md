## 手法契約

以下の処理をexp050内で実装し、元の候補の契約全文を後段へ保存する。

- input: exp043の固定候補点特徴・補正後物理座標・検出得点と融合後接続確率から作るexp047拡張候補graph。時間窓・前処理・特徴抽出位置を保存して照合する。
- target: GEFFの7 µm以内の時刻別一対一対応で得た既知接続・既知2娘。既知1娘は非分裂の証拠にしない。
- output: 母ごとの空、1娘、順序不変の2娘の集合得点。共有edge確率は1娘と2娘で同じ値を使い、2娘のみに予測分裂費用を引く。
- loss: 許容集合の周辺化負対数、既知2娘と自身の部分集合のmargin比較、既知親と競合親のmargin比較を別平均して等重みにする。
- decode: 母ごとに1集合を選ぶILP。娘の親は最大1、母の娘は最大2。元のnode選択・出現・消失制約を保ち、分裂固定費用1.2を二重に足さない。元IDと確率を固定後処理へ渡す。
- context unit: 隣接2時点の候補graphでGNNを実行し、動画全体のILPと後処理で最終graphを評価する。
- 実装区分: 特定論文の再現ではない独立案。候補に記載されたGNN、共有得点、部分教師、集合ILPを省略しない。管理上の変更classは `representation`。
- 学習・推論のコード: Jupytext percent形式のtrain/inference Notebookを正とする。共通の公開モデル推論と後処理はexp043/exp047のsourceとSHAを照合して移す。候補生成・教師・GNN・損失・ILPの単位テストを同実験のtestsへ置く。
- 学習設定・分割・Optunaの範囲・試行数・runtime上限は [config.yaml](config.yaml) を正とし、次の移行元全文の具体的な契約を保持する。
- 前段で両胚の既知接続回収、確認できる誤接続、2娘回収と母数を記録する。今回の明示済み方針では中間精度を全graph実行の合否にせず、実行不能・契約違反・資源超過だけで停止する。公式scoreはKaggleの全graph評価でのみ主張する。

## 2026-09-26に確定した設計

- ユーザー判断: 母ごとの空・1娘・2娘の学習得点を集合変数としてILPで選び、exp049で詳細を調べていない各胚のハッシュ順位21～30位、計20動画で評価する。今回の承認は設計確定であり、実験化・Kaggle実行・competition submissionの承認ではない。この節を実装契約の正とし、下の過去の未決記載は当時の経緯として読む。
- 動画分割: exp043と同じ `SHA256(42:動画名)` の昇順を胚ごとに固定する。両胚21～30位の各10動画は、この実験の学習・Optuna・checkpoint選択から除外し、外側評価だけに使う。一方の胚で学習して他方を評価する2方向を行う。学習側胚31～35位の5動画を内部選択用とし、同胚の21～30位と31～35位を除く動画をGNN学習に使う。11～20位は過去の診断対象なので学習に使えても未使用評価とは呼ばない。外側20動画の名前と選択SHAを予測・教師照合前に固定する。公開画像モデルの学習来歴があるため独立CVとは呼ばない。
- 入力と候補: exp043の検出器、画像encoder、座標head、primary/secondary trackerの重み、時間窓、座標補正と方向融合を固定する。同じ窓・補正座標で接続計算に渡す候補点特徴、物理座標、検出得点、融合後の接続確率、候補IDを保存する。特徴が旧cacheになければ同じ窓で再抽出し、版・窓・ID・座標・SHAを照合する。拡張側3条件はexp047と同じ、元の `p > 0.48` の全辺と `p > 0.10` かつ娘ごと上位3親の辺の和集合を使う。母側には追加の上位件数・距離制限を置かず、同じ母から出る全ての異なる2娘組を列挙する。候補が計算限界を超えたら記録して停止し、正解を見て候補を減らさない。
- GNNと得点: 隣接2時点の候補点と上記の辺で二部graphを作る。128次元のnode表現を両方向の隣接node平均から2回更新し、各回に線形変換、残差接続、LayerNorm、ReLU、dropout 0.1を使う。共有edge headは更新後の母・娘特徴、物理変位・距離、元の融合確率から接続確率を1個出す。元の確率のlogitに学習残差を加え、残差の最終層は0で初期化する。2娘headは母特徴、娘特徴の和と絶対差、2本のedge特徴の和と絶対差から、順序に依存しない分裂費用を0～2の範囲で出し、初期値を1.2にする。空集合の接続得点は0、1娘は共有edge確率、2娘は同じ2本の共有edge確率の和から予測分裂費用を引いた得点とする。単娘専用edge headを作らない。
- 教師と損失: exp043と同じ7 µm以内の時刻別一対一対応でGEFFの既知接続を候補IDへ写す。既知1娘から非分裂を断定せず、未知の娘を負例にしない。exp029と同じく、既知正例を全て含み、注釈済みの別母と矛盾しない母別集合の確率を周辺化した負対数を情報のある母で平均する。既知娘が候補外の母は集合損失から除外して件数を残す。候補に2娘がそろう既知分裂では、正解2娘の得点が自身の各1娘・空集合を0.05上回るsoftplus損失を別平均する。既知親が候補にいる娘では、その親の共有edge得点が競合する別親を0.05上回るsoftplus損失を別平均する。3項を等重みで足し、該当例のない項は0と件数を記録する。確定できない辺に負例損失を足さない。
- 学習設定: 1方式、胚入替2モデル。各方向でGNNと出力headだけをseed `42 + fold` で初期化し、AdamW、学習率0.0001、weight decay 0.01、勾配norm上限1、window batch 1、5 epochを固定する。最終epochを使い、内部・外側scoreでcheckpointやepochを選び直さない。loss各項、候補内の既知2娘件数、正解2娘と部分集合の得点差、既知親の順位を保存する。
- 集合ILP: 各母に空・1娘・2娘集合の二値変数を作り、選択された母は集合を1個、各娘は親を最大1個にする。node選択、出現、消失と時刻・端点の既存制約を維持する。選択集合の得点を目的値から引き、出現費用0、消失費用2を加える。固定分裂費用1.2は重ねず、2娘得点内の予測分裂費用だけを使う。空集合と消失変数の対応を検査し、費用を二重計上しない。元の候補ID・接続確率と選択辺をexp043の固定後処理へ渡し、同一IDで候補・ILP後・再接続後・最終graphを追う。動画ごと1200秒以内の最適終了を要求する。
- Optuna対照: 接続係数-1、候補、元の接続確率、制約、後処理を固定する。出現費用0～1、消失費用0～3、分裂費用-1～2を連続一様分布で探索し、既定の `(0, 2, 1.2)` を最初のtrialにする。seed `42 + fold`、TPEのstartup 4 trial、最大12 trial、方向ごと経過時間4時間を上限とする。学習側胚31～35位の5動画について、全graphと固定後処理の後に公式combined scoreを件数集約して最大化する。同点ならdivision Jaccard、なお同点なら費用3個の辞書順で選ぶ。solver非最適・出力不正・公式評価失敗は失敗trialとして記録して選択しない。有効trialが4件未満なら費用調整不成立で停止する。時間上限までに4件以上あれば完了したtrialだけから最良を凍結する。外側で追加試行・探索範囲変更・費用選び直しをしない。
- 比較と予算: 4条件は同じ外側20動画で全動画graphと公式評価器まで進める。現行exp043は元候補・得点・費用、拡張候補と旧費用は元得点・元費用、Optuna条件は元得点・選択費用、学習条件は共有集合得点・集合ILPを使う。後ろ3条件の候補ID・画像側・後処理を揃える。最後の差はGNN、共有得点、集合ILPを合わせた学習方式全体の効果と解釈する。画像特徴取得と2モデル学習は残GPU枠と週45時間以内、OptunaはCPUで各方向4時間以内、各Kaggle Notebookは12時間以内に収める。短い動作確認後は単体精度で止めず全graphへ進む。入力不一致、非有限loss、不正graph、solver非最適、メモリ80%以上、動画ILP1200秒超、Notebook12時間超過見込み、GPU枠不足では停止し未測定部分を示す。

## 入力・予測対象・出力・推論方法

- input: exp043の補正後座標・固定画像特徴と、隣接2時点の母・娘候補graph。
- target / objective: 公式注釈と整合する接続・分裂。娘1つだけの注釈を完全な非分裂教師にせず、未知の第2娘を接続なしに固定しない。
- output: 母ごとの空・1娘・2娘の得点。通常継続と分裂で同じedge確率を使い、2娘には順序に依存しない予測分裂費用を加える。空の接続得点は0とする。
- loss: 許容集合を周辺化した部分教師損失、既知2娘と自身の部分集合の比較損失、既知親と競合親の比較損失を別平均して等重みで足す。局所集合比較までを実装し、競合する全graphの構造化損失は今回含めない。数式に相当する処理とmarginは上の確定設計を正とする。
- decode / 推論方法: Graph Neural Network（GNN、候補間で情報を集約するニューラルネットワーク）で母・娘候補の特徴を更新し、娘の親は最大1、母の娘は最大2という制約の下で整数線形計画法（ILP）の集合変数により選ぶ。出現費用0・消失費用2と予測分裂費用の契約、後段再接続への引き渡しは上の確定設計に従う。
- 処理単位: 隣接2時点の母と娘候補、および同じ娘を取り合う候補集合。
- 実装区分: 特定論文の忠実再現ではない独立案。GNNの情報交換、得点共有、既知分裂の比較学習を中核とする。

## トラッカーの学習で変える具体的な処理

- exp029の共有backboneから別々の1娘・2娘headへ分ける方式に対し、親Aと娘候補Bの接続得点を一度計算し、1娘集合と2娘集合の両方で同じ得点を使う。特徴の共有だけではない。
- 1娘の得点はA→Bの共有edge確率、2娘の得点はA→BとA→Cの同じ共有edge確率の和から順序不変の予測分裂費用を引く。空集合の接続得点は0とし、消失費用と整合させる。構成と初期化は上の確定設計に従う。
- 既知の2娘B・Cでは、正しい2娘をBだけ・Cだけ・空集合と直接比較し、分裂例の損失を別平均して希少な信号が通常接続に埋もれるかを調べる。既知Bだけの母ではBを含む集合を許容し、未知のCがいないという教師を作らない。
- 初回は共有得点・分裂比較を含む学習案1設定とOptuna費用調整対照を比較し、損失だけの追加学習対照や多数の要素分解を前提にしない。推論では母ごとに1集合、娘の親は最大1という制約で整合する選択を行う。
- これはtrackerの採点構造・損失と、その出力の選択を変える案である。後処理の閾値変更だけではない。exp043で候補が欠けているなら、この採点学習を先行させない。座標補正の成功や本案の仮説から、exp041の失敗原因を断定しない。
- [exp043要件](../exp043_x138_self_trained_head/requirements.md)・[config](../exp043_x138_self_trained_head/config.yaml)・[metrics](../exp043_x138_self_trained_head/metrics.json)を新入力の正本とする。旧診断の128件・外側130件・内部3件/9件はexp029の母数で、新入力では再集計する。

## 成功条件と停止条件

- primary指標: 全動画の公式combined scoreと両胚別の接続・分裂成分。取得可能な既知接続回収、判定可能な誤接続、両娘回収と母数も同じ実行で記録する。
- 成功条件: 同じ外側評価対象のexp043に対し、両胚で公式combined scoreが改善し、division Jaccardが非悪化。費用調整単独の効果は拡張候補・旧費用とOptuna費用調整を比較して判断する。学習の追加価値を主張するには、同じ拡張候補のOptuna費用調整対照に対しても両胚のcombined score改善・division非悪化を確認する。exp043に対する改善だけ成立した場合は構成全体の改善とし、学習の追加価値は未確認と記録する。Public LBとの整合は未確認であり、調整用scoreを外側評価やLB改善と同一視しない。
- 必須guard: 2026-09-24のユーザー指示により、単体指標は記録に使い、全graphへ進むための合否判定には使わない。この理由を実験化時のrequirementsと実行時のSESSION_NOTESへ引き継ぐ。疎い注釈の未知接続を真の誤接続として数えない。
- 成功時の次段階: 全graph公式評価まで同じ実験で完了させてから結果を提示する。採否・完了はユーザー判断。competition submissionは別途の明示承認が必要。
- 失敗時の停止範囲: 実行不能、数値破綻、不正な出力、予算・時間上限超過では止める。中間の精度が低いことだけでは全graph評価を省略しない。実行できなかった場合は公式score未測定と記録する。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 未注釈の負例化、既知1娘から非分裂を断定すること、既存ILP graphの擬似正解化、topK解除や費用倍率だけへの縮小、GNNの情報交換省略、外側での損失調整、画像側更新。
- 壁打ちで採らなかった案と理由: topK解除やDeep-EIoU型の探索拡大だけでは現在の分裂抑制を解消できないため先行しない。手で固定費用1構成を選ぶ旧案は、今回の依頼により学習側内部のOptuna探索へ変更した。外側評価では選択済み費用を凍結し、本候補のGNN学習部分の代用にしない。合成事前学習・後続2軌跡・複数tracker融合は別比較。小例適合と多段階の要素分解は時間優先方針により実行前提から外す。
