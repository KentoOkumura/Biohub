## 仮説

共有接続得点と既知2娘の比較学習により、固定したx138候補から両胚の分裂と通常接続を改善できるか検証する。

2foldのGNN学習とOptuna費用選択はKaggleで終了した。4条件×外側20動画の全graph公式評価は、Optuna費用条件のSCIP時間切れで停止し、scoreは得られていない。実行の数値とSHAは[metrics.json](metrics.json)、時系列は[SESSION_NOTES.md](SESSION_NOTES.md)を正とする。

## 解釈

Optuna version 4のPublic LBはGNN version 3より`0.004`高く、exp043より`0.008`低い。これは提出条件の比較であり、未完了の外側20動画評価を補完しない。version 3の時間超過がどの動画・工程で起きたかは特定できず、version 4の採点結果だけから並列化による時間短縮幅を測ることもできない。

Optunaは各胚5動画で固定後処理まで実行した公式scoreを最大化しており、調整用データでは旧費用trial0から改善した。44b6は`0.952736 → 0.955123`、6bbaは`0.965599 → 0.970886`。有効trialはそれぞれ4件と6件で、これらは設定選択に使った同じ動画のscoreであり、未知の胚への改善を示す数値ではない。

提出版の費用は選択済みfold0 trial2とfold1 trial4の等重み平均で、元の最良trialそのものではない。分裂費用だけでも両trialは約`-0.532`と`1.913`と大きく異なる。ILPで選ぶgraphは費用に応じて離散的に切り替わるため、費用の平均からscoreの平均や改善は保証されない。平均費用の正解付き評価と外側20動画の評価が未完了であり、平均による劣化や調整動画への過適合は可能性として残るが、今回のLB低下の原因とは断定できない。

exp043に対しては費用と候補辺の両方が変わっているため、`0.950 → 0.942`を費用調整単独の悪化とは解釈しない。同じ拡張候補を使うold cost v2はPublic LB `0.943`で、今回のOptuna平均費用版はこれを`0.001`下回った。提出構成として改善は得られなかったが、元のfold別最良費用やOptuna一般の有効性を否定する結果ではない。old costはexp043より`0.007`低く、今回の候補拡張も提出全体の改善には結び付かなかった。候補別のhidden実行時間・動画別solver状態は得られておらず、外側20動画の4条件比較も未完了という限界は残る。
