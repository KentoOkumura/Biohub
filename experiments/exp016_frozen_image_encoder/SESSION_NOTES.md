### 予定

共通確認を先に行います。

```bash
make validate-exp EXP=exp016_frozen_image_encoder
make check-exp EXP=exp016_frozen_image_encoder
make test-exp EXP=exp016_frozen_image_encoder
```

次のうち、実験契約に必要なnotebookだけを予定へ残します。学習を伴わないauditやdiagnosticではtrain、提出を目的としない実験ではinferenceを機械的に実行しません。

trainが必要な場合:

```bash
make prepare-kaggle-notebooks EXP=exp016_frozen_image_encoder EXTRA_ARGS="--notebook train --run-on-push"
make push-kaggle-train EXP=exp016_frozen_image_encoder
make kaggle-logs KERNEL=<generated-kernel-id>
```

prepare後に生成された`kernel-metadata.json`からkernel idを取得して`KERNEL`へ指定する。id末尾とtitle由来slugが一致し、50文字以内であることを確認する。自動生成では上限や衝突を解消できない場合だけ、`kaggle-platform`の規則に従って意味のある短縮id/titleを明示する。placeholderのまま実行しない。

## 変更点

- 画像forward、検出loss、secondary tracker、decodeを学習Notebookから除外し、optimizerをprimary tracker parameterだけに限定した。
- exp015 cacheのsummary SHA、identity SHA、199 sample、19,701 windowと、公開train source・model source・checkpointのSHAをruntimeで検査する。
- sample prefixによる2方向の胚holdout、seed 0の胚内90%/10% checkpoint選択、seed 42 + fold offsetの学習を実装した。
- 公開sourceどおり、候補ごとの最近傍GTを距離昇順に5 µm以内で一対一対応し、source軸softmaxと正例行OR正例列maskのfocal-weighted BCEを使う。
- 公開sourceのtracker学習にないmixed precisionは追加せず、学習をfull precisionに固定した。
- 64 window/foldのbenchmarkから全工程を1.5倍で予測し、12時間を超える場合はfull train前に停止する。
