# exp029_mother_daughter_set_selection 結果

## 仮説

固定候補を保ち、母ごとの空・1娘・2娘の集合を直接選ぶと、娘ごとの母選択より誤接続を減らし、既知接続と分裂を維持できるか。

## 実行証拠

private Kaggle train Notebook `kentookumura/exp029-mother-daughter-set-selection-train` のkernel version 4（第5試行）が完了した。private DatasetからSHA照合済みの第2試行の候補監査・fold 0結果・重みを復元し、fold 1だけを学習・評価した。実行時間は5,708.21秒。候補監査、両foldのsummaryとモデル、early gate、model manifest、ログを取得し、SHAと相互整合を確認した。詳細なSHAと数値は[metrics.json](metrics.json)、保存済み生成物は[artifacts/train_v4](artifacts/train_v4)、実行経緯は[SESSION_NOTES.md](SESSION_NOTES.md)を参照。

同じ候補cache・教師・隣接2-frame評価対象で、保存済みexp016 primary trackerと比較した。外側胚6bbaは12,392 window、44b6は6,315 window。各foldのモデルとedge costは内部検証で選択した。

## 解釈

この結果は固定候補、部分観測の集合損失、母ごとの上位16集合を使う整数最適化という今回の構成に限る。追加診断により、正解の2娘集合が得点段階で1娘または空集合に負けていることを確認した。この得点を学習した原因は未分離であり、母ごとの集合選択全般の否定とはしない。GEFFの部分注釈のため、観測可能な誤接続率は全接続の真の誤接続率ではない。公開画像encoderの学習来歴から、胚別評価は独立CVではない。2-frameの結果を公式scoreの代用にはしない。

## 分裂が選ばれない段階の追加診断

公式注釈で分裂を含む151組を抽出し、保存済み2foldの重みをCPUで再評価した。固定cache・モデル・実行コード・注釈のSHAを確認し、Kaggleで得た既知分裂件数、候補回収件数、最終回収0件を再現した。数値とSHAの正本は[metrics.json](metrics.json)のdivision_diagnostic、個別記録は[division_rows.csv](artifacts/division_diagnostic_v1/division_rows.csv)、詳細集計は[summary.json](artifacts/division_diagnostic_v1/summary.json)。

| 段階 | 6bba・fold 0外側 | 44b6・fold 1外側 |
| --- | ---: | ---: |
| 検出候補に対応した既知分裂母 | 108 | 22 |
| 正解2娘集合が候補にある | 107 | 21 |
| 空集合を含む16集合への絞り込み後も正解が残る | 93 | 16 |
| 正解2娘が、同じ母の1娘または空集合より低得点 | 107/107 | 21/21 |
| 母ごとの最高得点が正解2娘になる | 0 | 0 |
| 全候補集合を残した最適化で正解分裂を回収 | 0 | 0 |

正解2娘を、その一方だけ、または空集合へ置き換えても、娘の重複禁止と母の出次数制約は壊れない。しかも全128件で置換後の得点が高いため、今回の目的関数では正解2娘を選ぶ全体最適解は存在しない。絞り込みでは19件を失うが、残った109件もこの得点条件で選べない。絞り込みを外しても回収0件なので、今回の0件は得点段階で説明できる。

正解2娘と、その1娘・空集合のうち最高得点との差の中央値は、6bbaで-8.83、44b6で-8.38だった。2娘集合の中だけなら正解が最高得点の例が42/128件あり、1娘・空集合との得点比較が重要な問題になっている。ただし、fold 0は対象108組の全母候補の中で別の2娘集合を16件出力しており、2娘出力そのものが全く動かないわけではない。

学習に使った分裂も確認した。正解集合を損失に与えられたfold 0の19件、fold 1の98件は全件で1娘・空集合より低得点となり、回収は0/19、0/98。未学習胚への一般化だけでは説明できない。一方、小例の逆伝播では、既知2娘の損失から2娘headへ勾配が届くことを確認した。

学習原因の候補を支える事実は次の通り。

- 1 epochあたりの教師のある母は105,243件・331,234件で、候補内の既知2娘は19件・98件。件数比は約0.018%・0.030%。これは件数比であり、window単位で平均する損失の勾配寄与率ではない。
- モデルとedge costは内部の接続選択accuracyで選ばれ、分裂を維持する条件を含まない。fold 0ではepoch 1の分裂回収1/3がepoch 3で0/3になったが、accuracyが60.26%から86.59%へ上がり、epoch 3が選ばれた。
- これらは保存済み結果とコードから確認した事実。教師の希少性、損失の寄与、モデル選択のどれが学習結果を決めたかを分離する再学習比較は行っていない。

この診断は151組の局所再評価であり、公式graph scoreや新しいCVではない。全母の2娘出力件数も、分裂を含む組だけの集計である。
