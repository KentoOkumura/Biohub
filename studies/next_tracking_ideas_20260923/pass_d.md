# 独立Pass D: 検証と計算

他passの最終案を見る前に作成。以下の名称はこの検討メモの識別子であり、既存手法の名称ではない。

1. D1 情報源と学習干渉を分離する: 保存基準の固定下で小さな追加モデルだけを学び、元trackerの共同更新による変化と切り分ける。通常過去/距離と密度を合わせた別細胞過去/過去なしの比較を学習側で事前に固定する。入力遮断だけの分布外比較で因果効果を断定しない。追加モデル自身の同条件対照が必要な場合は費用を明示する。
2. D2 識別可能性を先に調べる: 同じ動画・同じ時刻・近い距離の正解親と確定誤親を比べ、固定画像特徴、3点の運動、周囲の共通移動のどれが誤親から分離するかを小型probeで測る。正解過去を与えるoracleは可能性の上限に限定し、未知過去での選択結果と分ける。
3. D3 候補削減の上限を先に調べる: edgeごとの保持率に加え、母と両娘を同時に保持できる割合、完全な正解局所graphを保てる割合を測る。exp038の過去8候補保持率は高いが、これは選択精度や両娘の保持を証明しない。
4. D4 処理別費用計測で既存多時点学習を実行可能にする: 全窓の密度分布、データ読込、教師生成、学習、推論、比較対照推論を分離して見積もる。最大窓はpeak確認だけに使う。exp040に同様の計測と抽出設計が既にあり、新規案として重複作成せず既存契約を確認する。高速化の成功条件は秒数だけでなく、その結果実行した対応学習の両胚診断と公式graphを含む。
5. D5 学習得点が最終graphまで残るか検証する: 保存予測から候補graph・ILP後・運動再接続後・修復後のedge移動を追跡する。後段で消える学習改善を独立に測る。固定中心のまま学習得点を保持する局所再選択を検証する場合は復号変更の別契約とする。

## 共通の反証条件

- 外側胚で閾値・窓長・loss重みを選ばない。同一窓反復を独立な標本数と数えず、動画単位で不確実性を計算する。
- 誤例のラベルが確定せず未注釈を負例にする必要がある案、実装で必要な画像/特徴が推論時に得られない案は停止。
- 正解を候補に含めるoracleだけの改善、空間距離だけで説明できる分離、元モデルからの全体的な確率移動だけを識別改善としない。
- GPU時間を2枚のT4の壁時計へ無条件に読み替えない。週45時間の上限と残量、Notebook12時間は別々に判定する。
