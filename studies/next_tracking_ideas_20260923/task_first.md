# 課題から先に考えた6案

2026-09-23。対象実験の詳細な結果を横断する前に、公式仕様・現在方針・実験索引と直前の議論から作成。source-hidden調査ではない。ここでの案は推薦順位ではない。

## 課題

- 出力は3D中心点と親子接続・分裂のgraph。公式は接続Jaccardと分裂Jaccard、過剰nodeを考慮する。
- 推論で既知なのは同じ動画の前後画像、固定検出点・画像特徴・座標。GT identity・正解過去・真の分裂は未知。
- trainは2胚199動画、疎なGEFF。未知を一律の負例にできない。画像モデルの公開train学習来歴を含む条件付き評価。
- 同じ細胞の候補、競合する親、複数の娘、隣接細胞、同じ動画の時系列に依存がある。現在の点数/確率から最終graphへ進むと対応の不確実性を失う。
- 保存すべきものは物理単位、同一細胞のidentity、時間順序、分裂の1対2、未知ラベルの区別。特徴は元の2frame画像窓に依存し、画像・座標を変える際にキャッシュをそのまま流用できるとは限らない。
- hiddenは別胚・可変候補数・密度・欠落・境界を想定し、GTや固定dataset数を要求しない。公開検出器・画像encoder固定、Kaggle週45GPU時間・無課金・推論12時間。

## 6案

1. TF1: 固定候補の短い時間窓 -> GEFFの既知の祖先・子孫対応を直接教師にする -> 隣接以外も含む対応表 -> 分裂と親の整合を保つgraph。過去特徴の集約を目的にせず、過去対応そのものを学習対象にする。
2. TF2: 固定候補と画像特徴 -> 母ごとの娘集合を1娘/2娘として競合させる -> 集合の得点 -> 母娘の制約下で局所graphを選択。接続ごとの独立予測から組へ変更する。
3. TF3: 生画像の同一動画内の局所位置合わせ -> 観測された組織の移動と信頼度 -> 動画固有の移動場 -> その移動で説明できない接続を診断する。参照場の構築は現在の点予測・候補を使わない。画像モデルの学習は不要。
4. TF4: GEFFの学習側軌跡または独立に生成した座標・系譜 -> 真の接続を保ちながら欠落/重複/競合軌跡を付加 -> 対応の不確実性を出す下流学習 -> 実データの固定候補へ適応。事前学習は現在の点予測・候補集合を使わず成立するが、実誤差に合わせた設計が必要。
5. TF5: 固定候補と複数の異なる接続根拠 -> 不確かな場所だけ複数の対応を保持 -> 短い軌跡/分裂の候補集合 -> 将来観測も使って一貫した組を選択。対応を先に1本に固定しない。
6. TF6: 固定画像特徴と学習側の既知identity -> 正解対応と識別可能な競合を比較する損失 -> 時点を越えて照合する特徴 -> 接続候補の順位/得点へ接続。未知候補や分裂を誤って負例にしない。

## 構造的な確認

- 同一entity文脈: 動画内の観測は使えるがhiddenの正解はない。動画固有の位置合わせ/局所referenceとcoverage外fallbackを検討する。
- 不完全な中間予測: 既存trackerの履歴を入力するなら、学習側のOOFにある誤接続の連続長、偏り、欠落を再現し、実OOF入力へ適応する必要がある。
- 不変性: 物理座標の剛体変換とidentityの対応は検証可能。画像/窓依存特徴の移動や回転不変性を仮定しない。分裂を含む時間反転は同じ生物学的過程として扱わない。
