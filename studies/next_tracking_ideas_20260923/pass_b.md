# 情報の使い方・不変性・合成データの独立案

親エージェントから渡された task card と、`kaggle-idea-forge/SKILL.md`、`docs/02_metric.md`、`docs/04_data.md` だけを参照した独立発想。既存 backlog、実験詳細、他の発想 pass、外部資料は参照していない。以下は実験提案であり、実測結果ではない。

## 共通の前提

- 3D 動画から細胞中心と有向追跡 graph を出力する。公開検出器と画像 encoder は固定し、点候補・画像特徴32次元・位置特徴32次元と座標の cache を再利用する。
- 学習199動画は2胚に属する。正解 GEFF は疎であり、既知の正解に接続がないことだけで負例にしない。実データでは既存の検証済み教師 mask を継承し、以下の loss はその mask 内で計算する。
- Hidden test にあるのは新しい胚の画像だけである。同一動画の画像・検出候補・固定特徴は参照できるが、真の対応、真の細胞数、過去の正解 track は参照できない。
- 全座標計算は物理座標 µm に統一する。voxel scale は z=1.625、y=x=0.40625 µm/voxel。出力時だけ逆変換する。時間単位は取得済み間隔が確定しなければ frame とし、速度を µm/秒と呼ばない。
- 過去3 frame全点への追加 cross-attention の失敗が否定したのは、その集約・損失・融合方法だけである。履歴を観測誤差の推定や事前分布に使う効果は未検証。3時点の全候補積が費用で停止したことは、座標による運動の情報価値を否定しない。
- 下記の early test は隣接2-frame の既知 edge 回収、観測可能な誤接続、分裂、各胚別の悪化を確認する。単体指標で公式 score 改善とは言わず、進行条件が成立した案だけ全 graph と公式評価器へ進める。

## 案1：同じ動画の共通移動を推定し、候補接続の残差と観測分散に使う

**変える情報の役割**：履歴と周囲の細胞を直接の分類特徴から、同じ動画に固有の移動の基準と観測誤差の推定へ移す。

- **入力**：各時点の固定画像特徴と物理座標。隣接 frame の近傍内で、画像類似度と相互最近傍、候補間の余裕から暫定対応を作る。真の cell identity は用いない。
- **推定する対象**：時点ごとの全体移動と、支持があれば局所的に滑らかな移動、および対応残差の共分散。最初は頑健な translation のみで十分。局所 affine は translation の残差構造が残る場合だけ比較する。
- **学習 target / loss**：候補接続の正しさ。既存 pair loss と教師 mask を固定し、移動を引いた候補変位、その不確実性、支持点数・支持範囲だけを追加する。観測モデル自体は training GT を使わず各動画から推定する。
- **出力 / decode**：補正された pair score と uncertainty。既存の候補・graph decode をそのまま利用し、候補数を増やさず効果を切り分ける。
- **coverage と fallback**：推定に使う点の空間範囲、局所支持点数、残差、対応の相互性を記録する。支持範囲外、分裂密集部、欠損 frame、観測残差が大きい領域では、学習済みの全体移動分布または元の pair score へ戻す。局所支持のない場所へ確信を持って外挿しない。
- **循環を防ぐ方法**：評価中の候補 pair とそのごく近傍を、その pair が参照する移動推定の支持から除外する。暫定対応自身を正しい教師として使わない。
- **不変性**：全点に同じ座標原点変更を加えても残差と接続 ID は同じ。座標表現を変えると位置特徴、変位、共分散、支持領域、境界までの距離を一貫して再計算する。voxel anisotropy を消さない。分裂を1対1拘束へ吸収しない。
- **効く理由**：大きな見かけの移動が組織全体の共通移動である場合、細胞ごとの残差は小さくなり、密集した候補の識別が容易になる。全履歴を attention に入力するより観測誤差の意味が明確。
- **最強の反論**：密集部では暫定対応が集団で間違い、誤った移動場が自己強化される。局所的な細胞運動と分裂を平滑化して消す可能性もある。
- **cheap falsification**：訓練前に既知正解 edge の変位を補正したとき、両胚で正解と競合候補の距離順位が改善するか、誤接続しやすい bucket で悪化しないかを測る。query 除外時に効果が消える、支持が高い領域でも正解順位が悪化する、利用可能範囲が狭すぎるなら停止。推定時間は点数にほぼ比例する近傍処理に制限し、全候補積を作らない。

## 案2：同じ動画で画像特徴の時点間変化を校正し、外観類似度の観測モデルを作る

**変える情報の役割**：固定 encoder 特徴をそのまま predictor に渡すだけでなく、動画内の見え方の変化を測る reference に使う。

- **入力**：固定特徴、frame、位置、検出の品質情報。画像を追加処理する場合も固定 encoder の変更や再学習はしない。
- **推定する対象**：同じ動画の近接 frame 間で広く共有される特徴のずれと分散。各 frame の頑健な中心・対角分散と、案1とは独立に作った高信頼暫定対応の特徴差を使い、全体 reference へ縮小した小さな補正を推定する。32次元の自由な線形写像から始めない。
- **target / loss**：実 annotation の pair 対応を、元の類似度と校正後の類似度の両方から予測する。pair loss は同じ教師 mask を使う。暫定対応を利用する補助目的は特徴差の頑健な回帰とし、恒等写像からの乖離を制限する。
- **出力 / decode**：校正前後の類似度、動画内で期待される類似度範囲、校正の信頼度から pair score を作り、既存 decode へ渡す。
- **coverage と fallback**：支持のある時間帯・深度・特徴領域だけ補正する。稀な形態、分裂直前後、極端な輝度、少数支持では未補正特徴へ戻す。Hidden動画だけから支持を求められる。
- **不変性**：cell identity と分裂 graph を変更しない。特徴の平均変化を生物学的変化と区別できないため、大きな正規化を不変性として仮定しない。座標変形時は位置特徴と支持 bucket を再計算する。画像の幾何変換を行った場合は固定 encoder を再実行し、元特徴を流用しない。
- **効く理由**：別胚の撮影条件や bleaching に伴う特徴ずれが類似度を劣化させているなら、encoder を再学習せず補正できる。細胞ごとの長期履歴を保持する必要がない。
- **最強の反論**：固定特徴が既に撮影変化に頑健なら利得がなく、細胞周期や形態変化という有用な signal を消す。暫定対応の誤りも補正を汚染する。
- **cheap falsification**：GT を使わず推定した補正が、未使用の既知 edge の類似度順位と校正誤差を改善するかを胚・時間・深度別に確認する。相互最近傍による support と検証対象を分離する。正解 edge と難しい競合の差が縮む、分裂周辺が悪化する、恒等写像が同等なら停止。

## 案3：実際の予測誤差を再現した履歴で事前学習し、誤った履歴を信用しすぎない tracker を学ぶ

**変える情報の役割**：既存 tracker の履歴を正しい state の代用品にせず、誤りを含む観測として扱う。単なる入力 noise の追加にはしない。

- **入力**：候補 pair の現在2 frameの固定特徴・物理座標と、既存 tracker が作った3〜数 frameの履歴、その欠損・競合 score・選択経路。完全な真の履歴を推論入力としない。
- **段階1：学習側だけで誤差測定**：out-of-fold（OOF、学習に使わなかった対象への予測）を作り、既知 track に対応可能な範囲で座標誤差の大きさ、符号付き bias、時間自己相関、近傍細胞との誤差相関、連続欠損長、identity swap の継続長、誤分裂・見逃し分裂の頻度を測る。密度・画像品質・候補 margin ごとに条件付ける。部分 annotation で測れない量は unknown とし、未注釈の予測を誤接続扱いしない。
- **段階2：corrupted conditioning の生成**：真の注釈 track の条件入力へ、観測した誤り系列を block ごとに再標本化して付与する。独立 Gaussian だけで置き換えない。近傍の別 track へ数 frame 接続する、欠損を持続させる、移動方向に偏った座標誤差を続ける、分裂時だけ履歴を誤って共有するなど、測定できた誤り構造を再現する。target 側の cell identity・分裂 graph は保持する。
- **段階3：事前学習**：正しい current pair を選び、必要なら履歴への依存を下げる model を、corrupted history から学習する。現在の pair loss に、元の pair predictor へ戻るべき場面を見分ける補助 loss を加える。学習時の clean history の割合を高くしない。
- **段階4：実 OOF 入力で微調整**：synthetic conditioning で学んだ model を、実際の inner OOF history で短く微調整する。外側の held embryo は誤差分布推定・事前学習・微調整・選択のいずれにも使わない。
- **出力 / decode**：pair score と履歴信頼度を出し、現在2 frameの predictor と混合して既存 decode に渡す。生成済みの点が欠けている場合、その cell をこの model が復元できたとは主張しない。候補回収率は別限界として記録する。
- **2胚しかない制約**：外側 train は1胚なので、その内部で field of view（FOV、撮影領域）を分けた OOF を使う。この誤差は新胚での誤差を完全には再現しない。外側 held 胚を学習した tracker から作った予測を、反対 fold の refiner 学習に流用すると情報が回り込むため禁止する。
- **不変性**：target 側の位置・cell identity・分裂・時間順序を保持し、conditioner のみ意図的に壊す。座標誤差は µm 単位で生成し、履歴座標から位置特徴、速度・加速度、候補近傍と信頼指標を再計算する。誤った座標だけ変更して clean 位置特徴を残さない。
- **効く理由**：履歴が平均的に弱くても、正しい履歴の情報を利用しながら、連続誤接続に引きずられる失敗を抑えられる。現行の全点 attention 失敗とは学習分布と信頼度の扱いが異なる。
- **最強の反論**：部分注釈で測れる誤差が偏っており、学習胚内の誤差も新胚より易しい。synthetic corruption を見抜くだけになり、real history では current prediction のコピーか誤増幅になる。
- **cheap falsification**：最初に誤差測定可能な track・分裂件数を確認する。次に clean history / real OOF history / empirical corruption / 履歴なしを同じ小型 model で比較する。real OOF で履歴なしを超えない、corruption と real error の継続長・方向・欠損に大きな差が残る、現行予測のコピーが主体なら停止。全 graph 実行の前に両胚で既知誤接続を増やさず改善があることを求める。

## 案4：位置を細胞からの相対量へ変え、座標原点に依存しない学習をする

**変える情報の役割**：絶対位置を識別用特徴にする代わりに、接続元からの物理変位、近傍配置、観測境界までの距離を表す座標へ変える。

- **入力**：固定画像特徴と、source を原点とした target・近傍点の物理座標。光学軸に対する向き、FOV 境界までの距離、必要な深度情報は別に保持する。
- **target / loss**：既存の pair 対応。通常の pair loss に加え、同じ例の座標原点を変更した2表現で score が一致するよう consistency loss を入れる。位置 embedding は新しい座標から再計算する。
- **出力 / decode**：pair score。予測中心座標や graph ID の意味は変えず既存 decode を使う。
- **保存するもの**：物理距離、時間、cell identity、分裂、近傍関係。これは生物学的な移動を合成する操作ではなく、同じ観測の座標表現を変える操作。境界と source を同時に移し、境界までの実距離は保持する。
- **許可しない近道**：z と xy の voxel 座標をそのまま回転しない。cell size と速度が変わる一様 scaling、時間逆転、分裂を融合へ変える変形は不変性として使わない。原画像を回転・変形する拡張を追加するなら、対応する fixed encoder 特徴を再計算しなければならない。
- **効く理由**：同じ胚・同じ撮影領域内で有効だった絶対位置依存を減らし、新胚や異なる細胞配置に移る際の余分な変動を抑える。既存の位置32次元が何を表すかの監査もできる。
- **最強の反論**：深度や位置そのものが画像品質・発生段階・運動に関係しており、捨てると悪化する。また現行位置特徴が既に相対座標なら新規性がない。
- **cheap falsification**：モデルの再学習前に既存入力の位置特徴の定義を確認する。原点変更で境界などの物理量を正しく保存しただけで現行 score が大きく変わるかを測る。既に不変なら案を閉じる。差があれば絶対位置のみ / 相対位置のみ / 相対位置+実深度・境界を同じ小規模学習で比較し、両胚で改善しないなら停止。

## 案5：固定特徴 cache の上で、cell identity と分裂を保持した対応問題を大量に作る

**変える情報の役割**：実 annotation を最終教師として使うだけでなく、実際の変位・特徴変化・分裂局所配置を合成例の材料に使う。画像生成や encoder 学習をしない。

- **入力**：訓練 fold 内の点群・固定特徴、注釈された短い track、実際に観測された分裂の母細胞と娘細胞の特徴・物理座標。欠けた annotation は補完した真値として扱わない。
- **生成するもの**：同じ実点群の一部を1対1で次 frame へ写した小さな対応問題。移動は訓練側で観測した局所的な変位場と残差を別々に再標本化し、外観差も対応既知の実細胞から条件付きに採る。密集した配置は実点群から採り、全点を独立 jitter して現実の近傍相関を壊さない。
- **分裂の扱い**：分裂を含む例は実 annotation の母1点・娘2点の局所的な配置と特徴を組で使い、daughter identity と1対2 graph を保持する。母特徴の単純コピーを娘特徴としない。支持が少なければ合成分裂は作らず、実分裂だけで微調整する。cell count は division により変化するので保存量と呼ばない。
- **target / loss**：合成過程で確定した対応と非対応は完全教師として使える。set 内の matching loss と分裂 loss を学習し、その後は実 annotation と既存 mask に戻して微調整する。detector の誤検出が真の細胞になったとは扱わず、合成の identity はその点の仮の identity である。
- **出力 / decode**：候補 pair と daughter pair の score。まず既存候補を固定して実 OOF 改善を確認し、合成によって候補回収率まで改善したとは主張しない。
- **不変性と再計算**：保存するのは合成例内の identity と lineage、物理単位、時間順序。位置、相対変位、近傍構造、密度、位置 embedding、FOV 境界を新しい点群から再計算する。特徴変化の採り直しは意図的な観測変化であり、固定特徴の幾何変換不変性を仮定しない。
- **効く理由**：教師密度約2.8%の制約下で、密集した候補から対応を選ぶ基本処理を大量に練習できる。encoder 計算なしで、GPU費用の多くを tracker の学習に使える。
- **最強の反論**：生成過程が実動画より容易で、特徴変化と移動の実相関が壊れる。分裂 triplet の接ぎ木は不自然な密度・娘形態を作り、人工的な手掛かりへ過適合する。
- **cheap falsification**：実際の validation pair と合成 pair を区別する小さな分類器が、位置・特徴差だけでほぼ完全に識別できるなら生成を修正または停止する。合成の正解率を成功条件にせず、同じ学習予算で real-only と synthetic-pretrain→real-finetune を比較する。両胚の実 OOFで改善がなく、特に分裂が悪化する場合は全 graph に進めない。

## 案6：母細胞と娘2細胞の画像量の変化を、分裂を支持する観測として検証する

**変える情報の役割**：画像の明るさ・広がりを個々の cell の特徴だけでなく、母1細胞と娘2細胞を合わせた観測の比較へ移す。蛍光量の保存を事実とは仮定しない。

- **入力**：母候補と娘候補の小領域から取る背景補正後の積分輝度、局所的な広がり、固定 encoder 特徴。新しい画像モデルは学習しない。同じ動画の分裂以外の高信頼対応を使って frame 間の共通 gain と残差分布を観測する。
- **最初に測る対象**：既知の非分裂で1点→1点、既知の分裂で1点→2点とした場合に、合計輝度や広がりの比が、単に近くに2点ある場合より区別に使えるか。gain 校正後でも分散が大きければここで終了する。
- **target / loss**：候補母と娘の組が分裂か。既知の分裂近傍と、観測上判定可能な非分裂の例に限り、division loss を使う。未注釈の二股を自動的に誤分裂とはしない。
- **出力 / decode**：母と娘2点を同時に見る split score を既存 pair score の補助に使い、1本ずつの独立 edge 判定より分裂の整合性を確認する。娘候補の組は近傍内に制限し、3時点全候補積を作らない。
- **不変性**：真の cell identity、1対2 lineage、座標単位を保持する。共通の撮影 gain に対して比を校正するが、飽和、背景ずれ、異なる深度、cell cycle を保存則へ押し込めない。幾何変形時は aperture と局所画像記述子を再計算する。
- **coverage と fallback**：支持がある輝度・深度範囲でだけ追加 score を使う。飽和、境界切れ、近傍重なり、gain 推定不成立では現行 division score へ戻す。
- **効く理由**：分裂の2本の edge は独立ではない。過去3 frameの任意集約より、母と娘の関係を直接観測できる可能性がある。
- **最強の反論**：蛍光は発現・bleaching・重なりに依存し、母から娘への保存量ではない。aperture 内の隣接細胞混入を division の証拠と誤認する可能性が大きい。
- **cheap falsification**：少数の既知分裂と密度を揃えた比較例で、gain 校正後の量が胚を越えて分裂の識別に使えるかを先に測る。単純な位置情報に対する追加情報がない、胚ごとに関連の符号が反転する、境界・密度を条件付けると効果が消えるなら tracker 学習へ進めない。追加画像 read の実測時間も必須。

## 独立 pass としての見立て

最初に安価に反証できるのは案1と案4。案1は履歴を同一動画の観測モデルへ移すので、既知の attention 失敗と情報の使い方が異なる。案4は現行の位置特徴の定義次第で直ちに棄却できる。案3は最も大きな学習分布の問題を扱うが、誤差を測れる annotation の範囲と2胚制約を解決できるかが先行条件。案2・5・6は追加の独立候補として残し、同じ動画の校正、教師の増加、分裂観測という別々の仮説を試す。
