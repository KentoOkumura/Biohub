# 表現・教師・損失を変える独立発想

これは親エージェントへ渡す研究メモであり、採用・実験化・バックログ追加はしていない。既存backlogや全実験履歴を読まず、依頼されたtask cardと限定証拠だけから作成した。

## 参照した範囲

- 親から渡されたtask card、計算制約、2件の限定された失敗証拠。
- `.agents/skills/kaggle-idea-forge/SKILL.md` のPass A等の発想手順。
- `docs/02_metric.md`、`docs/04_data.md`。

画像・座標・保存済み特徴の具体的なarray、現行学習損失、注釈の選択機構、既知分裂件数、候補生成のoracle coverageは未確認。以下の改善理由は仮説であり、実測結果ではない。

## 全案に共通する契約

- 公開検出器と画像encoderを固定し、下流trackerだけを学習する。新規人手教師は作らない。
- hidden test入力は画像だけ。教師GEFF、真の履歴、真の総node数、注釈率を推論入力・分岐条件へ渡さない。
- train胚をまたぐ条件付き検証とし、2胚を個別に報告する。固定公開モデルのtrain学習来歴による限界は残る。
- 既知edgeは正例、候補の未対応や未注釈は未知。既知nodeへの候補対応自体が曖昧な場合は、許容候補集合へ周辺化するかその学習対象を除外する。
- 既知の1本の出力edgeだけでは「非分裂」と確定しない。2娘が既知の分裂と、分裂の完全性が不明な例を区別する。
- 最小検証は保存済みの同じ隣接2-frame入力・教師対応で行う。既知edgeの回収、根拠を持って判定できる誤接続、既知分裂の2娘回収、候補不足、曖昧対応を胚別に報告する。未注釈領域のprecisionを断定しない。
- 隣接2-frameで評価不能な効果は、少数の3–5-frame部分列で先に診断する。単体診断が通るまでは全動画のgraph推論を始めない。

## 案1: 母から出る辺を、娘の集合として予測する

**入力 → 教師・損失 → 出力 → 復号**

母候補の固定特徴と次frameの近傍候補集合 → 既知娘を含む許容集合への対数尤度 → 「後継なし」「娘1個」「順序のない娘2個」の確率 → 全母の選択を、各娘の親は高々1個という制約の下で決定。

娘2個のscoreは、母–娘それぞれの類似性に加えて、娘同士の相対位置・特徴差を同時に見る。既知娘が1個しかない場合、その娘を含む単体・2娘集合の確率を足し、未注釈のもう1娘を負例にしない。候補に真の娘がない例では、その母の全候補を負例にせず、候補外への確率または学習maskを使う。

- **機構・改善理由:** 独立edge scoreでは、最もよい2本が生物学的に整合する娘組とは限らない。母と2娘の3個を一つの対象にすると、片方だけ正しい分裂や、別母由来の2細胞をまとめる誤りを直接学べる。
- **最も強い反論:** 既知1娘の例はcardinalityを識別しないため、集合尤度だけでは2娘を過剰に出す解が残る。疎注釈から非分裂の確定例を得られないなら、分裂確率の校正をこの損失だけに任せられない。また近傍数の2乗で娘pairが増える。
- **最低費用の反証:** 保存済み既知分裂だけで、各娘が候補に入る割合と、正しいunordered pairの順位を現行の2辺score和と比較する。非分裂判定の教師がない場合は既存の分裂発生率の扱いを固定し、娘pairの選択だけ変える。正解2娘がそろう例でも両胚で順位が改善しない、または候補数増大で時間が過大なら停止。
- **疎注釈・分裂:** 分裂を直接扱える一方、分裂有無の識別可能性を解決したと偽らない。片娘注釈の例を非分裂negativeにしない。
- **失敗証拠との差:** 過去全候補を特徴へ追加する案ではなく、同一2-frame内の予測単位と教師を変える。

## 案2: 各辺ではなく、2フレーム全体の対応表を予測する

**入力 → 教師・損失 → 出力 → 復号**

隣接2-frameの固定特徴・物理座標と疎な候補辺 → 既知対応の確率を上げつつ、各娘の親の重複を防ぐ構造制約 → フレーム間の疎な対応確率行列と候補外・出現・消失の確率 → 容量制約つき最小費用の対応選択。

母は最大2娘、娘は最大1母とする。行列の正規化を必ず1対1にすると分裂を消してしまうため、母の2本目は別の許容枠として表し、分裂scoreと費用を明示する。対応のない候補を全て消失と教師化しない。

- **機構・改善理由:** ある娘への2母の競合は、辺ごとの学習では推論時まで見えないことがある。学習から競合を入れると、単独で高scoreな誤接続が周辺の正しい対応を壊すことを扱える。
- **最も強い反論:** 現行復号が既に同じ制約を適用しているなら、改善余地は学習と復号の不一致だけになる。softな対応表に整合した損失が、整数復号後の改善を保証しない。検出候補不足や重複を構造制約だけで直せない。
- **最低費用の反証:** 既存scoreを固定し、疎な対応表の正規化と構造化学習だけを切り分ける。競合母がある既知娘のbucketで、制約適用後の親選択が改善するか調べる。競合がほとんどない、または構造上のoracleでも現行から回収できるedgeがほとんどないなら学習前に停止。
- **疎注釈・分裂:** labelのない行列要素を0教師にしない。分裂の2本目の費用は案1と同じ識別可能性の問題を持つので、最初は既存設定を固定して比較する。
- **失敗証拠との差:** 過去frameの情報量を増やさず、現在の候補間の排他性を学習へ移す。

## 案3: 接続候補の二値判定を、移動先の確率分布へ変える

**入力 → 教師・損失 → 出力 → 復号**

母候補の固定特徴と次frameの局所観測 → 既知edgeの物理座標変位への尤度 → 方向・距離・不確実性を持つ多峰の移動先分布 → 各娘候補位置での密度と画像特徴整合性から接続scoreを作る。

教師は候補IDの正解分類だけでなく、既知母子の実座標変位を使う。候補の位置ずれと教師対応の曖昧さは、複数候補の許容範囲として扱う。2娘が既知の場合は、単一平均へつぶさず、2娘それぞれの分布または順序のない2点分布を学ぶ。

- **機構・改善理由:** 候補集合の密度・数が変わっても、物理座標上の移動分布は共通の予測対象になる。曖昧な母に広い分布、安定した母に狭い分布を出せれば、一律の距離priorより混雑時の誤接続を抑えられる。
- **最も強い反論:** 移動がほぼ等方でappearanceが支配するなら追加情報がない。尤度だけでは、広い分布へ逃げても候補順位が改善しない。分裂の中点を予測する単峰分布は逆効果になる。
- **最低費用の反証:** 固定特徴から小さな出力層だけを学び、胚別の変位尤度・真の娘を含む範囲の大きさ・同範囲内の競合候補数を測る。等方な距離分布と比べて、同じ回収率で競合を減らせないなら停止する。尤度だけの改善は通過条件にしない。
- **疎注釈・分裂:** 正例変位から学習でき、未知edgeのnegative化を避けやすい。一方、正例の選択偏りが移動分布へ入るため、注釈近傍以外への一般化は未確認のまま残る。
- **失敗証拠との差:** 過去点を接続pairごとに列挙せず、各母に一度だけ空間分布を出すので、候補pair×過去候補の計算を避ける。

## 案4: 短い既知系譜を使って、同一細胞の特徴距離を学ぶ

**入力 → 教師・損失 → 出力 → 復号**

固定画像特徴と必要最小限の局所位置情報 → 連続する既知edgeでつながる短い非分裂系列をpositiveとする距離・順位損失 → 複数frameで同一細胞が近くなる低次元特徴 → 隣接frameの特徴距離、運動情報、分裂scoreを合わせて復号。

3–5-frameの教師は表現を学ぶために使い、hiddenで正しい過去履歴を入力する必要はない。negativeは、既知の同時点に互いに別細胞として存在するなど、別対象と確定できる範囲に限定する。別GEFF componentだから別細胞と推測しない。

- **機構・改善理由:** 現在pairの正否だけでは、数frame持続する外観成分と一時的な変動を区別しにくい。短い系列の教師で、既存の32次元画像特徴に残る持続成分を抽出できる可能性がある。
- **最も強い反論:** 固定特徴に細胞を識別する情報がなければ、後段で作れない。位置を入れすぎると外観表現ではなく近傍距離の言い換えになる。分裂の前後を全て同一identityにすると娘同士の区別を失う。
- **最低費用の反証:** 既知の非分裂短系列だけを使い、同じ物理距離帯の競合に対する正例順位を2胚で測る。位置を除いた特徴と位置だけの特徴を比較し、外観に由来する改善か切り分ける。非分裂で効果がなければ、長系列への拡張や全graph推論は行わない。
- **疎注釈・分裂:** 系列の不明な区間を補完教師にしない。既知分裂でidentity教師を切り、分裂は別の2娘集合scoreへ引き継ぐ。分裂の回収が落ちないことを独立に見る。
- **失敗証拠との差:** 過去特徴を推論時のcross-attentionへ足す案と違い、過去情報を教師の役割へ移す。現在pair損失だけで過去の使い方を学ばせない。

## 案5: 辺scoreではなく、分岐を含む短い確率遷移を学ぶ

**入力 → 教師・損失 → 出力 → 復号**

3-frameの固定特徴・候補座標 → 既知edge尤度と、2段の遷移と直接2-frame先の遷移が一致する損失 → 母から将来の候補へ確率を分配する遷移行列 → 隣接辺scoreに戻して容量制約つき復号。

分裂では母の確率を2娘へ配分するため、子から親への確率を組み合わせる際に、姉妹が互いに同一細胞へ戻ることを強制しない。たとえば母→子→母の整合性は使えても、子→母→子の恒等変換をそのまま強制すると分裂を壊す。出現・消失・候補外の確率を明示し、全候補に閉じた一対一対応を強制しない。

- **機構・改善理由:** 2-frameでは曖昧な接続でも、3-frame全体で矛盾する組合せがある。疎な正例をanchorとし、未注釈の画像系列を確率遷移の整合性に使える。
- **最も強い反論:** 誤った近傍接続も時間的に一貫し得る。整合性損失の低下は精度向上の証拠にならない。候補欠損や分裂の扱いを誤ると、正解を規則違反として罰する。
- **最低費用の反証:** 同じ3-frame部分列に対し、既知教師だけの場合と整合性を加えた場合を比較する。整合性が下がっても、両胚の既知edge順位・分裂2娘回収が改善しないなら停止。順序を入れ替えたframeでも同程度に改善するなら、時間情報を使った機構という主張を棄却する。
- **疎注釈・分裂:** 未注釈領域へ真偽labelを付けずに使えるが、整合性そのものも仮定である。分裂、出現・消失、候補欠損を別bucketで測る必要がある。
- **失敗証拠との差:** 過去のattention特徴追加ではなく、現行pair教師にない時間方向の制約を損失へ入れる。

## 案6: 公式指標の差で、競合する局所graphを順位付けする

**入力 → 教師・損失 → 出力 → 復号**

固定特徴・現行候補scoreと、親交換・辺追加削除・娘pair交換をした小さなgraph候補 → 公式評価で差が確定する候補間の順位損失 → 各局所graphの相対score → 境界と容量制約を満たす候補を選ぶ。

最初は全graphを学ばず、同じ2-frameにある競合箇所と既知分裂だけを使う。教師は公式指標の変化から作り、metricが区別できない未注釈の差には優劣を付けない。nodeの過剰予測係数や全体の分母の影響があるため、局所指標を公式指標そのものと呼ばず、周囲を固定したgraph差として教師を作る。

- **機構・改善理由:** 全edgeの独立損失を一様に小さくするより、復号時に実際に競合する選択肢のうち、公式指標を壊す方を下げる。2娘の一括置換や親の交換による利益を教師にできる。
- **最も強い反論:** 候補graphに正解に近い構造がなければ学習で回収できない。疎なmetricが与える優劣は部分的で、候補生成器の癖へ過適合し得る。局所改善を貪欲に重ねても全体のJaccard最大化にはならない。
- **最低費用の反証:** 学習前に、既存候補scoreから生成した数個の局所graphを公式教師でoracle選択し、現行との回収差を測る。headroomが両胚でほとんどない場合は停止。次に特徴だけでその優劣をheld胚で選べるか測り、oracleと実際の選択可能性を分けて報告する。
- **疎注釈・分裂:** 未知同士の比較をtieとして除外する。既知2娘の分裂を構造単位で候補に含める。公式の分裂判定は局所系譜を使うため、単純なoutdegree教師だけへ置き換えない。
- **失敗証拠との差:** 情報量を増やさず、教師と損失を最終復号の競合に合わせる。

## 案7: 検出候補を使わず画像から移動場を求め、候補を運ぶ

**入力 → 教師・損失 → 出力 → 復号**

隣接3D画像の縮小画像または固定encoderの空間特徴 → 画像の対応残差と、利用できる場合だけ既知node変位の損失 → 物理座標上の局所移動場と対応不確実性 → 現行の母候補を移動場で次frameへ運び、候補への接続scoreを作る。

移動場の推定は現行検出候補も現行pair予測も使わない。最初の診断は学習なしの画像位置合わせでもよい。固定encoderに空間特徴が取れず、cacheが点特徴しかない場合は再計算費用が必要である。検出器を再学習しない。

- **機構・改善理由:** 画像全体の同じ方向への移動や局所変形があるなら、個々の細胞候補を先に対応付けなくても運動情報を得られる。母子pairごとに過去全点を列挙せず、frameごとに一度だけ計算できる。
- **最も強い反論:** 細胞の外観変化、分裂、輝度変化、密な相似細胞により、画像の対応残差を小さくしても正しい細胞移動にならない。3D画像の読出しと演算がGPU・12時間制約へ重い可能性がある。
- **最低費用の反証:** 少数の保存済み2-frame画像で、画像から求めた変位が、変位なし・局所候補の平均変位より既知子の位置に近づくか確認する。同じ回収率で競合候補を減らせない、片胚だけで効く、またはframe単位の費用をhidden規模へ外挿して許容できないなら停止。
- **疎注釈・分裂:** 画像対応にはGEFF不要。既知edgeは精度診断に使う。単一移動場で2娘分裂を表現できないので、分裂領域は不確実性を広げて案1の2娘候補へ渡す。分裂を移動場へ押し込まない。
- **失敗証拠との差:** 候補を基準に過去を要約するのでなく、画像にある運動を候補生成前の別表現として求める。

## 親への優先検討材料

この独立passだけなら、**案1の娘pair oracle診断**と**案6の局所graph oracle診断**は、新しいモデルを学習する前に改善可能性を確認しやすい。既存固定特徴の持続情報を調べる**案4**は、失敗した過去cross-attentionとは情報の役割が違うため、履歴情報全体を否定しないための対照になる。**案7**は現行候補から独立した探索案だが、画像入力と計算費用の確認が先に必要。

これは親が他passと統合する前の限定意見で、全体の順位ではない。親が既存実装を確認した結果、案1または案2がすでに現行方式なら、その案の新規性は失われる。

除外すべき方向は、未注釈を一律negativeとする損失、既知1娘を非分裂と確定する教師、hiddenで正しい過去graphを必要とする入力、未確認の注釈率から推論時のnode数を決める方式。これらは表現を工夫する前に比較の妥当性を壊す。
