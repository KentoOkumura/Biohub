## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 同じ検出に対する複数の局所構造を保持する価値と、正解情報なしでの選択。
- この候補の具体的な仮説: 候補間の親競合と分裂を満たす少数のgraphを保持し、選択用の画像・時間情報で採点すれば、単一解への早い確定による誤りを減らせる。
- 仮説が正しい場合に期待する観測: 同じ候補予算で正しい局所graphが追加回収され、その利益が実際の選別と全動画の公式評価へ残る。
- 仮説を棄却する観測: edgeは増えても両娘・局所graphは揃わない、候補解がほぼ同じ、正解を見た選択だけが改善する、または同じ費用の単一解に劣る。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 別検出器からの回収、複数trackerの融合、画像側の更新は含まない。
- 既存候補との差: [exp047](../experiments/exp047_x138_edge_candidates/)は同じ得点のedgeを既存ILPへ増やした実験、[whole_graph_choice](whole_graph_choice.md)は複数trackerの完成graph選択。本候補は競合する局所構造の複数解を生成して選ぶ。[joint_position_edges](joint_position_edges.md)へ位置変更を分離し、共同位置選択の実装を二重に行わない。

## 入力・予測対象・出力・推論方法

- input: exp043の固定検出ID・補正座標・画像特徴・候補接続得点、局所構造を判別する画像・時間情報。
- target / objective: 注釈で確認できる接続・分裂に整合し、娘の親重複などの矛盾がない局所graphを選ぶ。未注釈の違いだけを誤graph教師にしない。
- output: 各局所成分の少数の合法な候補graphと、その中から選んだ1つのgraph。最終出力は隣接時刻の接続へ戻す。
- loss: 選択を学習する場合は部分注釈に整合する候補集合と確認済み矛盾を持つ候補を比較する。具体的な順位損失・集約・未知部分の扱いは未決事項。元と同じ目的関数だけで再選択して追加利益が生じるとは仮定しない。
- decode / 推論方法: 時間順、娘の親は最大1、母の娘は最大2を満たす複数解を作る。局所境界の接続は共有し、別成分が同じ娘を二重選択しない。候補生成法・選択器・境界の扱いは未決事項。
- 処理単位: 親候補を共有する競合成分と短い時間窓。最大点数・解数・窓長は方式を先に確定し、学習側の費用測定で上限を決める。
- 実装区分: 複数の整合解を保持して選ぶ処理が中核。edgeの平均や閾値調整だけではこの案の実装としない。

## 位置変更との境界

本候補ではexp043の補正後座標を固定し、接続graphの選択だけを比較する。元位置と補正位置の排他的な選択・整合した再採点は[joint_position_edges](joint_position_edges.md#x138の元位置と補正位置を使う比較の引き継ぎ)へ分離した。位置変更を本候補の初回条件へ含めない。

## 親実験からの差分

- 変更するもの: 単一解に確定する時点、複数局所解の生成と選択。位置・検出IDの変更は含めない。
- 固定するもの: detector・画像encoder・座標headと候補採点trackerの重み、検出IDと補正後座標、前処理、教師対応、評価分割。候補数と費用の対照を揃える。
- 再利用するコード / config / 生成物: exp043の採点・制約・後処理と、先行する同入力対照。
- 新しく作るもの: 複数解の生成、部分教師、選択器、局所境界の整合処理、候補内回収と実選択の診断。

## 最小の反証可能な検証

- 検証方法: 単一解と複数解保持を同じ局所範囲で比較し、edge・両娘組・局所graphの回収を別々に集計する。正解を使った上限と正解なしの選別を分け、追加回収も選別もない場合は全動画へ広げない。
- variant / config / fold / booster数: 単一解、複数解の上限診断、実選択の3比較を基本案とする。位置状態は追加しない。学習する場合は胚を入れ替える2方向で比較し、booster数0。選択器と総モデル数は未決。
- control再学習: 候補採点trackerは固定。選択器を学ぶ場合は同じ特徴・損失で単一解側の対照が必要かを契約に明記し、候補保持と学習量を混同しない。
- 想定runtime / resource: Kaggleのみ、週45 GPU時間以内・課金なし・1回12時間以内。複数解のsolver、再採点、後処理を含める。CPUで可能な候補選択をGPU時間と分けて計測する。

## 成功条件と停止条件

- primary指標: 候補内の正解局所graph回収と実選択、両胚の既知接続・分裂・判定可能な誤接続、最終公式combined score。
- 成功条件: 同じ予算の単一解より正解構造の回収と実選択が改善し、事前に定める誤接続条件と分裂非悪化を満たす。全graphの改善は公式評価後に判定する。
- 必須guard: 未知edgeを誤接続と断定しない。画像由来の選別ができることを別に示し、候補数を増やすだけの回収率を成功としない。
- 成功時の次段階: 局所構造でしか測れない効果を含む進行条件と費用を満たしてから全動画へ進む。採否とsubmissionはユーザー判断。
- 失敗時の停止範囲: 追加の合法graphが得られない、選別できない、境界で矛盾する、費用上限を超える場合は拡大を止める。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 正解を使った候補補充・外側での解数調整、同じ検出の複製、互いに矛盾するedgeの単純和集合、元の目的関数だけの再実行を新しい選択法と呼ぶこと。
- 壁打ちで採らなかった案と理由: 全候補の一律平均は異なる構造を壊す。補正量の倍率調整は複数の整合解を保持する問いを検証しない。2時点先の直接対応を主に変える案は[x138_two_step_links](x138_two_step_links.md)で別に扱う。

## リスク

- leakage / validation: 選択器の学習と候補上限・損失調整は学習側だけ。固定公開モデルと最終headの来歴を含む条件付き評価を明示する。
- hidden test: 追加情報は推論画像と予測だけ。注釈密度や動画間の細胞IDを仮定しない。
- runtime / memory: 密な競合成分と候補graph数で計算量が増大する。時間切れ時の処理も契約で固定する。
- 再現性: 候補生成の順序・解数・同点処理・solver・境界接続・特徴・各重みの版とSHAを保存する。

## 未決事項

- 候補内回収・実選択・誤接続を使う全graph進行条件。実測値と生成物SHAは実行時の確認事項。
