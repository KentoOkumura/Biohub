## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 制約を維持した局所的な変更を学習して、完成graphの通常接続と分裂を改善する。
- この候補の具体的な仮説: 学習側で観測した親取り違えの持続長・連続欠落・密度・誤分裂・誤辺の過信を入力graphへ再現し、同じ修正器を実予測へ調整すると、実予測だけの学習や独立な破損より実graphを改善できる。
- 仮説が正しい場合に期待する観測: 合法な操作内に修復可能な既知誤りがあり、学習がそれを選び、壊す正解を抑えて両胚の最終指標が改善する。
- 仮説を棄却する観測: 操作集合に正しい修復がない、人工誤りにしか効かない、無変更へ退化、誤修正が上回る、順序・窓境界で不安定。
- この候補だけで上位仮説を判断できるか: いいえ。
- 上位仮説の判断に残る検証: ILP前の構造費用学習、直接選択、候補生成、分裂教師の不足は別比較。

## 入力・予測対象・出力・推論方法

- input: exp043の完成graph、局所の固定画像特徴・補正座標・検出得点・未使用候補、候補edge得点と存在mask、前後の短い予測軌跡。推論でGT履歴を使わない。
- target / objective: 既知注釈から確定できる誤りを直し、既知の正しい接続を保つ合法な操作を学ぶ。合成は確認済み部分graphに限定し、未注釈の全graphを完全正解とみなさない。
- output: 変更なし、親変更、競合する接続の交換、分裂2本の同時追加、候補点の回収などの操作得点。最初に含める操作集合は未決。
- loss: 既知注釈で優劣を判定できる操作の部分教師損失と不要編集への罰則を候補とする。具体式は未決。実誤りを模した入力で事前学習し実予測で調整する。未知のedgeを一律負例・削除対象にしない。
- decode / 推論方法: 削除と追加を原子的な操作として採点し、競合する操作を制約付きで同時選択する。子の親最大1、母の子最大2、時間方向、ID整合を守る。具体solverと境界は未決。exp043全後処理の後に適用し、旧ルールで再上書きしない。
- 処理単位: 完成graphの曖昧な局所領域と短い時系列。窓長、領域抽出、境界での統合は未決事項。隣接2-frameだけで欠落補完の効果を判定しない。
- 実装区分: 既存グラフの合法な編集を学ぶ独立案。特定論文の忠実再現ではない。完成graphを利用するため、前段ILPそのものの置換と称しない。

## 最小の反証可能な検証

- 検証方法: 学習側の実予測で修復上限・教師数と誤り持続長・密度・得点分布を測り、生成誤りと照合する。同一修正器・候補・実教師・復号で、実予測のみ、独立破損の事前学習後に実予測へ調整、相関破損の事前学習後に実予測へ調整を比較。設定を学習側内部で固定し反対胚の実予測で評価する。
- variant / config / fold / booster数: 学習3条件×2foldが提案。独立破損と相関破損は同じ総学習量で比較し、実予測のみ条件との学習量差も記録する。未変更exp043と固定ルールは推論参照。最終モデル数・学習量は設計時に確定、booster数0。
- control再学習: 入力となるexp043は固定。必要な修正学習対照と分割外予測は同じ実験内で作る。対照作成だけを別実験へ分割しない。

## 成功条件と停止条件

- primary指標: 全graphの公式combined scoreと接続・分裂成分。初段は操作内の修復可能率、実際の修復数/正解破壊数、観測可能な誤接続、分裂、構造違反。
- 成功条件: 相関破損を含む方式が、実予測のみ・独立破損の同モデル対照と未変更exp043に対し、両胚の実予測で正解破壊を抑えた修復を増やし、全graph公式combined scoreを改善、division Jaccardを損なわない。
- 必須guard: 実誤りと生成誤りの持続長・密度・得点の差、未知部分、無変更率、入力をコピーするだけの退化、誤りのない確認済み領域への不要編集、窓境界を記録。座標・画像・既知教師を保ち、破損後に軌跡特徴・運動参照を再計算する。
- 成功時の次段階: 短時系列の診断と費用条件を満たした場合のみ、Kaggleで全graphと公式評価を行う。採否・完了・submissionはユーザー判断。
- 失敗時の停止範囲: 教師不足・修復可能候補なし、生成誤りが実誤りと合わない、人工例だけの改善、入力コピーへの退化、実予測のみの対照に勝てない、正解破壊・片胚の悪化、予算超過なら拡大を止める。

## リスク

- leakage / validation: 破損分布と設定は学習胚内部だけで推定する。実予測教師を作る内部分割を決め、既に分析した20動画を未使用評価と呼ばない。固定公開モデル・座標headの来歴を含む条件付き比較とする。
- hidden test: 不確かさだけで拾えない高確信の誤りがある。領域抽出を全体評価へ含め、GTに依存しない。
- runtime / memory: 操作の組合せ・繰返しで増加する。回数上限、同点処理、境界に未決がある。
- 再現性: 元graph・操作候補・採用操作・修正後graphのIDとSHAを保存し、変更を追跡可能にする。
