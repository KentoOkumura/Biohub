## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 制約を維持した局所的な変更を学習して、完成graphの通常接続と分裂を改善する。
- この候補の具体的な仮説: 変更なしと親変更・接続交換・分裂組追加・点回収を競わせれば、既知の誤りを減らしつつ正しい既存接続を維持できる。
- 仮説が正しい場合に期待する観測: 合法な操作内に修復可能な既知誤りがあり、学習がそれを選び、壊す正解を抑えて両胚の最終指標が改善する。
- 仮説を棄却する観測: 操作集合に正しい修復がない、人工誤りにしか効かない、無変更へ退化、誤修正が上回る、順序・窓境界で不安定。
- この候補だけで上位仮説を判断できるか: いいえ。
- 上位仮説の判断に残る検証: ILP前の構造費用学習、直接選択、候補生成、分裂教師の不足は別比較。

## 入力・予測対象・出力・推論方法

- input: exp043の完成graph、局所の固定画像特徴・補正座標・検出得点・未使用候補、候補edge得点と存在mask、前後の短い予測軌跡。推論でGT履歴を使わない。
- target / objective: 既知注釈と矛盾する部分を直し、既知の正しい接続を保つ合法な変更を選ぶ。未知部分だけが異なる操作間に正解順位を捏造しない。
- output: 変更なし、親変更、競合する接続の交換、分裂2本の同時追加、候補点の回収などの操作得点。最初に含める操作集合は未決。
- loss: 既知注釈で優劣を判定できる操作対の順位または部分教師損失。正解edge破壊を明示評価する。未注釈edgeを一律に削除対象にしない。人工誤りだけを主教師とせず実予測の誤りでも評価する。
- decode / 推論方法: 操作後も子の親最大1、母の子最大2、時間方向、ID整合を満たす。親変更は削除と追加を原子的に扱う。競合操作の同時選択または制約付き逐次選択を設計時に選ぶ。exp043全後処理の後に適用し、さらに旧ルールで上書きしない。
- 処理単位: 完成graphの曖昧な局所領域と短い時系列。窓長、領域抽出、境界での統合は未決事項。隣接2-frameだけで欠落補完の効果を判定しない。
- 実装区分: 既存グラフの合法な編集を学ぶ独立案。特定論文の忠実再現ではない。完成graphを利用するため、前段ILPそのものの置換と称しない。

## 親実験からの差分

- 変更するもの: exp043完成graphの後に、学習した局所変更の選択を加える。
- 固定するもの: exp043の検出器・画像encoder・座標head・公開tracker、元の候補・ILP・全後処理。追加する回収候補集合は対照と共通に固定し、候補増加と選択学習の効果を分ける。
- 再利用するコード / config / 生成物: exp043の全推論と未使用点・低得点点の生成、段階別ID対応、既知教師の照合。必要な特徴の追加取得は費用へ含める。
- 新しく作るもの: 局所操作生成、合法性検査、実予測からの部分教師、変更選択モデル、修復/破壊診断。

## 最小の反証可能な検証

- 検証方法: 学習せず、完成graphの既知誤りを操作候補だけでどこまで直せるか測る。余地があれば、学習側の実予測で修正モデルを学び、短時系列で修復したedgeと壊したedge、分裂、操作数、境界を評価する。
- variant / config / fold / booster数: 未変更exp043、同操作集合の固定ルール選択、学習選択を比較する案。人工誤り事前学習は別条件とし、同時追加しない。両胚を入れ替える2方向、booster数0。
- control再学習: 入力となるexp043は固定。必要な修正学習対照と分割外予測は同じ実験内で作る。対照作成だけを別実験へ分割しない。
- 想定runtime / resource: [現在方針](KAGGLE_DIRECTION.md#今後の学習方針)のKaggle・課金なし・週次GPU枠・提出推論12時間に従う。候補全得点・未使用点の特徴保存、予測graph作成、操作反復を含めて実測する。

## 成功条件と停止条件

- primary指標: 全graphの公式combined scoreと接続・分裂成分。初段は操作内の修復可能率、実際の修復数/正解破壊数、観測可能な誤接続、分裂、構造違反。
- 成功条件: 未変更exp043と同操作固定ルールに対して、両胚で正解破壊を抑えた修復が増え、事前条件を満たし、全graphの公式指標にも改善が残ること。
- 必須guard: 部分注釈で観測できない誤修正は不明として残す。合法性と窓境界、変更なし率、密集・分裂・欠落領域を確認する。数値の進行条件は実装前に固定する。
- 成功時の次段階: 短時系列の診断と費用条件を満たした場合のみ、Kaggleで全graphと公式評価を行う。採否・完了・submissionはユーザー判断。
- 失敗時の停止範囲: 修復可能な候補がない、実予測に移行しない、正解破壊増加、予算超過なら全graph実行を止める。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 未注釈の全edgeを誤りとする、GTを局所領域の抽出に用いてそのまま本番性能とする、既存graphを正解として模倣する、画像側再学習、外側で操作閾値の再調整。
- 壁打ちで採らなかった案と理由: [neural_graph_selection](neural_graph_selection.md)はILP選択自体の置換。[x138_detection_recovery](x138_detection_recovery.md)は回収候補の選択、[neighbor_dynamics](neighbor_dynamics.md)は運動参照の利用。本候補は既存接続の交換も含む完成graphの修正を扱い、これらを一括実装しない。

## リスク

- leakage / validation: 学習に使った動画の予測は誤りが少なく修正教師が偏る。学習側内部で対象を外した下流予測の作成方法を定める。画像側・座標headの学習来歴は条件付き比較として残す。
- hidden test: 不確かさだけで拾えない高確信の誤りがある。領域抽出を全体評価へ含め、GTに依存しない。
- runtime / memory: 操作の組合せ・繰返しで増加する。回数上限、同点処理、境界に未決がある。
- 再現性: 元graph・操作候補・採用操作・修正後graphのIDとSHAを保存し、変更を追跡可能にする。
