- Assumption: 2時点先の同一系譜の観測が、隣接2本のスコアだけでは分からない経路の正誤を識別する。論文は2時点先の教師を使うが最終リンクは隣接時点であり、本案の経路選択はその発展案。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 2時点先の対応を、3時点の経路選択へ伝える価値。
- この候補の具体的な仮説: exp043の隣接候補を固定したまま、A→B→Cの経路を選ぶ際にAとCの同一系譜の予測を加えると、最終graphの誤接続を減らせる。
- 仮説が正しい場合に期待する観測: 同じ候補集合内の正しい経路選択が増え、分裂を抑制せず両胚の公式指標が改善する。
- 仮説を棄却する観測: 2時点先の予測が経路の正誤を識別しない、片側胚や分裂が悪化する、ILP後の利得が後処理で消える。
- この候補だけで上位仮説を判断できるか: いいえ。
- 上位仮説の判断に残る検証: [案1](x138_window_features.md)の特徴追加、位置履歴・近傍移動、[案5](x138_edge_candidates.md)による候補拡張との組合せ。

## 入力・予測対象・出力・推論方法

- input: exp043の固定検出候補・補正座標・固定画像encoderの点特徴、隣接接続スコア、3時点の候補経路。特徴の入力窓と役割を記録する。
- target / objective: 主催者GEFFから確認できる2時点先の祖先・子孫対応。既知の分裂後の子孫も対象とし、姉妹間を祖先関係としない。既知の矛盾だけを負例とし、途中注釈の欠落や不明な第2娘を負例にしない。
- output: 2時点先の対応得点と、それを使って選んだ隣接接続graph。時点を飛ばす辺を提出へ直接追加する案ではない。
- loss: 既知祖先対応に対する部分教師の損失。学習器・具体式・重み・分裂の扱いは未決。exp043の予測を正解教師にしない。
- decode / 推論方法: exp043の隣接辺得点に加え、選択された3時点経路の整合性を評価する。経路の補助変数を持つILP等の具体方式、同じ証拠の重複加算防止、分裂経路の得点は未決。
- 処理単位: 3時点の候補経路を評価し、動画の整合した隣接graphを選ぶ。最初の比較では候補拡張を併用しない。
- 実装区分: 多時点の対応学習をexp043へ適用する独立案。Trackastra本体の忠実再現とは呼ばない。隣接確率の積だけを独立した2時点先の観測として代用しない。

## 最小の反証可能な検証

- 検証方法: 同じ候補と隣接スコアで、経路得点なしのexp043と、2時点先の対応を加えた選択を比較する。新しい予測器の単体診断では正しい経路・既知誤経路・分裂を区別する。
- variant / config / fold / booster数: 固定exp043対照と追加予測器1構成を基本案とする。胚を入れ替える2fold、内部でのみ設定選択。学習条件・比較総数は設計時に確定、booster数0。
- control再学習: exp043の既存trackerはしない。追加予測器だけを学習する。
- 想定runtime / resource: Kaggleのみ・課金なし。現在の学習方針と実行前のGPU残量を適用し、特徴再取得、学習、経路数・ILPの時間を別計測する。密な領域の経路数増加を評価する。

## 成功条件と停止条件

- primary指標: 両胚の公式combined score、接続・分裂成分。候補経路の回収、判定可能な経路誤り、両娘回収と母数を先に測る。
- 成功条件: 同じ候補のexp043より両胚の最終graphが改善し、division Jaccardが非悪化。経路診断からgraphへ進む条件は実装前に固定する。
- 必須guard: 単体の親1位率だけでは経路選択を評価できないため、候補経路の識別と小規模graph・計算費用を初段条件にする。全後処理後まで変更の伝達を確認する。
- 成功時の次段階: 事前条件を満たす構成を公式評価へ進める。採否・完了はユーザー判断を受ける。
- 失敗時の停止範囲: 教師の識別不能、経路誤りや分裂の悪化、予算超過なら全graphを始めない。外側胚で得点係数を調整しない。

- 壁打ちで採らなかった案と理由: 単なる方向反転や等速外挿は既存処理と重なる。[neighbor_dynamics](neighbor_dynamics.md)は近傍移動からのずれ、[shared_edge_graph_learning](shared_edge_graph_learning.md)は継続・分裂集合の共有得点とgraph学習であり、2時点先の対応を別に予測する本案とは異なる。
