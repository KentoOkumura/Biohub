## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 画像から細胞の3D領域を予測・分離し、中心とgraphへ変換する表現を検証する。
- この候補の具体的な仮説: 品質を確認した領域教師でnnU-Netを学習し、接触した細胞を分離して得た中心を追跡すれば、中心検出を起点とする対照より両胚の公式指標が改善する。
- 仮説が正しい場合に期待する観測: 密集部での中心の見逃しや2細胞の混同が減り、過分割による過剰検出を増やさず、通常接続と分裂の回収が改善する。
- 仮説を棄却する観測: 領域の重なりだけ改善してgraphの指標が下がる、過分割・誤結合が増える、中心変換で主催者の注釈との対応が悪化する、または推論費用が上限を超える。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: [2D断面の3D統合](slice_3d_instances.md)、[中心集合の直接出力](direct_center_set.md)、[時空間のvoxel関係](voxel_time_affinity.md)など別の出力表現。1候補の結果で既存仮説全体を閉じない。

## 入力・予測対象・出力・推論方法

- input: 3D画像、物理間隔、来歴と品質を確認した学習側の領域教師。有効な教師領域と未知領域を区別する。
- target / objective: 個々の細胞を分離するための領域教師。前景・境界などのクラスを使うか、分離に必要な距離情報を追加するかは未決。
- output: 領域の予測値、細胞ごとの3D領域、中心と信頼度、最終的な接続・分裂graph。
- loss: 確認済み領域だけを使うDice損失と交差エントロピーなどを候補とする。Diceは領域の重なりを学習する損失であり、採用判断の公式指標にはしない。疑似教師の誤りと未知領域の重み付けは未決。
- decode / 推論方法: nnU-Netの3Dパッチ予測を統合し、予測画像に基づいて接触細胞を分離する。領域から中心を取り出し、現行と同じ方式の接続器へ渡す。分離用の種、分離方法、中心の定義と接続特徴は未決。推論時に正解中心を分離の種として使わない。
- 処理単位: 3Dパッチを時点ごとに予測し、動画内で追跡する。前後時点の画像を領域モデルに与えるかは設計時に固定する。外側分割は胚単位。
- 実装区分: nnU-Netの設定・学習・推論と、細胞を分離する処理を保持した構成を意図する。具体案確定後に[用語集](../docs/glossary.md)のこのリポジトリ内の管理ラベルを選ぶ。2D断面の統合で3D領域予測を代用しない。

## 親実験からの差分

- 変更するもの: 領域教師、検出モデルの出力と損失、細胞の分離、領域から中心への変換、必要な特徴の接続部分。
- 固定するもの: 胚を分ける評価、固定公式評価器、同じ評価動画、物理単位、接続・分裂の推定方式と共通予算。教師の情報量と領域表現の効果を区別できる対照を用意する。
- 再利用するコード / config / 生成物: exp005の分割・graph評価・保存・hidden test処理。追跡器は画像特徴との整合を確認してから利用し、重みをそのまま使えるとは仮定しない。
- 新しく作るもの: 教師の来歴manifest、品質評価と未知mask、nnU-Net入力、分離と中心変換、必要な追跡器への接続、費用の測定記録。

## 最小の反証可能な検証

- 検証方法: 教師を確保した後、学習胚内の小領域で細胞の欠落・過分割・誤結合・中心のずれを確認する。実験化後に3D領域の学習・分離・追跡を一通り通し、仕様固定後に胚を入れ替える2方向で公式指標を比較する。
- variant / config / fold / booster数: 最初の提案は領域モデル1構成と対照、外側2fold。領域教師から中心を得る同情報量の対照を加える必要性と総学習回数は未決。複数モデルの平均は初回に加えない。
- control再学習: 領域教師を追加する効果と予測表現の効果を区別するには、同じ教師情報を使う中心検出の対照が必要。既存の同条件重みがなければ再学習を要する。
- 想定runtime / resource: 教師生成、領域学習、分離・追跡推論を別々に計測する。Kaggle無料枠内、課金なし、提出推論12時間以内。教師生成を含む総予算は未実測。

## 成功条件と停止条件

- primary指標: exp003で照合した固定公式評価器の総合スコア。胚別の接続・分裂成分と検出数を併記する。
- 成功条件: 両胚で対照より公式指標が改善し、実行失敗が増えず、必要な推論処理が12時間以内に収まる証拠を得る。領域精度だけでは採否を判断しない。
- 必須guard: 評価胚の注釈・中心・細胞数を教師生成・分離規則・条件選択へ使わない。疑似教師を完全な真値とみなさず、来歴と有効領域を保持する。
- 成功時の次段階: 公式結果と費用、教師依存性を提示してユーザーに採否を確認する。本登録は実験化・Kaggle実行・submissionの承認ではない。
- 失敗時の停止範囲: 教師の品質・来歴が不十分、分離が成立しない、片側胚が悪化、推論費用超過のいずれかで本比較を停止する。中心検出案と既存の上位仮説全体は独立して扱う。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 点周囲の球を実際の細胞境界とみなす、前景を予測するだけで接触細胞も分離済みと扱う、正解中心で領域を分割する、未知領域を背景にする、外側評価胚で分離条件を最適化すること。
- 壁打ちで採らなかった案と理由: 先行候補には[中心マップの学習](nnunet_center_detection.md)を挙げた。こちらは領域教師を要するため別候補とする。人手注釈、FOCUSの取得条件同意、別の外部重みの採用は今回決めていない。
- 既存候補との差: [slice_3d_instances](slice_3d_instances.md)は2D断面から3Dへ統合、[shape_aux_teacher](shape_aux_teacher.md)は領域の形状を補助教師として利用する。本候補ではnnU-Netが3D領域を主出力として予測し、分離結果から検出中心を作る。

## リスク

- leakage / validation: 教師モデルの学習来歴や、評価胚から作った疑似教師の混入。同じ胚内の隣接時点・重なる領域も外側評価へ混ぜない。
- hidden test: オフラインで利用できる画像とmetadataだけで、全時点の領域を中心・隣接時点への辺に変換する必要がある。
- runtime / memory: 領域予測に加えて3D分離と追跡が必要。全動画の領域maskをメモリへ保持せずに処理できるか確認する。
- 再現性: 教師とモデルの版・依存関係・前処理計画・分離条件・座標変換を固定する。動的な外部モデル取得を提出時の前提にしない。
