## 観測事実と根拠

- 実測済みの事実: Trackastraは検出集合の時空間文脈から対応得点を学習する手法であり、本コンペ向けに学習・評価した結果はない。exp027の3時点局所attentionは両胚で一貫して改善せず、exp032の学習延長も部分窓で保存済みexp016を上回らなかった。これらはTrackastraの対応教師・正規化・損失を再現した比較ではなく、本案の棄却根拠とはしない。
- 根拠ファイル / 一次資料: [Trackastra論文](https://arxiv.org/html/2405.15700v2)、[公式実装](https://github.com/weigertlab/trackastra)、[exp027結果](../experiments/exp027_multi_frame_tracker/result.md)、[exp032結果](../experiments/exp032_three_frame_ten_epoch_training/result.md)、[exp016教師・評価](../experiments/exp016_frozen_image_encoder/frozen_tracker.py)。新たな文献探索ではなく、会話で確認した手法の適用候補を記録する。
- 利用する保存済み生成物とSHA: 入力cache・公開checkpointのidentityとSHAはexp016 config、対照モデル・予測は[exp016 metrics](../experiments/exp016_frozen_image_encoder/metrics.json)を正とする。適用するTrackastra sourceのrevision、窓対応表、学習生成物のSHAは実験化時に固定・記録する。
- 仮定: Assumption: 親候補の競合、分裂を含む複数時点の対応を一緒に学べば、単独の隣接接続だけでは区別できない候補を選べる。ただし固定候補にない細胞を本案だけで回収できるとは仮定しない。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 短い時間窓の検出集合を使う対応モデルと、時間をまたぐ対応教師・正規化の組合せ。動画全履歴、検出器更新、軌跡擬似教師の生成は対象外。
- この候補の具体的な仮説: 固定候補・固定画像特徴の下で、Trackastraを参考にした窓内対応学習が、保存済みexp016より両胚の接続回収を改善し、分裂回収と教師上の負例予測を許容範囲に保つ。
- 仮説が正しい場合に期待する観測: 同じ評価ペアで正解親順位と既知接続回収が改善し、密集領域・分裂を含む有効件数でも悪化しない。単なる確率の閾値跨ぎと順位改善を区別する。
- 仮説を棄却する観測: 確定した教師・構造・学習条件で進行条件に届かない、または疎い注釈で必要な教師を作れず、計算予算にも収まらない。その適用設計を停止し、時間情報全般まで棄却しない。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: [past_feature_cross_attention](past_feature_cross_attention.md)による過去画像特徴の参照、[multi_time_past_candidate_attention](multi_time_past_candidate_attention.md)による座標集約、予測履歴、公式graph評価。モデルと損失をまとめて変える本案だけで、改善原因を時間窓の長さだけに特定しない。

## 入力・予測対象・出力・推論方法

- input: 同じ動画の短い窓内の固定検出点、物理座標、実時刻、有効mask、保存済み画像特徴。初回は対象ペアを含む5〜6時点を候補とし、窓長・方向は実装前に確定する。全動画の履歴や正解軌跡は入力しない。
- target / objective: 窓内の既知の同一系譜対応。隣接接続と母娘接続に加え、既知の接続列から保証できる非隣接対応を候補とする。教師に使う時間差とmaskは未決事項。未注釈、見逃し、crop外の親を「対応なし」の正解にしない。
- output: 窓内の検出点間の対応得点。最終的にはコンペが求める隣接時点間の接続得点を取り出す。分裂による1母2娘を許し、子に複数親を割り当てない。
- loss: 原論文の親候補間の正規化と対応なしを許す仕組み、正規化した対応に対するbinary cross entropy（BCE、二値交差エントロピー）と補助損失を参照する。疎い主催者注釈へそのまま密な0/1行列を当てはめず、既知・未知のmask、非隣接教師、分裂の扱いを実装前に確定する。exp016の損失を維持する案とは別比較。
- decode / 推論方法: 重複する短窓の同一接続得点を集約し、隣接接続を既存の候補生成・整数線形計画（ILP）による復号へ渡す案。最初は全graphを作らない共通ペアの単体評価。集約規則、secondary trackerとの得点の整合、正逆方向の扱いは確定が必要。
- 処理単位: 窓内の全検出点をtokenとし、self-attentionとcross-attentionを含む対応モデルで点間の関係を学ぶ。教師の処理単位は窓、対照との共通診断は隣接2時点、最終出力は動画の接続graph。
- 実装区分: Trackastraの対応モデル・正規化・対応学習を残し、入力特徴と部分注釈への適用変更を明記する。公式評価だけを後段に分ける`staged-faithful`を想定するが、これは本リポジトリ内の管理用語。原論文の完全再現や公式の学習済み重みの直接適用とは呼ばない。

## 最小の反証可能な検証

- 検証方法: 学習前に、隣接・非隣接・分裂・対応なしについて、既知と保証できる教師の件数・分母を胚別に確認する。小規模な学習成立と時間・メモリを確認後、保存済みexp016と同じ対象ペアで接続・分裂指標を比較する。非隣接教師が作れない場合に、無断で隣接のみの別設計へ置き換えない。
- variant / config / fold / booster数: 初回は1構成、外側2fold・モデル2個を基本案とする。boosterなし。epoch・層数・幅・head数・時間差・初期化は設計時に固定し、評価後に探索を増やさない。
- control再学習: 保存済みexp016を対照とし、初回から再学習を必須にしない。画像特徴・時間窓・損失が異なるため、この比較を時間情報だけの効果測定とはしない。
- 想定runtime / resource: Kaggle Notebook、GPU週30時間以内・課金なし・Notebook最大12時間。窓内の総検出数に対してattention・対応行列が増えるため、通常窓と密な窓のforward/backward、2fold学習、後続推論を見積もる。必要な特徴再抽出も費用へ含め、Colab例外は引き継がない。
- 受け入れテスト案: 時刻・物理単位・候補順序の整合、動画混入防止、paddingと空窓、分裂の1対2教師、未知mask、同一接続の窓間対応、分割計算の等価性、未来側を含む窓の扱いを確認する。

## 成功条件と停止条件

- primary指標: 初段は両胚別の既知接続recall。公式精度は全graphの公式combined scoreと成分で判断する。
- 成功条件: 実行前に確定する推奨条件は、両胚で保存済みexp016より既知接続recallが厳密に改善、同じ評価mask内の教師負例予測の増加が各胚5%以内、分裂親回収数が非減少。得点正規化が変わるため、固定閾値での比較と正解親順位を分け、校正が必要なら学習側だけで規則を定める。
- 必須guard: 教師件数・有効分母、親1位率、教師負例予測、分裂親回収、密集度・窓境界別の結果、非有限値なし。部分注釈由来の負例指標を真の誤接続全数と呼ばない。分裂などの有効分母がなければ判定不能とする。
- 成功時の次段階: 単体結果と総費用を提示し、全graph・公式評価へ進むかユーザーに確認する。採否・完了・submissionは別の明示判断とする。
- 失敗時の停止範囲: 教師が成立しない、片方でも進行条件未達、入力不整合・非有限値・予算超過なら全graphへ自動進行しない。公式score未計測と明記し、候補数・教師・窓長を無断で削って手法の実施済みとはしない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 未知を全て負例または対応なしにする教師、正解系譜の入力、確定軌跡だけの入力、画像encoder更新、外側評価での閾値・窓長・損失選択、既存pair MLPの時点数だけの変更をTrackastraと呼ぶこと。
- 壁打ちで採らなかった案と理由: 全履歴入力はユーザーが不要とした。公式の学習済みモデルを点検出cacheへそのまま適用する案は入力仕様が異なる。擬似教師生成は別候補であり混ぜない。原論文の領域特徴を固定画像特徴へ変更する差は明記し、完全再現という主張をしない。

## リスク

- leakage / validation: 胚分割を維持し、教師・校正・checkpoint選択は学習側のみ。公開画像重みの来歴による条件付き評価であり、独立CVとは呼ばない。
- hidden test: 開始・終了窓、空frame、検出数の変化、画像特徴元の2時点窓への依存。後の時点を含む重複窓を使う場合はオンライン因果予測とは呼ばない。
- runtime / memory: 対応行列は窓内の点数の二乗で増える。chunkingによるピークメモリ低減と演算量削減を区別する。
- 再現性: 特徴元窓、候補identity、時刻、教師mask、source版、正規化・損失、seed、checkpoint、得点集約、生成物SHAを記録する。
