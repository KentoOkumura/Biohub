- 上位仮説のうちこの候補が検証する範囲: 観測可能な構造制約を接続の直接予測へ組み込み、主催者の疎い注釈で学習したときに、固定候補内の継続・分裂を改善できるか。
- この候補の具体的な仮説: 同じ検出候補と画像特徴から、親子数や候補の競合を考慮して接続を直接選ぶと、既存の接続スコア＋ILPより誤接続を減らし、両胚の公式指標を改善できる。
- 仮説が正しい場合に期待する観測: 既知接続だけの再現率を上げる退化を起こさず、観測可能な誤接続と分裂の誤りが減る。構造制約と実行予算を満たし、全graphの公式評価でも両胚に改善が残る。
- 仮説を棄却する観測: 未知部分への過剰接続、分裂の抑制、制約違反、処理順への大きな依存、または固定対照に対する両胚改善がないこと。ILPの出力との一致だけでは本仮説を支持しない。

- 上位仮説の判断に残る検証: 別候補explicit_no_matchの対応なし教師、known_parent_constraintの既存損失との差、image_count_priorの個数情報。本候補が不成功でもこれらを棄却しない。

## 入力・予測対象・出力・推論方法

- input: 固定検出器の候補ID、時刻、物理座標、検出得点、元の時間窓で抽出した画像特徴。未注釈候補を含む。学習側の主催者GEFF中心・接続・分裂は教師の作成だけに使う。
- target / objective: 注釈から確認できる同一細胞の継続・分裂と矛盾しない接続を選ぶ。注釈欠落と検出欠落、真の接続なしを混同しない。
- output: 固定候補ID間の採用する隣接時刻の接続と、その分岐が表す分裂。単なる全ペアのスコア改善だけを本候補の直接予測と呼ばない。親を選ぶ形式か、母から娘集合を選ぶ形式かは未決。
- loss: 正解の根拠は主催者注釈のみ。未対応・注釈終端・片娘だけの注釈を確定負例や終了教師にしない。未知の選択を除外する範囲と、部分的に観測された接続集合へ損失を定義する方法は未決。exp019のmaskを既定の改善策として採用しない。
- decode / 推論方法: 学習したモデルが候補を選び、1娘に複数の母を付けないこと、母の子数上限、娘の重複選択禁止、時刻の整合を満たす出力を作る。逐次生成と選択肢のmask、または集合出力から制約を満たす形式など、具体方式は未決。推論で主催者の注釈を使わず、選択をILPへ戻して本候補を実施したことにしない。
- 処理単位: 入力cacheの単位は隣接2-frame。直接選択の時間範囲を同じ2-frameにするか、既存の複数窓の固定特徴を使うか、窓間をどう整合させるかは未決。画像encoderの再学習は含めない。
- 実装区分: 特定論文の再現実験ではなく、固定候補の接続を直接選ぶ設計案。実装時に実際の出力方式・制約・省略点を記録し、既存手法を忠実再現したと主張しない。

## 最小の反証可能な検証

- 検証方法: 実装前に、完全に既知の人工的な候補・接続の小例で出力制約と損失の意味を確認する。この小例を学習用の合成系譜へ拡張する承認ではない。実データでは学習側の注釈対応、既知接続・既知分裂・確定した矛盾・未知の件数を数え、候補を変えず小規模学習で比較する。
- variant / config / fold / booster数: 直接選択の1方式と保存済みexp016対照を基本比較とし、exp016の2方向の胚分割を引き継ぐ。複数の出力方式を同時にGPU探索しない。初期値の継承範囲と学習量は設計時に記録し、学習量の数値は小規模実測から設定する。
- control再学習: 同じ入力・教師対応・評価条件の保存済み対照を使う。教師対応等を変える必要がある場合は比較不能な既存数値と並べず、対照の再評価・再学習の要否を記録する。
- 想定runtime / resource: Kaggleのみ、GPU週30時間以内・課金なし。cacheを再利用し、学習時間・選択処理の時間・最大メモリを小規模に測る。ILPを外すだけで高速になると仮定せず、逐次生成の費用を含める。
- 全graph前の確認: AGENTS.mdの常時品質基準に従い、同じ対象の隣接2-frameで既知接続の回収、観測可能な誤接続・分裂、構造違反、接続数、胚別結果を比較する。長い履歴や窓間整合を使う場合は短い動画での代替診断と進行条件を実装前のrequirementsへ記す。再現率だけで全graph実行へ進めない。

## 成功条件と停止条件

- primary指標: 全graphの公式combined scoreと接続・分裂成分。事前の単体指標は公式scoreの代用にしない。
- 成功条件: 同じ固定候補の対照より両胚の公式combined scoreが改善し、構造制約と提出推論12時間・学習GPU予算を満たすこと。事前診断では誤接続や分裂の悪化を隠した再現率上昇を成功としない。
- 必須guard: 候補の取り違え・重複・候補外の正解を区別する。GT出力1本を非分裂、0本を終了として学習しない。ILP出力を教師にしない。未注釈候補を入力から落として推論条件と変えない。
- 成功時の次段階: 指標・実行証拠・疎い評価の限界を提示し、採否・完了はユーザーが判断する。
- 失敗時の停止範囲: 教師と推論条件が一致しない、未知を負例にする、構造違反が残る、早期診断の進行条件を満たさない場合は全graphを自動実行しない。公式score未計測と理由を記録する。教師の不足をILP擬似教師や新たな合成系譜で無断補完しない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: ILPの模倣、公開検出器・画像encoderの更新、GTによる推論候補選別、未知を接続なしとする全出力の教師化、外側胚での閾値や生成順の救済探索。
- 壁打ちで採らなかった案と理由: ILP出力を擬似教師とする案は今回のユーザー選択から外れた。画像から新しい中心・軌跡集合を生成するtrajectory_setは固定検出候補を使う本候補と異なる。frame_self_attentionは全ペア得点とILPを保つ比較、division_local_ilpはILPを残す局所再選択であり、本候補の代替にしない。

## リスク

- leakage / validation: 公開checkpointの学習来歴により条件付き評価となる点を引き継ぐ。学習用の選択履歴にGTを使う場合も、推論時には自身の予測を使う差と、未知履歴の扱いを明記する。
- hidden test: 細胞数や分裂密度の変化、窓端、候補不足に対して出力の制約を保つ必要がある。注釈の有無を推論入力へ持ち込まない。
- runtime / memory: 全候補間のattentionと逐次生成の反復が費用を増やし得る。候補制限で既知接続・分裂を失う率も測る。
- 再現性: 候補ID、順序、同点処理、制約、windowの確定順、モデル・cacheの版とSHAを記録する。
