## 入力・予測対象・出力・推論方法

- input: 固定cacheの中心・得点・画像特徴、GEFFの既知edge、候補と注釈の対応監査。
- target / objective: 各子について正しい親と確定した誤親を区別できるかを測る。既存のedge回収率集計だけの再実行にはしない。
- output: 正例・確定負例・未知・重複曖昧例の件数と、近傍親候補の順位を胚・密度・距離・対応曖昧度別に集計した診断。
- loss: 件数と生の特徴類似度の集計にはなし。小型学習モデルの目的は親候補の識別。線形射影か小型MLPか、学習損失をどれに固定するかは未決事項に残す。
- decode / 推論方法: 提出graphを変更しない。小型モデルの出力は診断用の親候補順位であり、公式scoreの代用にしない。
- 処理単位: 1動画内の隣接時刻の候補点・接続と、明記した範囲の履歴。特徴の元の時間窓を保持し、評価の分割は胚単位にする。
- 実装区分: 画像encoderの対照学習を省き固定特徴へ転用する案であり、ASCENT全体の再現ではない。[用語集](../docs/glossary.md)のこのリポジトリ内の管理用ラベルでは、原法に対して`proxy`とする。ユーザー承認後も本候補の中核処理を閾値調整だけへ縮小しない。

## 最小の反証可能な検証

- 検証方法: 同じ候補に対して座標・距離のみ、生の固定特徴の類似度、固定特徴から学習した小型モデルを比較する。まず片娘のみ・既知の別親・重複検出の例で教師資格を確認し、未知を除外した件数と除外による難易度変化を報告する。
- variant / config / fold / booster数: 上記3条件を同じ候補・2方向の胚評価で比較する。学習側の小型モデル選択を外側胚の結果でやり直さない。booster数0。
- control再学習: 画像モデル・本番trackerの再学習は不要。診断用の小型モデルだけを学習する。
- 想定runtime / resource: Kaggle Notebookのみ・GPU週30時間以内・課金なし。初期案は既存cacheを再利用して画像特徴を再抽出しない。CPUで可能な集計を先行し、追加の下流学習、最大候補数での評価・graph処理、hidden推論を別計上する。所要時間は未実測なので小規模測定で予算内か確認し、Notebook12時間を超える見込みなら本実行前に止める。

## 成功条件と停止条件

- primary指標: 近傍候補内の正しい親の順位と、使用可能な正例・確定負例の数。公式combined score改善とは呼ばない。
- 成功条件: 教師の未知・重複・分裂の扱いを検査でき、特徴の寄与またはその条件付きの不足を同条件の比較で示せる。後続へ進む根拠は局所候補の順位差で確認する。
- 必須guard: GEFF（Graph Exchange File Format）の未知領域を負例にしない。正例は注釈で確認できる有向edgeと予測中心の対応から作り、負例は別の親であることが確定した候補に限定する。重複検出・対応が曖昧な候補は対照損失から除く。娘ごとに正しい母を照合し、娘同士を競わせない。分裂の片娘だけの注釈を非分裂の完全教師とみなさない。
- 成功時の次段階: 根拠と限界をユーザーへ示す。改善を理由に別候補の実験化、Kaggle実行、submission、採用・完了を自動で確定しない。
- 失敗時の停止範囲: 資格が保証できない負例を必要とする現設計を停止する。生の特徴のcosine類似度が弱いだけで、学習可能なtracker表現全体を棄却しない。
- 再開条件: 失敗した具体的な教師・入力・表現の不足を解消する別の根拠が得られた場合に再検討する。対照学習全体や上位仮説を一括で棄却しない。

## リスク

- leakage / validation: 条件・checkpointは学習側内部だけで選び、胚を入れ替える2方向で公式combined scoreと接続・分裂成分、有効件数・失敗を報告する。公開画像モデルがtrain動画を学習に含むため、固定公開モデル下の条件付き比較であり独立した交差検証ではない。
- hidden test: 入力は画像からの予測と使用可能なmetadataのみ。GT履歴・正解の細胞数・動画間の細胞共有を仮定しない。時間窓依存の特徴を単一frameの特徴と呼ばない。
- runtime / memory: Kaggle Notebookのみ・GPU週30時間以内・課金なし。初期案は既存cacheを再利用して画像特徴を再抽出しない。CPUで可能な集計を先行し、追加の下流学習、最大候補数での評価・graph処理、hidden推論を別計上する。所要時間は未実測なので小規模測定で予算内か確認し、Notebook12時間を超える見込みなら本実行前に止める。
- 再現性: cache、重み、source、教師資格、分割、損失、候補生成、評価器の版とSHAを正本へ記録する。母・娘・重複対応の検査と最大サイズでのオフライン推論smokeを含める。
