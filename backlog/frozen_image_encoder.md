## 入力・予測対象・出力・推論方法

- input: 選定した公開検出器の候補中心・検出得点・物理座標と、元の時間窓に対応する候補点の画像特徴。学習用に主催者のGEFF中心・接続・分裂を候補へ対応付ける。
- target / objective: 既知の親子関係と分裂を予測する。予測検出を入力とし、正解は主催者の注釈に置く。未対応・重複・未知・候補外を区別して記録する。
- output: 候補間の接続得点と、選定した既存トラッカーが持つ分裂の得点または判定に必要な出力。新しい組採点への変更はdivision_tripletsで別比較する。
- loss: 選定した公開トラッカーの既存接続・分裂の学習目的を基準に、主催者注釈から教師を作る。現行の教師mask・分母・未知部分への損失を監査して記録する。maskの変更はpartial_edge_maskで別比較し、検出lossで公開画像モデルを更新しない。
- decode / 推論方法: 検出候補と復号条件を基準と揃え、学習後の接続・分裂得点を渡して最終graphを作る。モデルを変える比較以外では復号費用を同時調整しない。
- 処理単位: 元の公開モデルと同じ動画・時間窓の候補集合。最初から長い画像窓や全動画の密な候補組合せへ拡大しない。
- 実装区分: 固定する画像モデルと学習する下流部分を列挙し、参照公開モデルの構造・lossとの差を実験契約へ記録する。窓を変えた特徴を同一の特徴とは扱わない。

## 親実験からの差分

- 変更するもの: 同じ公開検出器下で接続・分裂部分を学習すること。初回は既存の下流構造を維持し、初期値の選択を含む比較条件を実験化前に確定する。
- 固定するもの: 公開検出器・画像特徴抽出器の重みと統計、候補生成、画像前処理、時間窓、復号と評価対象。optimizerから画像側を除外し、特徴抽出は勾配を保持しない。
- 再利用するコード / config / 生成物: 選定公開モデルの基準推論と学習コード、exact_window_cacheの候補点特徴、exp003の公式評価照合。exp002の設定を公開モデルの設定とみなさない。
- 新しく作るもの: 下流だけの学習、教師対応と未知状態の診断、学習前後の比較、費用と公開重み不変の記録。

## 最小の反証可能な検証

- 検証方法: 公開版・来歴と教師対応を確定し、小規模な同一窓で直接抽出と保存特徴の得点を照合する。短い学習で画像側の重み・統計が変わらず下流だけが更新されることを確認し、費用が成立した場合に対象を広げて学習前後を公式評価する。
- variant / config / fold / booster数: 初回は同じ公開検出器で既存トラッカーと下流学習後を比較する。公開checkpointの来歴に応じて評価の独立性を表示し、両胚別に報告する。学習量は小規模実測後に決め、追加seedや全層学習の比較を必須にしない。
- control再学習: 公開の既存トラッカーを初回の基準とし、検出器は再学習しない。後続の学習変更では同条件の学習済みトラッカーを対照に使い、必要な再学習も下流部分だけとする。
- 想定runtime / resource: 未実測。Kaggle Notebookのみ、週30時間のGPU枠と実行時残量に従う。初回抽出、読み込み、下流学習、公式評価、全件推論を別計上する。固定特徴でも候補数の増加で時間・メモリが大きくなる場合はsparse_motion_graphで回収率と費用を診断する。

## 成功条件と停止条件

- primary指標: 現行公式combined scoreと接続・分裂成分。両胚別の結果、失敗・有効件数、評価の独立性を併記する。
- 成功条件: 検出器が不変で、再現可能な下流学習・比較が週の残量内に成立することを基準整備の条件とする。精度仮説の支持には同じ固定検出器下で両胚の改善が必要。基準整備と精度向上を別々に判定する。
- 必須guard: 公開重みの来歴と分割を記録し、外側評価の正解で教師・条件を作らない。画像側の更新、条件の違うcacheの再利用、未注釈を確定負例とする解釈を避ける。
- 成功時の次段階: 結果と限界を示して採否はユーザーが判断する。partial_edge_maskとdivision_tripletsへ比較基準を引き継ぐ。
- 失敗時の停止範囲: 当該学習を停止して画像情報・候補回収・教師・費用のどこが制約か記録する。全層更新や検出器再学習へ自動で変更しない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 自前検出器の再学習を公開検出器固定の実装と扱う、全層学習を必須対照にする、学習を行わず閾値・後処理だけで本候補を完了させる、外側評価で条件を探索すること。
- 壁打ちで採らなかった案と理由: 旧案の全層更新との比較は新方針と週の予算に合わないため初回比較から外す。frame単独cacheへの置換は時間窓の画像特徴を変えるため採らない。

## リスク

- leakage / validation: 公開重みの学習来歴は未確認。評価胚を含む・不明な場合は固定公開モデル下の条件付きの比較とし、トラッカーの分割だけで独立CVになったと解釈しない。
- hidden test: 画像と使用可能なmetadataから候補を作り、GEFFは学習・診断の教師のみ。提出は隣接時刻の辺へ戻す。
- runtime / memory: 凍結は画像側の逆伝播を省くが、初回特徴抽出・候補間計算・最終推論の費用をなくさない。最大入力と保存量・読み込みも測る。
- 再現性: 公開版、重みと統計のSHA、候補と時間窓、特徴schema、分割、教師対応、下流初期値、評価器を記録する。
