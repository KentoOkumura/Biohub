- 根拠ファイル / 一次資料: 上記sourceと[カルマン予測と割当の解説](../docs/surveys/biohub-tracking-techniques-illustrated_20260915.md#sort)、[appearance_reference](appearance_reference.md)の予測履歴の来歴・誤り対策、[neighbor_dynamics](neighbor_dynamics.md)の近傍履歴との境界。これらは本案の改善証拠ではない。
- 利用する保存済み生成物とSHA: [exp015 metrics](../experiments/exp015_oracle_stage_limits/metrics.json)のcacheと[exp016 metrics](../experiments/exp016_frozen_image_encoder/metrics.json)の重み・対照を参照する。新たな履歴は予測元の学習split、重み、候補、設定、SHAを記録する。
- 仮定: Assumption: 過去の相対位置・変位から学ぶ情報が、画像特徴と単一変位だけでは曖昧な接続を補う。誤履歴を含む実予測でも効果が残ることを必要とする。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 同じ細胞と予測した過去の位置列を、学習するtrackerの接続特徴として使う効果。
- この候補の具体的な仮説: 同じ固定画像特徴・中央ペア・教師・損失・復号で、予測位置列を入力した条件が履歴を隠した対照より両胚の公式combined scoreを改善する。
- 仮説が正しい場合に期待する観測: 自己予測履歴でも取り違えが減り、履歴を隠す・入れ替える診断で効果が失われる。履歴不足や分裂直後で悪化しない。
- 仮説を棄却する観測: 正解履歴の場合だけ改善する、履歴を入れ替えても変わらない、誤対応が連鎖する、または片方の胚で公式指標が悪化する。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: [未対応点の複数時点入力](multi_frame_tracker.md)、カルマン予測、周囲の動き、画像特徴の履歴、軌跡断片・欠測の回収。

## 入力・予測対象・出力・推論方法

- input: 現在の2時点の固定画像特徴・候補座標に、同じ細胞と予測した過去3〜5時点の相対位置・変位、時間差、欠測mask、対応の信頼度を追加する提案。正解の細胞ID・分裂・軌跡は通常入力に渡さない。
- target / objective: 現在のsource候補から次時点のtarget候補への通常接続・母娘接続。位置予測や平滑化座標の出力へ主目的を変えない。
- output: 対照と同じ隣接ペアの接続logit。提出する検出中心は固定する。
- loss: exp016の接続損失と教師maskを維持する。履歴の有無とloss変更を混ぜず、未知の接続を追加の負例にしない。履歴の補助損失や対照損失は初回に追加しない。
- decode / 推論方法: 小型Transformerなどで履歴を集約して既存の接続予測へ渡し、同じsecondary寄与・整数線形計画（ILP）・修復で処理する提案。履歴を固定の初回予測から作るか逐次更新するかは未決事項。平滑化した位置・速度の提出ではない。
- 処理単位: 1動画内の予測trackの履歴と評価対象の隣接ペア。動画・foldをまたいで状態を継承しない。
- 実装区分: 特定論文の再現ではなく、位置列を直接入力して接続を学ぶ比較案。このリポジトリ内の管理用語では中核の履歴入力を保持する`faithful`を想定する。カルマン費用や一定速度だけの特徴を本案の実装と呼ばない。

## 最小の反証可能な検証

- 検証方法: 同じ履歴集約器で現在位置だけを有効にする対照と予測履歴条件を比較する。現在位置・画像特徴・教師対象を揃える。正解履歴は任意の上限診断だけに使い、設定・checkpoint選択や実改善判定には使わない。
- variant / config / fold / booster数: 主比較2条件×外側2fold、保存済みexp016参照、booster 0。履歴生成用trackerの内部split・追加学習数は実装前に確定する。履歴長3〜5は候補範囲で、全条件の探索承認ではない。
- control再学習: 同構造の履歴なし対照を学習する。保存済みexp016は再学習しない。履歴生成の追加学習が必要なら回数と費用へ含める。
- 想定runtime / resource: Kaggleのみ、週30 GPU時間以内、提出推論12時間以内。履歴生成・内部学習・tracker学習・graph推論を別計上し、履歴が無料で得られるとは扱わない。
- 全graph推論への進行条件: 履歴は正解なしの動画内予測から作り、単体評価でも正解の過去へ毎フレーム戻さない。同じ隣接ペアで既知接続recall、判定可能な誤接続、分裂、有効件数を両胚別・履歴長別・信頼度別に比較する。両胚で改善し、誤接続・分裂を悪化させず、境界・予算検査を通ることを提案する。指標・閾値は実装前に固定する。長い誤対応の連鎖は単体で測れないため、予測履歴を引き継ぐ短い動画診断も先行する。

## 成功条件と停止条件

- primary指標: 現行公式combined score。adjusted edge Jaccard、division Jaccard、両胚別・履歴条件別の結果も示す。
- 成功条件: 正解を使わない履歴条件が履歴なし対照より両胚の公式combined scoreを改善し、分裂成分が悪化せず、全対象で有効かつ予算内。exp016との差も別報告する。
- 必須guard: 学習時も予測履歴、予測元の学習分割、正解に依存しない信頼度、時刻・動画境界、初期化・短履歴・欠測・分裂後の状態継承を検証する。
- 成功時の次段階: ユーザーへ結果を示し、採否・完了と他の時間情報との統合を判断してもらう。
- 失敗時の停止範囲: 正解履歴だけの改善、誤対応の増幅、単体診断不成立なら全graphへ進まない。公式score未測定と記録し、別方式や検出器学習へ自動で切り替えない。

## リスク

- leakage / validation: 学習履歴は対象動画をtracker学習から除いた予測で作り、外側胚は生成器・集約器・設定の学習から除く。公開画像モデル由来の学習内評価は残り、全工程の独立CVとは呼ばない。
- hidden test: 履歴は推論画像・検出・予測だけで作る。動画開始、空フレーム、短履歴、分裂後でも有効な出力を返す。固定特徴は2時点窓依存で、過去画像だけの因果的予測とは呼ばない。
- runtime / memory: 履歴生成の追加pass・内部学習、track数・保持量を最大例で測る。未取得履歴の費用を除外しない。
- 再現性: 予測元split・重み・規則、候補ID・座標・時刻、信頼度・reset、履歴長・集約器、生成物SHAを保存する。
