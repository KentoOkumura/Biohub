## exp027の結果から引き継ぐこと（2026-09-20）

### 観測事実と解釈の範囲

- 根拠: [exp027の結果](../experiments/exp027_multi_frame_tracker/result.md)、[metrics](../experiments/exp027_multi_frame_tracker/metrics.json)の`context_diagnostic`・`validation_diagnostic`、[考察の正本](../docs/surveys/biohub-exp027-three-frame-analysis_20260920.md)。train version 4の1epoch・各外側胚64窓の予備比較と、保存重みの過去入力除去・内部validationによる閾値診断を参照する。
- 保存2時点、保存3時点の過去あり、同じ3時点重みの過去なしで、正解親が1位になる総数は両胚とも同じだった。個々の親順位がすべて不変という意味ではない。元のrecall差は正解親が1位を保った接続の確率0.5通過で生じていた。
- 内部validationで教師負例予測数の上限を揃えて閾値を決めても、外側6bbaでは3時点の回収が2時点より5件少なく、教師負例予測数は同じだった。44b6では3時点の回収が多かった。両胚での一貫した改善は未確認で、外側差の動画bootstrap区間は0を含む。
- Assumption: 同じ細胞と予測した対応を明示して動きを入力すれば、未対応の近傍点を混ぜる構造では得られなかった接続判断の改善を得られる可能性がある。本候補を検証する理由であり、有効性の証拠ではない。近傍での混合、時間表現、学習量、教師のどれがexp027の主因かは未確定。attentionで履歴を学習できないと結論しない。
- 1epoch・部分評価、画像重みの来歴、疎い注釈の制限を継承する。exp027の外側分裂親は0件／1件で、分裂への効果は判断できない。exp025の等速カルマン費用の悪化は、履歴を入力して利用法を学習する本候補を棄却する根拠にしない。

### 次の設計・診断へ反映する条件

- まず、対象動画をtracker学習に使わず生成した予測履歴について、有効な長さ・対応の信頼度・注釈で判定可能な誤対応を記録する。元モデル、分割、候補ID、時刻、座標の単位を保存し、短い動画を連続処理して誤履歴の連鎖を診断する。学習側と評価側で履歴を作る手順を揃える。正解履歴へ毎フレーム戻す評価は通常比較に使わない。
- 同じ構造・学習量で履歴あり／なしを学習して比較し、保存済み同一重みで履歴を隠す・入れ替える診断は補助として併記する。後者は学習時と異なる入力になり得るため、独立に学習した対照の代用にしない。
- 各既知接続の候補ID、正解親の順位・確率、最大競合親との差、閾値通過を保存する。親1位率、既知接続recall、active pair内の教師負例予測、分裂回収と有効件数を両胚別に示す。未知端点を含む教師負例数を、真の誤接続数とは呼ばない。
- 固定0.5の結果に加え、閾値が必要なら学習側の内部validationだけで決め、外側へ固定適用する。具体的な選択規則は実装前に確定する。親順位の改善と確率尺度の変化を分け、外側で都合のよい閾値を探さない。履歴長・信頼度・分裂前後でも差を確認する。
- 学習量はepochだけでなく、動画数・有効窓数・更新回数・内部validationの推移も記録する。exp027の1epochを原因と決めつけず、本候補のモデル数、履歴生成用学習、追加passを含めて事前benchmarkする。exp027は元の全件比較が12時間gateを超えたため、既存の縮小条件や安価な実行を自動的に仮定しない。
- 履歴が不確かな場合・開始直後・欠測・分裂後に履歴の寄与を制限できる入力と処理を設計する。具体方式、履歴生成元、内部split、逆方向採点、全graphへの数値的な進行条件は下記の未決事項として維持する。今回のバックログ更新だけで実装方式を確定しない。

- 本候補への具体的な反映: 同じ細胞と予測した順序付き位置列を入力して履歴を集約する範囲を維持する。履歴の長さ・時間差・欠測・信頼度を明示し、未対応点を混ぜるexp027との情報表現の差を検証する。速度の要約特徴だけで本候補を実装したことにはしない。`velocity_features`との共有履歴の生成条件を先に検討し、一方の精度改善を他方の必須開始条件にはしない。

## 入力・予測対象・出力・推論方法

- input: 現在の2時点の固定画像特徴・候補座標に、同じ細胞と予測した過去3〜5時点の相対位置・変位、時間差、欠測mask、対応の信頼度を追加する提案。正解の細胞ID・分裂・軌跡は通常入力に渡さない。
- target / objective: 現在のsource候補から次時点のtarget候補への通常接続・母娘接続。位置予測や平滑化座標の出力へ主目的を変えない。
- output: 対照と同じ隣接ペアの接続logit。提出する検出中心は固定する。
- loss: exp016の接続損失と教師maskを維持する。履歴の有無とloss変更を混ぜず、未知の接続を追加の負例にしない。履歴の補助損失や対照損失は初回に追加しない。
- decode / 推論方法: 小型Transformerなどで履歴を集約して既存の接続予測へ渡し、同じsecondary寄与・整数線形計画（ILP）・修復で処理する提案。履歴を固定の初回予測から作るか逐次更新するかは未決事項。平滑化した位置・速度の提出ではない。
- 処理単位: 1動画内の予測trackの履歴と評価対象の隣接ペア。動画・foldをまたいで状態を継承しない。
- 実装区分: 特定論文の再現ではなく、位置列を直接入力して接続を学ぶ比較案。このリポジトリ内の管理用語では中核の履歴入力を保持する`faithful`を想定する。カルマン費用や一定速度だけの特徴を本案の実装と呼ばない。

## 成功条件と停止条件

- primary指標: 現行公式combined score。adjusted edge Jaccard、division Jaccard、両胚別・履歴条件別の結果も示す。
- 成功条件: 正解を使わない履歴条件が履歴なし対照より両胚の公式combined scoreを改善し、分裂成分が悪化せず、全対象で有効かつ予算内。exp016との差も別報告する。
- 必須guard: 学習時も予測履歴、予測元の学習分割、正解に依存しない信頼度、時刻・動画境界、初期化・短履歴・欠測・分裂後の状態継承を検証する。
- 成功時の次段階: ユーザーへ結果を示し、採否・完了と他の時間情報との統合を判断してもらう。
- 失敗時の停止範囲: 正解履歴だけの改善、誤対応の増幅、単体診断不成立なら全graphへ進まない。公式score未測定と記録し、別方式や検出器学習へ自動で切り替えない。

## リスク

- leakage / validation: 学習履歴は対象動画をtracker学習から除いた予測で作り、外側胚は生成器・集約器・設定の学習から除く。公開画像モデル由来の学習内評価は残り、全工程の独立CVとは呼ばない。
- hidden test: 履歴は推論画像・検出・予測だけで作る。動画開始、空フレーム、短履歴、分裂後でも有効な出力を返す。固定特徴は2時点窓依存で、過去画像だけの因果的予測とは呼ばない。
- runtime / memory: 履歴生成の追加pass・内部学習、track数・保持量を最大例で測る。未取得履歴の費用を除外しない。
- 再現性: 予測元split・重み・規則、候補ID・座標・時刻、信頼度・reset、履歴長・集約器、生成物SHAを保存する。
