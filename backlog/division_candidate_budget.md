- 仮定: Assumption: 画像得点と運動は異なる正解候補を拾い、同じ組数なら距離のみの順位より両娘を残せる。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 固定中心から作る分裂組のうち、予算内でどれを学習・選択へ渡すか。
- この候補の具体的な仮説: 同じ組数制約で画像・運動の候補を併用すると、距離順位のみより既知の母・2娘が両胚で多く残り、同じ分裂得点モデルで最終精度へ移る。
- 仮説が正しい場合に期待する観測: 同じ候補予算の回収率が改善し、最終graphでもcombined scoreが改善する。
- 仮説を棄却する観測: 回収が下がる、候補数増加だけの差、または正解を知れば選べるが実際には選べない。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 分裂組の学習、通常接続との競合解消、分裂時刻と境界。

## 入力・予測対象・出力・推論方法

- input: 固定中心、窓別画像得点、母の予測運動状態。同じ広い幾何候補を対照と共有する。
- target / objective: 正解を推論で使わず、予算内に母・2娘の候補を残す。
- output: 娘の順序に依存しない組の一覧、候補数、各候補を残した理由。
- loss: 候補生成は学習なし。比較中に分裂モデルを再学習しない。
- decode / 推論方法: 画像得点の高い娘と運動予測に合う娘の候補を合わせて組にする。距離順位のみの対照と組数を揃える。Hungarianの未対応娘だけに限定せず、仮接続された娘も対象に残す。
- 処理単位: 隣接時刻の母ごとの候補と窓全体の組数。予算配分の具体方式は未決。
- 実装区分: このリポジトリ内の管理用語では`staged-faithful`。先に候補回収と費用、次に同じ学習済み得点で実選別を測り、前者だけを精度改善としない。

- 新しく作るもの: 実験化後に候補制限、同予算比較、母単位と窓単位の計数。今回は文書だけ。

## 最小の反証可能な検証

- 検証方法: 学習側内部で予算選択の手順を固定し、距離のみと画像＋運動の2条件を同じ組数で比較する。199動画で母と両娘の同時回収、両胚・密度別の損失、時間・メモリを測る。その後、同じ分裂得点・復号で実選別を比較する。
- variant / config / fold / booster数: 主比較2条件、胚を入れ替える外側2方向、booster 0。予算の探索幅は実験契約で限定する。
- control再学習: 候補回収段階はなし。最終選別も保存済み同一モデルを使い、異なる学習データでの再学習を同時変更にしない。
- 想定runtime / resource: Kaggle CPU中心。固定trackerの得点再計算が必要ならGPU費用に含め、週30時間・推論12時間制約を小規模実測から確認する。
- 候補の回収と実選別: 未注釈を誤組とせず、既知組の支持集合と実際に選べた組を分ける。候補回収段階からdivision_tripletsへ入力契約を渡し、学習後の得点を最終選別段階で受け取る。

## 成功条件と停止条件

- primary指標: 初段は同予算の既知分裂組回収率、最終段は現行公式combined scoreとdivision Jaccard。
- 成功条件: 初段で両胚の回収率が対照以上かつ全体で上昇し、最終段でも両胚のcombined scoreが上昇、division成分が悪化せず、予算内で全件有効。
- 必須guard: 候補数を揃える。単純に組数を増やした効果を情報の効果としない。新しい辺の未保存得点を0などで代用しない。
- 成功時の次段階: 候補契約をdivision_tripletsへ渡す判断を求める。学習や提出を自動実行しない。
- 失敗時の停止範囲: 回収減少、無制限な候補増加、実選別へ移らない改善なら後続昇格を止める。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 正解娘の強制追加、未対応娘だけの探索、検出中心の追加、検出閾値変更、外側胚での予算選択は行わない。
- 壁打ちで採らなかった案と理由: exp020/021の広い幾何候補診断は繰り返さない。division_search_gateの母を探索対象にする判定、sparse_motion_graphの通常辺計算削減、contrastive_edge_candidatesの新しい照合特徴学習とは分ける。

## リスク

- leakage / validation: 注釈のある母だけに適した候補順位へ過適合し得る。既知151件の回収は全分裂回収率ではない。
- hidden test: 履歴不足と高密度での配分が必要。推論でGTや合成系譜を使わない。
- runtime / memory: 娘候補数に対して組数は急増する。母ごとの平均だけでなく最大窓の実測を取る。
- 再現性: 同点順位、順序なし組のID、上限配分、固定得点の版を記録する。
