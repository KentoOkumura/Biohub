## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 未対応の過去検出点の画像特徴・座標・時刻を現在の点が参照する効果。時間窓は数時点とし、動画先頭からの全履歴や確定軌跡の入力を対象にしない。
- この候補の具体的な仮説: 固定検出器・固定画像特徴・同じ教師と接続損失の下で、過去集合へのcross-attentionを加えたトラッカーが、保存済みexp016より両胚の既知接続回収を改善し、教師上の負例予測と分裂回収を許容範囲内に保つ。
- 仮説が正しい場合に期待する観測: 同じ候補と評価窓で両胚の改善があり、正解親順位、近接細胞の取り違え、過去候補の利用可能性別の結果が改善の説明と整合する。attentionの可視化だけでは成功としない。
- 仮説を棄却する観測: 確定した構造・学習条件で片方の胚でも事前の進行条件に届かない、または必要な入力・計算費用が成立しない。その構成の結果として扱い、他の時間情報の利用法まで棄却しない。

- 上位仮説の判断に残る検証: 座標だけの接続候補別集約、予測位置履歴、複数時点間の対応学習、固定候補外の見逃し、全graph・公式指標への移行。

## 入力・予測対象・出力・推論方法

- input: exp016と同じ対象隣接2時点の検出点・固定画像特徴に、同じ動画の過去数時点の検出点の固定画像特徴・物理座標・実時刻・有効maskを追加する。初回の窓案は対象2時点に過去3時点を加えた合計5時点。予測接続、正解軌跡、注釈の有無は入力しない。
- target / objective: 対象の隣接2時点間の既知の通常接続・母娘接続。過去点の対応を確定する教師や、非隣接時点間の補助教師を初回に追加しない。
- output: 現在の点の特徴を更新した後、exp016と同じ対象2時点間の接続logitを出す。検出中心・検出候補は変更しない。
- loss: exp016のsource軸softmax後のfocal-weighted binary cross entropy、教師対応、既存の正例行OR正例列mask、分裂重みを維持する。未知を除外する新しいmaskや対照損失を同時に導入しない。この比較境界は、既存教師上の負例がすべて真の負例だと保証する意味ではない。
- decode / 推論方法: 最初は全graphを作らない隣接2時点の単体診断を行う。進行条件とユーザー確認後の全graphでは、exp016のsecondary tracker・候補生成・整数線形計画による復号・graph修復を保持する。既存の正逆方向採点へ過去文脈を与える具体規則は実装前に確定する。
- 処理単位: 文脈は同じ動画の短い時間窓、queryは対象2時点の検出点、key/valueは追加の過去検出点集合。集約は接続候補ごとではなく検出点ごと。教師・出力・単体評価は対象の隣接2時点。
- 実装区分: 設計確定後は、合意した画像特徴・座標・時刻とcross-attentionを省略せず、公式graph評価だけを段階分けする`staged-faithful`を想定する。このリポジトリ内の管理用語であり、現時点で実装済みまたはTrackastra再現という意味ではない。

### 特徴・時刻の契約

- 保存画像特徴は2時点の画像入力窓に依存する。同じframeに由来しても、別の窓で抽出された特徴を同一のframe単独特徴とみなさない。各tokenに元のsample・入力窓・frame・candidate ID・座標・重み版を対応付ける。
- 同じframeが複数のcache窓に現れる場合の採用元、検出候補の違い、重複の扱いを設計時に決める。時刻や候補IDだけを根拠に異なる特徴・候補を無条件に連結しない。
- 過去候補の範囲は設計時に確定する。計算費用を理由に、全候補の参照を無断で距離上位候補や一つの予測履歴へ変更しない。
- 動画開始、空の過去frame、padding、履歴不足を明示する。過去なし時に現在2時点だけで処理する経路を持たせるが、その構造・初期化・学習後の出力保証は未決事項とする。
- 追加する検出点は対象ペア以前の時点から取得する。画像特徴の抽出窓と既存の正逆推論が持つ時間文脈は別に記録し、厳密なオンライン因果予測とは主張しない。

- variant / config / fold / booster数: 初回は1構成・外側2fold・モデル2個を基本案とする。予測履歴生成モデルは不要、boosterは対象外。追加の窓長・seed・同構造対照を自動で増やさない。学習epoch、追加部分と本体の初期化・学習設定は未決事項であり、測定前に契約へ固定する。
- control再学習: 保存済みexp016を主対照として使用し、初回から対照の再学習を必須にしない。本体構造も変わるため、この比較だけで差の原因を過去情報だけに断定しない。履歴なしや時刻を入れ替えた同じ重みの診断を補助として提案するが、独立に学習した対照の代わりとは扱わず、評価結果を見た救済調整に使わない。

## 成功条件と停止条件

- primary指標: 初段は両胚別の既知接続recall。全graph段階はexp016と同じ公式combined scoreとその成分。単体指標を公式scoreの代わりにしない。
- 成功条件: 設計時の推奨は、exp035と同じく両胚で保存済みexp016より既知接続recallが厳密に改善し、active pair内の教師負例予測の増加が各胚5%以内、分裂親回収数が各胚で非減少であること。比較閾値は同じ固定0.5を基本とし、判定条件を実行前に確定する。最終的な公式精度改善は、全graphで両胚の公式scoreが改善して初めて主張する。
- 必須guard: 正解親1位率、教師上の負例予測数、分裂親回収数と有効分母、開始窓・過去欠落・密集度別の件数と結果、候補・教師・時刻対応の一致、非有限値なし。疎い注釈に基づく負例予測を真の誤接続全数と呼ばない。分裂の有効分母がない場合は判定不能とし、非悪化の証拠にしない。
- 成功時の次段階: 単体結果と費用を提示し、ユーザーに全graph・公式評価へ進むか確認する。採否・完了・submissionはそれぞれ別の明示判断とする。
- 失敗時の停止範囲: 片方でも事前条件に届かなければ全graphへ自動進行せず、公式score未計測として報告する。特徴対応不整合、実行予算超過、非有限値では停止する。履歴長・候補数・fold・学習量を無断で削って実施済みとしない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 正解軌跡・確定した予測接続の入力、過去の画像特徴を省いた座標だけの代替、接続候補別delta logitへの無断変更、画像encoder更新、全履歴化、外側評価での窓長・閾値・構造・epoch選択、未知の教師を密な正解とみなす評価。OOFは学習に使っていない対象への予測を指すが、公開画像重み由来の条件付き評価の制約は残る。
- 壁打ちで採らなかった案と理由: 動画先頭からの全履歴はユーザーが不要とした。座標attentionの複数時点化は入力と集約単位が違う別候補であり、本案の代わりにしない。Trackastraの窓内対応教師・専用損失の導入、過去候補欠落を再現する学習は比較の意味が変わるため初回へ混ぜない。座標版の成功を必須にすると別の情報・構造まで同じ結論で扱うことになるため、その依存は置かない。

## リスク

- leakage / validation: 胚分割と学習側内部の選択を維持する。GTから過去候補を選ばず、注釈の有無も特徴にしない。公開画像モデルと初期trackerの学習来歴による条件付き評価であり、独立CVとは呼ばない。
- hidden test: 動画開始・欠測・検出数の変動・密集した細胞に対応する。全候補を参照しても、真の前身の選択や現在の正解接続回収が保証されるわけではない。対象候補に存在しない接続は本案だけでは回収できない。
- runtime / memory: 現在の検出点数と過去検出点総数の積に比例するattentionが増える。保存特徴が小さくても学習時の中間値が大きくなり得る。ピークメモリ削減と演算量削減を区別する。
- 再現性: 採用窓・candidate ID・座標・mask・相対時刻、乱数、初期化、checkpoint選択、モデル・予測SHAを記録する。候補数でattention重みが変わる場合や、過去なし入力が学習分布外になる場合も診断し、重みの解釈だけで効果を断定しない。
