## 入力・予測対象・出力・推論方法

- input: 同じ画像窓・固定検出ID、補正前後の座標、それぞれの位置で三線形補間した画像特徴、GEFFの既知中心・接続・分裂。
- target / objective: 新しいモデルは学習せず、同一入力の公開trackerとその後段に対する補正の作用を評価する。
- output: pair別・胚別の順位、既知接続回収、両娘の候補内回収と実選択、判定可能な誤接続、後処理前後の残存件数、費用と再利用可能な対照。
- loss: なし。
- decode / 推論方法: exp043の公開tracker、融合、整数線形計画（ILP）、再接続、修復を両条件で揃える。補正なし側も補間方法を揃え、旧exp013全体へ置き換えない。
- 処理単位: 最初は共通の隣接2-frame。pairでは見えない再接続・修復の影響は、共通動画のgraph評価を別段階として扱う。
- 実装区分: 既存推論の条件を揃える診断。モデル改善手法の再現ではなく、測っていない全graphの効果を単体指標で代用しない。

## 最小の反証可能な検証

- 検証方法: 補正なし／ありの2条件を共通pairで比較する。正解順位、両娘が候補に揃う数、採点・選択で落ちる数を先に取得し、後段での消失が疑われる共通動画を全graph診断へ進める。
- variant / config / fold / booster数: 初段は2条件、新規モデル0、両胚別に集計、booster数0。対象範囲とheadの評価来歴は未決事項で固定する。座標だけ・特徴だけの追加分解を自動で増やさない。
- control再学習: 採用headを固定する条件付き診断なら不要。headの学習外評価を主張する場合の分割別再生成は別途契約に明記する。
- 想定runtime / resource: Kaggleのみ、週45 GPU時間以内・課金なし・1回12時間以内。特徴再抽出、pair採点、graph処理を別計上する。基準作成だけの別expを必須にせず、最初の改善実験内で取得し共有する。

## 成功条件と停止条件

- primary指標: 同一pairの既知接続、判定可能な誤接続、両娘回収、段階別の消失件数。公式scoreはKaggle上の全graphと公式評価器を実行した範囲だけ報告する。
- 成功条件: 胚別に有効母数と対応条件を揃え、どの段階の変化かを追跡できる対照が得られる。診断自体には精度向上を要求しない。
- 必須guard: 未注釈を真の負例にしない。既存教師maskで負例とされた予測数は、注釈で保証された誤接続と区別する。既知1娘だけから非分裂を断定しない。
- 成功時の次段階: 候補内の正解2娘が採点で落ちれば共有得点、局所移動で候補を分けられれば近傍参照、複数graphに補完性があれば候補選択、正解履歴と予測履歴の差が大きければ誤履歴学習を検討する。5案を機械的に順番実行しない。
- 失敗時の停止範囲: 特徴再取得・ID・教師対応の等価性が崩れた比較から結論を出さない。全動画のgraphを無条件で先行せず、pairで測れない問いと費用を記録して進行条件を確定する。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 旧exp016数値との直接比較、未知候補の負例化、最終headの学習動画を学習外予測と呼ぶこと、診断途中でhead容量・epoch・接続閾値を調整すること。
- 壁打ちで採らなかった案と理由: 座標補正の成功だけからattentionの失敗原因を断定しない。通常使わない座標・特徴の組合せを診断しても採用構成としない。追加情報の有効性、学習内の適合、別動画での改善を混同しない。

## リスク

- leakage / validation: 採用headは20動画の教師に触れている。固定公開モデルとheadの来歴を含む条件付き診断と、headも学習外にする評価を分ける。結果を見て外側で次の設定を探索しない。
- hidden test: 実推論は画像と予測だけを使う。注釈は診断だけに用い、正解を使った上限を推論精度としない。
- runtime / memory: 中心と6近傍の224次元だけでは補正位置の補間に必要な頂点を再現できるとは限らない。再抽出費用を含める。
- 再現性: 入力窓・検出ID・特徴の抽出位置・教師対応・重み・後処理の版とSHAを記録する。
