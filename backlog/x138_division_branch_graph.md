## 入力・予測対象・出力・推論方法

以下の実装区分は[用語集](../docs/glossary.md)の、このリポジトリ内の管理用語に従う。

- input: exp043で固定した検出・補正座標・画像encoder・trackerから得た点特徴と接続確率。中央の母と娘は時刻 `t,t+1`、文脈は `t-1` の母の直前候補と `t+2` の各娘の直後候補、計4時点。接続候補はexp050と同じく元の `p > 0.48` を保持し、保存済み `p > 0.10` の追加分は娘ごとに確率上位3親までとする。元に存在しない得点を0点の実測値と混同しない。
- target / objective: 7 µm以内の時刻別一対一対応でGEFFの既知接続を候補IDへ写し、確定できる継続と2娘分裂を学ぶ。未知の第2娘や後続欠落を非分裂・死亡の教師にしない。動画内で分裂時刻と前後の接続を同時に選ぶ。
- output: 母ごとの空・1娘・2娘の共有接続得点、2娘の前後接続に依存する得点補正、選択されたnodeと隣接時刻edge・分裂時刻。2娘の順序は得点へ影響させない。
- 採点器: exp050の2回のmessage passing・幅128の共有edge得点と2娘費用を、両条件で同じseedから新規学習する。2娘の前後組には、固定点特徴、元接続確率、物理変位、時間端と候補不存在のmaskを入力する幅128のMLPを追加する。娘2本は特徴の和と絶対差で表す。補正の最終層は0初期化し、`tanh`で-1～1に制限する。前後情報遮断対照も同じ構造・候補・学習手順を使い、前後の特徴・確率・変位・maskだけを0にする。中央の母娘情報は両条件で共通にする。
- loss: exp050と同じ、許容集合を周辺化した部分教師損失、既知2娘と自身の1娘・空集合を比べる損失、既知親と競合親を比べる損失を、該当例ごとに別平均して等重みで足す。比較marginは0.05。前後組では、中央の既知接続に加え、注釈で確定した直前・直後接続と矛盾しない組だけを許容する。各中央2娘候補の前後組は同じ事前重みで周辺化し、全組数で正規化して組数だけで2娘が有利にならないようにする。既知2娘が候補外、または許容組が空の項は除外し、件数と理由を残す。未知辺を真の負例にしない。
- 候補と処理単位: 中央の空・1娘・2娘集合は拡張接続候補から全列挙する。文脈補正を付ける2娘集合だけ、母ごとの元得点上位3娘の組に制限する。母への直前接続と各娘の直後接続は、元確率上位2の単一接続と「それ以外」の排他的な3分類にする。同点は候補IDで決める。「それ以外」は接続なし、上位2以外、娘自身の次時点の2娘を含み、分裂禁止の意味を持たない。各中央2娘集合の文脈は最大27組とする。対象外の中央2娘集合も共有得点で合法に選べる経路を残し、対象外率を記録する。
- decode / 推論方法: exp050の母ごとの空・1娘・2娘集合変数、node・出現・消失制約を使う動画全体の整数線形計画（ILP）に、前後組の得点補正変数を加える。選ばれた2娘集合では、その母の実際の入辺と各娘の実際の出辺の分類に対応する前後組を厳密に1つ選び、補正を1回だけ加える。中央edge得点を二重計上しない。出現費用0、消失費用2で、学習した2娘費用に固定分裂費用1.2を重ねない。娘の親は最大1、母の娘は最大2、edgeは隣接時刻のみ。全動画の制約を共同で解くので、4時点窓の境界へ既存graphの接続を固定しない。分裂時刻は選択された2娘集合の時刻とし、隣接窓の候補も同じILPで競合させる。両条件の後処理を揃える比較原則は維持するが、共同選択を再接続・欠落補完・分裂修復へどう渡すかは下記の未決事項を解消して固定する。
- 動画端・観測不足: `t-1` または `t+2` が存在しない場合はその時間端maskを立て、対応する分類を「それ以外」にする。画像境界近傍は補正後座標から画像境界までの最短物理距離7 µm以内として層別し、真の視野外移動と断定しない。候補はあるが採用辺がない場合と、候補自体がない場合を別に記録する。視野端や欠落で後続がない可能性、娘間距離、対称性を硬い分裂判定にしない。
- 実装区分: 固定モデルの後段を変更する新規案。特定文献の忠実再現ではない。2時点の得点だけを再学習する案や、選択済み軌跡を後から特徴化する案に置換しない。

## 最小の反証可能な検証

- 動画分割: exp050と同じ `SHA256(42:動画名)` の胚内昇順で、各胚21～30位の計20動画を外側の全graph公式評価に固定する。両胚の21～30位を新規学習から除外する。各方向で一方の胚を学習し他方を評価し、学習側胚31～35位の5動画を動作・費用診断へ固定して学習から除外する。残りはその方向の学習に使う。exp049で分析済みの各胚11～20位や、exp050も使う21～30位を研究全体で未使用の評価集合とは呼ばない。方式・費用・checkpointを外側結果から選び直さない。公開画像モデルと座標headの来歴がある条件付き評価であり、独立CVとは呼ばない。
- 検証方法: 正解を使わず中央候補と前後組を生成し、既知2娘が中央候補にある件数、文脈補正対象にある件数、同じ合法graphに入る件数を分ける。母・娘・直前/直後候補の欠損、時間端・画像境界近傍・注釈不足も分ける。pilotでは特徴schema、教師対応、有限loss、前後組の排他性と制約、補正0のILPが元の集合ILPと目的値・辺集合で一致することを確認する。両学習条件を同じ候補・後処理で外側20動画の全graphと[同じ主催者評価器](https://github.com/royerlab/kaggle-cell-tracking-competition/blob/main/metrics.md)まで実行する。ILP後・再接続後・最終graphで既知2娘と通常edgeを追う。局所順位を公式scoreの代用にしない。
- variant / config / fold / booster数: 前後情報遮断対照と4時点条件を各1設定、胚入替2方向で計4モデル。両条件とも幅128、2回のmessage passingと幅128の得点補正MLP、dropout 0.1、AdamW、学習率0.0001、weight decay 0.01、gradient norm上限1、window batch 1、5 epoch、seed `42 + fold`、最終epochを固定する。損失3項は等重み、該当教師がない項は0と件数を記録する。既存exp043・exp050の再学習0、booster0。
- 全graph進行条件: pilotで両胚の入力・対照同一性・部分教師・前後組制約が通り、各学習方向に情報のある既知2娘教師が1件以上あり、lossが有限で、1動画・1epochの実測から週45 GPU時間、Notebook1回12時間、動画ILP1200秒以内を見込めること。局所精度を進行gateにせず、技術・費用条件を満たせば両胚の全graph公式評価まで行う。未達なら公式score未計測と記録して停止する。
- control再学習: 固定画像モデル・座標head・元trackerは再学習しない。中央2時点対照と4時点条件だけ上記の同一設定・初期seedで学習する。
- 想定runtime / resource: 候補生成とILPはKaggle CPU、4モデルの採点器学習と足りない固定特徴の取得はKaggle GPU。cache取込・結合・目的値照合の時間も計上する。[現在の学習方針](KAGGLE_DIRECTION.md#今後の学習方針)のKaggleのみ・週45 GPU時間以内・課金なし・1回12時間以内を守る。実行秒数は未測定。

## 成功条件と停止条件

- primary指標: 同条件対照との差として両胚別の全graph公式combined score、adjusted edge Jaccard、division Jaccard。exp043との同動画比較も示すが、主比較の差と混同しない。
- 成功条件: 前後情報遮断対照より両胚でcombined scoreが上回り、adjusted edge Jaccardとdivision Jaccardがいずれの胚でも低下しない。division Jaccardは少なくとも一方の胚で上回り、正解を見ない選択で増えた既知2娘が最終graphまで残る。
- 必須guard: 母・娘・直前/直後候補の欠損、正解2娘の候補・文脈・合法解の上限、採点された前後組の選択率、通常edgeと分裂のTP/FP/FN、動画別の最悪悪化、段階別消失、node数、solver・メモリ・時間を記録する。正解固定解は診断のみに使う。
- 追加する診断: 選択した母・2娘・前後辺をIDで追い、再接続・欠落補完・分裂修復・最終の各段階で保持・破壊・再生成を分ける。固定IDの回収数と、公式の位置対応後の正解・誤接続・見逃し件数を別表にする。分裂は母数と個別事象も示し、教師1件以上という技術条件を十分な精度証拠とみなさない。点数は元候補の保持・除去と後処理での新規追加に分け、公式のnode数調整まで確認する。
- 成功時の次段階: 上の技術・費用条件を満たした実験で公式全graph評価へ進む。採否・完了・competition submissionは評価後のユーザー判断に従う。
- 失敗時の停止範囲: 候補・文脈上限が不足する、前後情報で選択差が残らない、通常edgeが悪化する、片胚で分裂が悪化する場合は本方式の採用を推奨しない。入力不一致、非有限loss、違法graph、solver非最適、peak memory 80%以上、動画ILP1200秒超、Notebook12時間超過見込み、GPU残枠不足なら実行を止める。hidden testの入力異常・時間切れ時は合法なexp043元graphへ戻し、その件数を残す。再検討条件は後続候補または観測支持が増えた場合。

## リスク

- leakage / validation: 画像モデルと座標headの学習来歴を含む条件付き比較。exp050の外側集合を再利用するので研究全体で新規のholdoutとは主張しない。設定選択は学習側内部に限定し、未知注釈を負例化しない。
- hidden test: 全test動画の画像と固定予測だけを使い、GEFF・正解細胞数・公開testと同じ動画数を使わない。可変動画数、短い動画、時間端・画像境界近傍・密度を変えたラベル非参照のsmokeを行う。隣接時刻edge、娘の親高々1・母の娘高々2を維持する。
- runtime / memory: 文脈対象の2娘集合あたり最大27の補正変数と動画全体の制約でCPU費用が増える。候補数・変数数・制約数・peak memory・solver終了状態・fallbackを動画別に記録する。固定特徴が不足すれば再抽出費用を含める。
- exp051からの費用上の注意: 動画ILPの時間切れと全体12時間枠を別に測る。固定DeepCenterによる後処理にもモデル推論があり、CPUで行う場合はその時間を含める。GPU追加でCPUのILP時間切れが解決するとは仮定しない。本候補の1200秒・最適解必須という既定条件を、exp051の3600秒・暫定解許可へ自動変更しない。
