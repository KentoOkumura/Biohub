## 入力・予測対象・出力・推論方法

実装区分は`docs/glossary.md`に定義したこのリポジトリ内の管理用ラベルを使う。処理内容と省略点を先に具体的に記録する。

- input: 母の短い過去、候補2娘と各娘の後続の固定検出・座標・tracker得点・画像特徴、観測可否mask。
- target / objective: 部分注釈で確定できる継続・分裂の構造を識別し、分裂時刻と前後の競合接続を同時に選ぶ。
- output: 通常継続と分裂の局所graph候補の得点、および選択した分裂時刻・母・2娘・前後の接続。
- loss: 既知接続に整合する複数候補を許す部分教師損失、または確定競合に対する順位損失を候補とする。具体式・集約は未決。
- decode / 推論方法: 母の過去・2娘の後続を同じ局所整数線形計画（ILP）で選ぶ。現在のgraphから将来を1本へ固定せず代替接続を残す。動画端・視野外・欠落は観測可否として扱い、娘の分離や対称性を硬い制約にしない。
- 処理単位: 分裂候補を含む短い時間窓と、親子を共有する局所候補集合。窓長・境界は未決。
- 実装区分: 固定モデルの後段を変更する新規案。特定文献の忠実再現ではない。上記の入出力・比較を実験契約へ移し、管理用ラベルは[用語集](../docs/glossary.md)に従う。

## 最小の反証可能な検証

- 検証方法: 教師非参照で分裂と継続の候補を生成し、正解2娘が同一合法graphに含まれる率と、後続特徴あり/なしでの順位を調べる。 母・娘・孫の各候補欠損、動画端・視野外・部分観測を分け、2娘の同時実現率を測る。 学習側内部で方式と費用を固定し、反対胚へ適用する両方向の条件付き評価。候補内診断→Kaggleで全動画graphと同じ公式評価器→ラベル非参照の可変動画数・密度・境界・offline推論smoke。既に詳細を分析した20動画を未使用評価と呼ばず、設定選択にも使わない。
- variant / config / fold / booster数: 同じ候補集合で隣接2時点の選択と前後接続の同時選択を比較する案。採点器を学ぶ場合は2fold。総モデル数・学習量・特徴なし対照は未決、booster数0。
- control再学習: 画像モデルとtrackerは固定。局所採点器の対照を同じ特徴・学習量で揃える方式は実装前に確定する。
- 想定runtime / resource: 候補生成とILPはCPU。固定特徴が不足する時間窓のみ抽出費用、新しい局所採点器を学習する場合は小規模実測後に見積もる。秒数未測定。 [現在の学習方針](KAGGLE_DIRECTION.md#今後の学習方針)のKaggleのみ・週45 GPU時間以内・課金なし・1回12時間以内を引き継ぐ。

## 成功条件と停止条件

- primary指標: 同条件対照との差として両胚の全graph公式combined score、adjusted edge Jaccardとdivision Jaccard。局所指標を公式評価の代用にしない。
- 成功条件: 正解なしの実選択で既知2娘の同時回収が改善し、両胚の全graph公式combined scoreが向上、通常接続を損なわずdivision Jaccardが改善または維持される。
- 必須guard: 母・娘・後続点の候補欠損、両娘が同じ合法graphに入る率、窓端・視野外・観測不足、通常接続の破壊を分ける。正解固定解は診断のみに使う。
- 成功時の次段階: 事前に決める局所進行条件と費用条件を満たしてからKaggleの全graph公式評価へ進む。実験化・採否・完了・submissionは各ユーザー判断に従う。
- 失敗時の停止範囲: 合法候補の上限が増えない、後続情報が順位に寄与しない、通常edge悪化または片胚の分裂損失が残る。 局所条件未達なら全graph拡大を止める。再検討条件: 後続候補または観測支持が増え、両娘を同時に識別できる場合。

## リスク

- leakage / validation: 画像モデルと座標headの学習来歴を含む条件付き比較で、独立CVとは呼ばない。既に分析した20動画を未使用評価へ戻さず、方式・閾値・checkpointの選択は学習側内部に限定する。未知注釈を負例化しない。
- hidden test: 全test動画の画像と固定予測だけを使い、GEFF・正解細胞数・公開testと同じ動画数を使わない。隣接時点edge、娘の親高々1・母の娘高々2。未知入力/時間上限時は合法な元graphへ戻す。保存cacheが必要項目を欠けば取得費用を見積もり、勝手に代用しない。
- runtime / memory: 分岐候補の組合せと窓境界でCPU費用が増える。固定特徴の未取得窓は抽出費用を追加し、候補数・最大成分・メモリ・時間切れ時の元graphへの復帰を測る。
- 再現性: 入力動画・窓・候補ID・座標・得点と存在mask・重み・source・config・選択結果の版とSHAを保存する。
