## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 固定候補と既知接続教師を保ち、接続の出力単位を娘から母へ変える効果。

- 仮説が正しい場合に期待する観測: 同じ胚・cache・評価対象の2フレームで、exp028より観測可能な誤接続が減り、exp016の早期条件も両胚で満たす。全graphへ進んだ場合は公式の接続・分裂成分も比較する。
- 仮説を棄却する観測: 母ごとの選択で誤接続が減らない、既知edgeや分裂回収を犠牲にする、または構造制約と計算予算を満たせない。

- 上位仮説の判断に残る検証: 疎い教師からの対応なし学習、通常継続と分裂の識別、exp028以外の出力方式、全graphの公式評価。

## 入力・予測対象・出力・推論方法

実装区分はこのリポジトリ内の管理用ラベルとして[用語集](../docs/glossary.md)に従う。特定論文の再現は主張しない。

- input: exp028と同じ固定検出候補ID・位置・検出得点・固定画像特徴を隣接2フレームから使う。GTの有無を推論入力にしない。
- target / objective: 主催者GEFFで確認された母娘edgeと矛盾しない娘集合を母ごとに選ぶ。注釈が0本または1本の母を、真の娘数0人または1人の教師と断定しない。
- output: 母候補ごとに空集合、娘候補1人の集合、または異なる娘候補2人の順序に依存しない集合。単なる0・1・2人の個数分類ではなく娘IDを出力する。
- loss: 既知edgeを正例とし、未記録edgeを一律負例にしない部分注釈対応の損失が必要。許容集合上の周辺化、確定した競合のみの負例化などの具体方式は未決事項に残す。
- decode / 推論方法: 母の出次数は最大2、娘の入次数は最大1、時刻は前向きとする。娘を複数の母が要求した場合の集合全体の選択方法、対応なしの校正、ILPの使用は未決。全graphではexp028と同じ固定graph repairだけを適用し、適用前後を分けて記録する比較案とする。
- 処理単位: exp028と同じ隣接2フレームを先に評価し、早期条件を満たした場合だけ全graphへ進む。
- 実装区分: 特定論文の再現ではない出力表現の変更。実験化時に用語集上の区分、具体的なモデルと省略点を記録する。

## 親実験からの差分

- 変更するもの: 娘ごとの母・対応なし選択を、母ごとの娘集合選択へ変える。部分注釈に合う損失と、母同士の娘競合を解く復号を設計する。
- 固定するもの: 公開検出器・画像特徴抽出器、exp015 cache、候補座標、GEFF対応、胚を入れ替える2方向の分割、2フレーム評価対象、対照のexp016とexp028、全graph時の固定graph repair。secondary trackerと順逆融合は接続選択に使わない比較案とする。
- 再利用するコード / config / 生成物: exp028の教師対応・cache検査・胚別診断と保存済みモデル・manifest、exp016の保存済み対照。exp028の損失と娘ごとの復号は新方式へそのまま流用しない。
- 新しく作るもの: 母ごとの集合候補・モデル出力、部分注釈の教師mask・損失、母間競合処理、候補回収・誤接続・分裂・構造の診断。

## 最小の反証可能な検証

- 検証方法: まず既知edgeに対する母別の教師状態、既知2娘の候補回収、候補集合数、確定できる負例を保存済みcacheで監査する。方式確定後、Kaggleで同じ2foldを学習し、exp028と保存済みexp016を同じ胚・2フレーム・教師対象で比較する。必要なexp028候補別予測は保存済み重みから再生成する。
- variant / config / fold / booster数: 出力方式の一変更を主比較にし、胚を入れ替える2fold。モデル容量、集合候補上限、閾値は学習側の実測と内部検証で決め、外側胚で選び直さない。booster数は0。
- control再学習: exp016とexp028の保存済み対照を再学習しない。入力・評価対象が一致しない場合だけ対照の再推論を行い、差を記録する。
- 想定runtime / resource: Kaggle Notebookのみ、週30 GPU時間以内・全graph推論12時間以内。娘2人の組が候補数に対して二次に増えるため、小規模benchmarkで最大windowの候補数、GPU memory、学習・推論時間を測る。費用と上限は未実測。

## 成功条件と停止条件

- primary指標: 早期診断では胚別の既知edge recall、観測可能な誤接続率、既知分裂母の回収、構造違反。全graphでは現行公式のcombined scoreと接続・分裂成分。
- 成功条件: 両胚で構造違反0、既知edge recallのexp016対照からの低下が1 percentage point以下、観測可能な誤接続率がexp016以下、既知分裂母の回収がexp016以上。exp028との差も同じ対象で報告する。全graphへ進んだ場合は両胚で公式指標を比較し、効果と費用を示す。
- 必須guard: 未注釈の母や第2娘を負例・終了教師にしない。同じ娘を複数母に割り当てない。外側胚でモデル・閾値・候補上限を選ばず、同じcache・教師・評価対象と生成物SHAを確認する。
- 成功時の次段階: 早期条件成立後だけ全graphの公式評価を検討し、実験の採否・完了はユーザー判断に委ねる。Kaggle submissionは別の明示依頼を要する。
- 失敗時の停止範囲: 安全な教師と候補集合を構成できない場合は学習前に停止する。2フレーム条件不成立なら全graphを自動開始しない。この候補の失敗で関連仮説や他候補を閉じない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 0・1・2人の個数だけを出す分類器、単独edge得点を足しただけの集合選択、未記録edgeを全て負例にする学習、外側胚での閾値救済、候補点のGTによる追加を本候補の実装と呼ばない。
- 壁打ちで採らなかった案と理由: exp028の娘ごとの母選択は対照として残す。[division_triplets](division_triplets.md)は分裂組だけの採点と合成事前学習の有無、[division_state_model](division_state_model.md)は継続・分裂・観測不能という状態の選択、[division_local_ilp](division_local_ilp.md)は既存得点を使う局所再割当であり、通常接続を含めて母が娘IDの集合を直接出す本候補とは分ける。secondary tracker・順逆融合の再導入は出力方式と同時に比較しない。

## リスク

- leakage / validation: 公開checkpointの学習来歴を引き継ぐため、胚を分けた比較を独立CVとは呼ばない。GEFFは疎く、観測可能な誤接続率は全graphの真の誤接続率ではない。
- hidden test: 推論でGEFFや注釈有無を参照しない。窓をまたいだ候補ID・時刻の整合とgraph repair前後を確認する。
- runtime / memory: 母ごとの娘2人の組と母間競合解決の費用が未実測。候補上限で正解組を落とす割合を同時に測る。
- 再現性: cache・GT対応・fold・モデル・閾値・候補制限・復号・Kaggle kernel versionとSHAを実験化時に固定する。
