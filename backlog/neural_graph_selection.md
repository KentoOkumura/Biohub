## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 固定候補内の競合をモデルが扱い、通常接続・分裂の選択を直接出力する効果。
- この候補の具体的な仮説: 候補グラフに沿った情報交換と制約を守る出力により、同じ候補のILP選択より誤接続を減らし、両胚の継続・分裂を保持できる。
- 仮説が正しい場合に期待する観測: 候補回収率を変えず、制約を満たす出力で既知接続の選択が改善し、後処理後も効果が残る。
- 仮説を棄却する観測: exp028同様に誤接続が増加、分裂が消失、順序依存、制約処理で利得消失、計算上限超過。
- この候補だけで上位仮説を判断できるか: いいえ。
- 上位仮説の判断に残る検証: 得点と構造損失、対応なし、候補回収、後段修正は別比較。

## 入力・予測対象・出力・推論方法

- input: exp043の固定検出点・補正座標・元窓の画像特徴・検出得点、同じ接続候補、候補間の競合、必要な既存接続得点。未評価得点はmaskを持ち、低確率0と区別する。
- target / objective: 主催者の既知接続・分裂に整合し、子の親最大1、母の子最大2、時間方向を守るgraphを直接選ぶ。未知辺は完全な負例にしない。
- output: 接続の選択と分裂組の選択、または同じgraphを作る逐次割当。
- loss: 既知辺・既知分裂と矛盾を用いた部分教師損失。既知1娘を第2娘なしと教えず、注釈と両立する複数解を許す。出力方式に対応する損失、分裂の寄与、対応なしの教師は未決事項。
- decode / 推論方法: 候補グラフ上の反復情報交換後に制約を満たす解へ投影する方式、または選択済みの割当をmaskする逐次方式を設計時に選ぶ。最終接続の主選択を既存ILPへ戻すだけの実装はshared_edge_graph_learningの比較とし、本候補の置換とはしない。
- 処理単位: 最初は隣接2-frameの競合成分。独立でない成分を便宜的に分割せず、動画への統合と境界を設計する。長窓化は同時投入しない。
- 実装区分: 競合を扱う直接選択という提案の中核を保つ。引用論文の通常物体追跡をBiohubの分裂・疎注釈へ適用する設計であり、論文の忠実再現とは呼ばない。具体方式と省略点を確定後、リポジトリ内の管理ラベルを記録する。

- 固定するもの: exp043の検出器・画像encoder・座標補正head、候補点・抽出条件、比較中の接続候補集合、教師対応と胚分割。後処理の変更は初回に併用しない。
- 再利用するコード / config / 生成物: exp043の入力と全後処理、exp028/029の教師監査・2-frame診断の考え方。旧入力のモデル数値を新入力対照にしない。
- 新しく作るもの: 直接選択モデル、部分教師、合法性処理、同条件対照、候補から最終graphまでの接続ID追跡。

## 最小の反証可能な検証

- 検証方法: 同じ候補の小競合成分で、教師整合解が存在するかを先に確認。次に学習側の小例へ適合できるか、入力順変更で出力が変わるか、制約処理前後の選択を調べる。
- variant / config / fold / booster数: 直接選択1構成と同候補のILP対照を基本とする。費用学習と選択変更の寄与を分けるために必要な追加対照は方式確定後に定める。両胚を入れ替える2方向、booster数0。
- control再学習: 同条件の保存済み対照がなければ下流部分のみ学習。同じ改善実験内で対照と必要cacheを取得する。

## 成功条件と停止条件

- primary指標: 公式combined scoreと接続・分裂成分。初段は既知edge recall、観測可能誤接続、分裂、構造違反。
- 成功条件: 制約違反0で同候補対照より両胚の接続が改善し、観測可能誤接続・分裂の事前条件を満たす。最終的に全graphの公式指標へ改善が残ること。
- 必須guard: 候補回収と選択を分離し、制約投影後を評価する。公開画像重みと座標headの学習来歴を明示した条件付き比較とする。
- 成功時の次段階: 事前に定めた単体指標と費用条件を満たしてから全graphへ進む。採否・完了・submissionはユーザー判断。
- 失敗時の停止範囲: 小例を学べない、誤接続が増える、順序依存が大きい、予算内に収まらない場合は全graphへ進めない。外側胚で救済調整しない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: ILP出力を生物学的正解にした模倣学習、未知辺の一律負例化、画像側再学習、単なるILP費用倍率探索、既存ILPが全選択を行う構成を置換と呼ぶこと。
- 壁打ちで採らなかった案と理由: [shared_edge_graph_learning](../experiments/exp050_shared_edge_graph_learning/requirements.md)はILPを保持する得点学習。[final_graph_edit](final_graph_edit.md)は完成graphの局所修正。候補生成の変更は[x138_edge_candidates](x138_edge_candidates.md)へ分離する。

## リスク

- leakage / validation: 2胚の部分注釈で構造全体の正解は観測できない。画像重みの学習内評価はtracker分割だけでは解消しない。
- hidden test: 未知の密度・細胞数・窓境界でも親子数を守り、GTを参照しない。
- runtime / memory: 全結合・多数反復・beam幅で費用増加。対象と上限到達時の処理を設計する。
- 再現性: 入力・候補・教師・重み・推論順・同点処理・版・SHAを記録する。
