## 入力・予測対象・出力・推論方法

- input: 固定cacheの候補点特徴・周辺候補・予測履歴。画像特徴と残す中心の座標は変えず、保持された対応が分かる候補欠落・文脈maskを作る。
- target / objective: 不完全な候補文脈でも正しい親子対応を保持する。消した未注釈候補を偽細胞とみなさず、教師を確認できる対応だけで比較する。
- output: 既存の検出点に対する接続スコアと対照学習用特徴。欠測中心の新規生成や直接のskip edge出力は含めない。
- loss: 基本trackerの接続損失と対照損失を引き継ぐ。合成文脈で事前学習して実予測で追加学習する。2つの文脈view間の対照項を別途追加するかは未決事項とし、自動で増やさない。
- decode / 推論方法: 推論には未加工の実予測だけを使い、基準と同じ接続候補・グラフ選択・修復を使う。
- 処理単位: 1動画内の隣接時刻の候補点・接続と、明記した範囲の履歴。特徴の元の時間窓を保持し、評価の分割は胚単位にする。
- 実装区分: 画像encoderの対照学習を省き固定特徴へ転用する案であり、ASCENT全体の再現ではない。[用語集](../docs/glossary.md)のこのリポジトリ内の管理用ラベルでは、原法に対して`proxy`とする。ユーザー承認後も本候補の中核処理を閾値調整だけへ縮小しない。

## 最小の反証可能な検証

- 検証方法: 学習側のみで欠落の頻度・連続長・条件依存を測る。その分布で文脈を壊して学習後、学習側の分割外tracker予測で調整し、未加工の外側胚の実予測で評価する。実予測のみ／合成後に実予測を同じ総学習量で比較し、同じ合成入力で対照損失なし／ありも切り分ける。
- variant / config / fold / booster数: 基本比較は実予測のみ／合成後に実予測。対照損失の有無の比較は同じ入力・総学習量に揃える。合成のみは移行失敗の診断用。胚2方向・booster数0。
- control再学習: 同じ構成・教師・総学習量で下流trackerを比較する。実予測は学習側の内部でtrackerの学習から除いた動画から作るが、公開画像モデルの学習から独立した予測とは呼ばない。
- 想定runtime / resource: Kaggle Notebookのみ・GPU週45時間以内・課金なし。初期案は既存cacheを再利用して画像特徴を再抽出しない。CPUで可能な集計を先行し、追加の下流学習、最大候補数での評価・graph処理、hidden推論を別計上する。所要時間は未実測なので小規模測定で予算内か確認し、Notebook12時間を超える見込みなら本実行前に止める。
- 候補の回収と実選別: 正解を使う上限診断と、予測だけを使う候補順位・最終graphの比較を分ける。候補外の正解、除外例、失敗を隠さない。

## 成功条件と停止条件

- primary指標: 未加工の実予測に対する公式combined scoreと接続・分裂成分。合成欠落での損失や回収率は補助診断。
- 成功条件: 実入力の誤接続が減り、両胚の公式combined scoreに改善が残り、通常条件と分裂を悪化させない。
- 必須guard: GEFF（Graph Exchange File Format）の未知領域を負例にしない。正例は注釈で確認できる有向edgeと予測中心の対応から作り、負例は別の親であることが確定した候補に限定する。重複検出・対応が曖昧な候補は対照損失から除く。娘ごとに正しい母を照合し、娘同士を競わせない。分裂の片娘だけの注釈を非分裂の完全教師とみなさない。
- 成功時の次段階: 根拠と限界をユーザーへ示す。改善を理由に別候補の実験化、Kaggle実行、submission、採用・完了を自動で確定しない。
- 失敗時の停止範囲: 入力を丸写しする近道、合成と実予測の誤差不一致、実入力への効果なし、通常条件の悪化、予算超過なら本処理を止める。
- 再開条件: 失敗した具体的な教師・入力・表現の不足を解消する別の根拠が得られた場合に再検討する。対照学習全体や上位仮説を一括で棄却しない。

- leakage / validation: 条件・checkpointは学習側内部だけで選び、胚を入れ替える2方向で公式combined scoreと接続・分裂成分、有効件数・失敗を報告する。公開画像モデルがtrain動画を学習に含むため、固定公開モデル下の条件付き比較であり独立した交差検証ではない。
- hidden test: 入力は画像からの予測と使用可能なmetadataのみ。GT履歴・正解の細胞数・動画間の細胞共有を仮定しない。時間窓依存の特徴を単一frameの特徴と呼ばない。
- runtime / memory: Kaggle Notebookのみ・GPU週45時間以内・課金なし。初期案は既存cacheを再利用して画像特徴を再抽出しない。CPUで可能な集計を先行し、追加の下流学習、最大候補数での評価・graph処理、hidden推論を別計上する。所要時間は未実測なので小規模測定で予算内か確認し、Notebook12時間を超える見込みなら本実行前に止める。
- 再現性: cache、重み、source、教師資格、分割、損失、候補生成、評価器の版とSHAを正本へ記録する。母・娘・重複対応の検査と最大サイズでのオフライン推論smokeを含める。
