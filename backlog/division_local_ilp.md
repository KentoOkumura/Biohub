- 根拠ファイル / 一次資料: 上記結果、[公式評価器の照合](../experiments/exp003_official_metric_audit/result.md)、[既存のILP解説](../docs/surveys/biohub-tracking-techniques-illustrated_20260915.md)。

- 仮定: Assumption: 娘が通常接続に先に割り当てられていても周辺を再選択すれば、正しい分裂を通常接続の損失より大きく回収できる。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 母・2娘を一括の事象として、競合する通常接続と同時に選ぶ効果。
- この候補の具体的な仮説: 同じ通常・分裂費用と候補なら、局所的なILPは分裂を順番に採否判定する方法より両胚の公式combined scoreを改善する。
- 仮説が正しい場合に期待する観測: 暫定通常接続に占有された娘を正しく回収し、娘の重複使用や通常接続の取り違えを減らす。
- 仮説を棄却する観測: 得点上だけの改善、combined scoreの悪化、局所境界の誤り、計算予算超過。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 分裂学習・候補回収そのもの、時刻曖昧性、異なる観測窓と密度への頑健性。

## 入力・予測対象・出力・推論方法

- input: 通常Hungarianの暫定割当、対応なし費用、固定の母・2娘候補と分裂得点、候補点と過去の予測状態。
- target / objective: 通常接続・分裂・終了／対応なしの合計費用を制約下で比較する。
- output: 局所で選び直した通常edgeと2本一組の分裂edge。中心は固定。
- loss: なし。先行候補のモデル・得点・校正を固定して復号だけを比較する。
- decode / 推論方法: Hungarianは暫定解とする。分裂候補に触れる通常接続とその代替候補を同じ局所問題へ含め、母は終了・1娘への継続・2娘への分裂のいずれか、娘の親は最大1つとする。分裂は1つの変数で2辺を同時に採用し、片娘だけの採用や二重計上を禁止する。局所外との境界制約を保つ。
- 処理単位: 動画内の分裂と通常辺が競合する局所領域・時間窓。窓の具体範囲と確定順は未決事項。
- 実装区分: このリポジトリ内の管理用語では`staged-faithful`。通常接続は一対一割当、分裂付近は事象単位の制約付き選択。単なる分裂edgeの後付けを同じ手法とは扱わない。

- 再利用するコード / config / 生成物: 先行3候補の入力とexp016の公式評価。新しい得点を使うためexp018の保存費用そのものは対照に混ぜない。
- 新しく作るもの: 実験化後に局所問題の抽出、ILP制約、決定的な専用判定対照、状態更新・境界検証。今回は文書だけ。

## 最小の反証可能な検証

- 検証方法: `A→B、D→C`から`A→{B,C}`への変更でDの別接続も検討できるか、二つの母が同じ娘を要求する場合、時間窓境界、履歴再計算を人工例で検証する。小規模な実動画の費用・時間を測り、同じ候補・得点の専用判定対照と局所ILPを199動画・両胚で比較する。
- variant / config / fold / booster数: 復号2条件、外側2方向、booster 0。exp016既存graphは外部参照として区別する。
- control再学習: なし。得点モデルを変えた比較へ置き換えない。
- 想定runtime / resource: Kaggle CPU中心。週30 GPU時間・推論12時間以内を維持し、最も密な競合成分の時間とメモリを先に測る。
- 候補の回収と実選別: 局所境界で消える既知組の数と、実際に選ばれた正誤分裂を分ける。ILP目的値の改善を公式精度改善と呼ばない。

## 成功条件と停止条件

- primary指標: 現行公式combined score、division Jaccard、adjusted edge Jaccard。
- 成功条件: 同じ得点の専用判定対照より両胚のcombined scoreが上がり、division成分が悪化せず、全件で構造制約と推論予算を満たす。
- 必須guard: 同じ候補・費用、no merge、母の継続と分裂の排他、2娘の一括採否、境界整合、処理順の再現性を検証する。再割当後は影響するカルマン状態を再計算し、分裂母を終了して娘へ状態を初期化する。
- 成功時の次段階: 統合結果と追加費用を示し、採否と提出の判断を別途求める。
- 失敗時の停止範囲: 片方の胚でcombined scoreが悪化、得点の二重計上、局所制約破綻、timeoutを未記録のまま隠す場合は昇格しない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: Hungarianの全通常辺を固定した後で娘だけ追加する、未対応娘だけを探す、半分の分裂を採用する、GTで競合領域を指定する、外側胚で費用を救済調整することは行わない。
- 壁打ちで採らなかった案と理由: 全動画の密な最適化は初回比較に不要。exp018の倍率変更、division_state_modelの継続・分裂・観測不能の新しい学習、分裂学習の変更とは別候補にする。

## リスク

- leakage / validation: 公開モデル下の条件付き評価。GTで局所問題の範囲や費用を選ばない。
- hidden test: 分裂が密集すると局所問題が連結する。窓外の継続・分裂との容量整合が必要。
- runtime / memory: 平均が速くても最悪成分が巨大になる可能性。timeout時の未承認の簡略化を行わない。
- 再現性: solver版、許容誤差、同点処理、確定順、境界条件、状態再生の開始点を記録する。
