## 入力・予測対象・出力・推論方法

- input: exp027と同じt−1・t・t+1の固定候補、窓に対応する画像特徴32次元、位置特徴32次元、物理座標、有効mask、相対時刻。exp015の保存cacheを使い、動画境界を越えない。
- target / objective: 中央t→t+1の主催者GEFF既知接続と母娘接続。
- output: 中央ペアの候補対logit。候補座標・追加node・新しい教師を作らない。
- loss: source軸softmax、focal weighted binary cross entropy、既存active pair maskをexp027から維持する。疎い教師の未知部分を真の負例と断定しない。
- decode / 推論方法: 最初はgraphを作らず同じ中央ペアで親順位・確率・閾値通過を比較する。固定0.5と、下記の内部検証だけで選ぶ閾値を併記する。
- 処理単位: 1動画内の3時点窓。外側評価は各胚64窓、分割と結果を胚別に保持する。
- 実装区分: このリポジトリ内の管理用ラベルはexp027と同じ`staged-faithful`。exp027の機構を維持する学習量比較であり、Trackastra全方式の再現ではない。

## 最小の反証可能な検証

- 検証方法: 3時点1構成×外側2foldを同じ初期化から3epoch学習する。各epochの学習loss・内部指標・更新回数・時間を記録し、内部`selection_score`最大、同点なら後のepochという親の選択規則を保持する。外側を見てepochや学習率を選ばない。
- 学習量の比較: 同じrunの1・2・3epochと内部選択重みを、exp027で事前選択した各胚64窓で診断する。exp027保存1epochとのstate SHAと指標を照合し、差があれば再現性の差として記録し、同じrun内の1→3の差と分ける。入力・教師・splitの不一致なら停止する。
- 保存済み対照: 主対照はexp016の内部選択済み2重みを固定し、再学習・再選択せず同じ128窓へ推論する。exp027の2時点1epochを補助対照に使う。exp024の重みから外側結果で都合のよいepochを選ぶことはしない。
- 指標と閾値: 正解親の1位率・順位・確率・競合親との差、既知edge recall、active pair内の教師負例予測数、分裂母回収数と有効件数を胚別に示す。まず全条件で0.5を適用する。追加でexp027の内部閾値規則を再利用し、保存2時点1epochの0.5での教師負例数上限（fold 0:151、fold 1:288）以下になる最小閾値を、各モデルの同じ内部窓だけから選ぶ。exp016を含めて同じ上限・strict greater判定を使い、外側へ固定適用する。外側の誤接続数まで揃うとは仮定しない。
- 比較の保持: 同じ候補ID、GEFF対応、source軸確率、教師mask、64窓manifestを検証する。exp016の全件公式scoreやexp024の全件集計値を128窓の数値と直接引き算しない。動画単位のpaired bootstrapで差の不確実性を示すが、既知の128窓を新しい独立評価と呼ばない。
- variant / config / fold / booster数: 新規学習は1構成×2fold、計2 tracker、各3epoch、booster 0。2時点の新規学習0回。各epoch診断と保存対照の推論を費用へ含める。
- control再学習: なし。保存済みexp016とexp027を使う。実装都合で2時点の学習を追加しない。
- 想定runtime / resource: Kaggleのみ、週30 GPU時間・Notebook 12時間を維持する。exp027の3時点1epochの学習＋内部検証はfold 0が831.12秒、fold 1が1106.22秒だった。合計3epochへの単純外挿は約5812秒（1.61時間）だが、入力準備・benchmark・保存対照・epoch別診断を含まない粗い目安である。実行前にこれらを含む小規模実測と最新quotaを確認する。元の34.52時間推定は2構成・全外側窓を含むため、そのまま今回の費用に使わない。

## 成功条件と停止条件

- primary指標: 内部選択した3時点モデルの外側胚別の既知edge recallを、教師負例予測数と正解親1位率を併記して判定する。学習量比較は同runの1epoch、既存方式比較は保存済みexp016をそれぞれ基準にする。固定0.5と内部で選んだ閾値を混ぜず報告する。
- 成功条件: 内部で選んだ閾値の比較で、対象の基準に対して両胚とも既知edge recallが増え、教師負例予測数が増えず、正解親1位率が下がらない場合を、その比較における予備的改善とする。1epoch比だけ改善しexp016を超えない場合は、学習量の効果と既存方式への優位性を別に判断する。後のepochの内部選択値が同点なだけの場合は、学習延長が有効だった根拠にしない。
- 必須guard: 胚別分割・内部だけの選択、固定重みとcandidate identityの照合、両胚の指標と分母の記録、NaN/OOM・runtime gate・GPU予算を確認する。教師負例予測数は真の誤接続数とは呼ばない。exp027では外側分裂母0件／1件のため、同じ窓で分裂の非劣化を確定しない。
- 成功時の次段階: 改善と費用をユーザーへ示し、外側全件の前段診断へ進むか判断を得る。各胚64窓だけでは分裂条件を確認できないため、公式graph評価へ自動で進まない。全件診断と公式評価は次段の範囲とする。
- 失敗時の停止範囲: 改善条件が不成立なら本3epoch条件の結果を保存し、epoch・seed・半径・学習率探索を自動追加しない。全graph推論を始めず、3時点方式全体・上位仮説・位置履歴候補の棄却へ一般化しない。

## リスク

- leakage / validation: 公開画像重みの来歴により独立CVではない。内部集合はcheckpoint選択と閾値設定に共用し、外側128窓もすでに分析済みである。少数窓・疎い注釈の比較を全件や公式scoreと同一視しない。
- hidden test: 本候補は学習量と共通窓の診断までで、hidden test・提出用推論の実装や費用は検証しない。
- runtime / memory: 同じ局所attentionでも候補密度によって費用が変わる。epoch別保存・内部閾値診断・保存対照推論の費用を含めて判断する。
- 再現性: 原runと実行環境が違えばGPUの数値差があり得る。1epochの再現差と学習量の差を分け、入力や教師の違いを数値誤差として許容しない。
