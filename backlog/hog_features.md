## 観測事実と根拠

- 実測済みの事実: HOG（Histograms of Oriented Gradients、勾配方向ヒストグラム）は局所画像の勾配方向を集計・正規化する特徴。標準的な実装は2次元画像を対象とする。現行exp016は学習済み画像特徴を使い、HOGを追加した精度改善は未測定。
- 根拠ファイル / 一次資料: [既存HOG解説](../docs/surveys/biohub-tracking-techniques-illustrated_20260915.md#hog)、[Dalal and Triggs, 2005](https://lear.inrialpes.fr/people/triggs/pubs/Dalal-cvpr05.pdf)、[scikit-image HOG](https://scikit-image.org/docs/stable/auto_examples/features_detection/plot_hog.html)。前ターンで確認した一次資料の人検出の結果を、細胞追跡の改善実証とは扱わない。
- 利用する保存済み生成物とSHA: [exp015 metrics](../experiments/exp015_oracle_stage_limits/metrics.json)と[exp016 metrics](../experiments/exp016_frozen_image_encoder/metrics.json)のcache・split・重み・対照を正とする。親configのsummary_sha256・identity_sha256と取得物を照合し、追加生成物のSHAは実行時に記録する。未生成の特徴や履歴のSHAを捏造しない。
- 仮定: Assumption: 形や輪郭の向きの違いが細胞間・前後時刻で残り、既存の画像特徴を補える。似た丸い細胞同士を必ず区別できるとは仮定しない。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 固定検出点の周囲から抽出するHOGを追加し、隣接時刻の接続を学ぶ効果。細胞ごとの領域分割や外観履歴の蓄積は追加しない。
- この候補の具体的な仮説: HOG特徴または前後のHOG類似度を追加すると、同構造で追加情報を隠す対照より両胚の公式接続・分裂指標が改善する。
- 仮説が正しい場合に期待する観測: 形状が異なる近接細胞の取り違えが減り、分裂で形が変わる場合にも接続回収が悪化しない。
- 仮説を棄却する観測: 既存画像特徴に対する追加効果がない、回転・変形・断面変化で誤接続が増える、または片胚が悪化する。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 検出得点・DoGの個別効果とHOGとの相補性。画像特徴抽出器自体の学習更新はこの比較に含めない。

## 入力・予測対象・出力・推論方法

- input: 固定点中心の局所画像から計算するHOGベクトル、または接続元と接続先のHOGの類似度。2次元断面、投影、3次元の勾配方向分布のどれを使うかは未決で、同等の方式とは扱わない。
- target / objective: 主催者GEFFの既知中心・接続・分裂に対応付けた、隣接時刻の候補間の通常接続と母娘接続。
- output: 既存と同じ隣接候補ペアの接続logit。検出点や新しい細胞IDを生成する出力へ変更しない。
- loss: exp016の接続損失と教師maskを固定する。未注釈を追加の真の負例とみなさず、今回の特徴量の有無と教師・損失の変更を混ぜない。
- decode / 推論方法: HOGを点の入力へ加えるか、類似度を候補ペアの入力へ加えて接続を学ぶ。標準HOGの勾配方向集計と局所正規化を保持し、単一の勾配強度や可視化画像への置換はしない。 最終的なsecondary trackerの寄与・整数線形計画（ILP）・修復は対照と揃える。
- 処理単位: 同じ動画の隣接2フレームの固定候補と候補ペア。追加情報も同じ候補IDと画像窓へ対応付ける。
- 実装区分: 特定の追跡論文全体の再現ではなく、上記特徴を実際に入力して接続を学ぶ比較。このリポジトリ内の管理用語では中核を省略しない`faithful`を想定する。方式が未決の部分は実装前に確定する。

## 最小の反証可能な検証

- 検証方法: 既存の画像・位置入力を共通とし、追加情報ありと、同構造で追加情報を中立値に固定した対照を比較する。新規層の初期化・学習量を揃え、保存済みexp016とも比較する。入力箇所・対照の具体構造は未決事項を解消してから固定する。
- variant / config / fold / booster数: 初回の提案は2条件×外側2fold、計4 tracker、booster 0。設定探索を包括承認したものではない。追加の履歴生成用学習が必要なら別途回数を明示する。
- control再学習: 同構造の追加情報なし対照を学習し、構造追加の効果と情報の効果を分ける。保存済みexp016の参照値だけを理由なく再学習しない。
- 想定runtime / resource: Kaggle Notebookのみ、週30 GPU時間以内、提出推論12時間以内。元画像のI/O、切出し、方向ヒストグラムの次元数、特徴保存量、入力変換層と学習費用を測る。高次元特徴を無制限に連結しない。 実行前に残量・最大規模の小規模実測を確認する。
- 全graph推論への進行条件: 隣接ペアで接続回収・判定可能な誤接続・分裂を比較し、HOGの類似度と画像特徴の類似度の重なり、細胞密度・形状変化別の性能を補助診断する。 同じ入力・教師対応・評価条件のgraphを作らない隣接ペア診断を先に実施する。両胚の既知接続回収が改善し、取得可能な誤接続・分裂指標が悪化しないことを進行条件として提案する。使用指標・許容幅・有効件数は実装前に確定する。条件未達なら全graphへ自動で進まず、単体指標を公式scoreの代用にしない。長い軌跡の整合性と最終復号の効果は全graphの公式評価で確認する。

## 成功条件と停止条件

- primary指標: 現行公式combined score。adjusted edge Jaccard、division Jaccard、両胚別の結果と有効件数を併記する。
- 成功条件: 追加情報ありの条件が同構造対照より両胚の公式combined scoreを改善し、分裂成分を悪化させず、全対象で有効な出力を予算内に生成する。exp016に対する差も別報告する。
- 必須guard: 候補ID・時刻・座標・画像窓の一致、学習側だけでの設定選択、未知教師の扱い、追加特徴の欠損・非有限値、両胚・分裂・境界での悪化を確認する。
- 成功時の次段階: 結果と実行証拠を提示し、採否・完了はユーザー判断とする。他特徴との組合せ、提出は別判断。
- 失敗時の停止範囲: 単体診断・予算条件未達では全graphへ進まない。公式score未測定と記録してユーザーへ示し、外側評価を見た救済探索や検出器更新へ切り替えない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: HOGだけの単独trackerへの置換、画像モデルの再学習、正解領域による画像切出し、2次元投影を3次元HOGと呼ぶこと、評価胚で断面・特徴次元を選ぶこと。
- 壁打ちで採らなかった案と理由: HOG単独の対応付けでは既存画像特徴への追加効果を分離できない。任意回転に不変と仮定する使い方、DoG点検出や複数特徴の同時導入は採らない。

## リスク

- leakage / validation: 特徴の正規化・方式・checkpointの選択は学習側内部に限定する。公開画像モデル・初期重みの学習来歴による条件付き評価であり、独立した交差検証とは呼ばない。予測履歴を使う場合は対象動画をtracker学習から除き、外側胚の教師を生成・校正に使わない。
- hidden test: 検出座標だけで同じ物理範囲の画像を取得し、境界padding・画像向き・異方性を扱う。教師の領域分割や細胞IDを必要としない。
- runtime / memory: 似た丸い細胞の識別力不足、画像特徴との冗長性、回転・分裂・断面変化への感度、2次元投影で重なる細胞、高次元化。 抽出・読出し・学習・全graph推論の費用を分けて記録する。
- 再現性: 元画像・cache・重みの版、候補ID・窓、特徴の定義・正規化・単位、split・seed・設定と追加生成物のSHAを記録する。
