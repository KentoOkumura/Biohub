## 観測事実と根拠

- 実測済みの事実: 現行[tracker入力](../experiments/exp016_frozen_image_encoder/frozen_tracker.py)は隣接2フレームの特徴・位置。[graph推論](../experiments/exp016_frozen_image_encoder/graph_inference.py)では同じ2フレームを逆方向にも採点するが、3時点以上を同時入力しない。exp016の公式combined scoreは0.9120545013で、両胚の改善は未確認。本案の精度・費用は未測定。
- 根拠ファイル / 一次資料: 上記sourceと、Gallusser / Weigert, [Trackastra: Transformer-based cell tracking for live-cell microscopy（2024）](https://arxiv.org/html/2405.15700v2)。複数時点の検出点から対応を予測する先行例。細菌の正解検出点を使う時間窓の比較では2時点で性能が低下したが、本コンペの3D画像・検出誤差・疎い注釈での改善証拠ではない。
- 利用する保存済み生成物とSHA: [exp015 metrics](../experiments/exp015_oracle_stage_limits/metrics.json)のcache manifestと[exp016 metrics](../experiments/exp016_frozen_image_encoder/metrics.json)のfold別重み・対照graphを正とする。窓間のID・座標・特徴と実際に使用するSHAは実験化時に照合する。
- 仮定: Assumption: 前後の位置と見た目を同時参照すると、近接細胞の取り違えや分裂前後の曖昧さが減る。固定候補にない細胞の回収は範囲外。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 軌跡の事前確定を要しない、短い時間窓内の検出点集合による接続予測。
- この候補の具体的な仮説: 同じ画像特徴抽出器・候補・教師・損失・復号で追加時点を参照すると、2時点対照より両胚の接続指標と公式combined scoreが改善する。
- 仮説が正しい場合に期待する観測: 同じ評価対象で親の取り違えが減り、追加時点を隠した対照より良い。分裂を抑えて通常接続だけを改善する結果にならない。
- 仮説を棄却する観測: 追加時点を隠しても差がない、窓端の誤接続が増える、片方の胚で公式scoreが悪化する。予算超過による停止と情報の有効性の棄却は分ける。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: [位置履歴入力](position_history_tracker.md)、長い画像窓、軌跡断片・実欠測の回収。3時点だけの結果で多時点手法全体を判断しない。

## 入力・予測対象・出力・推論方法

- input: 初回提案は`t−1, t, t+1`の検出点の物理座標、固定画像特徴、相対時刻、有効点mask。時点付きのtokenとして渡し、正解軌跡・母娘対応を入力しない。
- target / objective: 中央時刻`t`から`t+1`への通常接続・母娘接続。前フレームは判断の入力であり、評価対象の辺や教師を増やす変更とは分離する。
- output: 対照と同じ候補ペアの隣接接続logit。座標や欠測nodeを新たに生成しない。
- loss: exp016の既存接続損失と教師maskを中央ペアへ適用する提案。新しい対照損失や全時点間の系譜損失を同時導入しない。既存maskが未知注釈を含む限界は明記し、追加時点の未注釈点から負例を増やさない。
- decode / 推論方法: 動画内を窓移動し、中央の隣接得点を既存の候補graph・整数線形計画（ILP）・修復へ渡す。secondary trackerと復号設定を維持する。逆方向採点の窓、重複予測・窓端の扱いは未決事項。
- 処理単位: 1動画内の3時点の検出点集合。分割と報告は胚単位。
- 実装区分: Trackastraの「軌跡を確定せず複数時点の検出点から対応を学ぶ」機構を参考にした別設計。このリポジトリ内の管理用語では`staged-faithful`を想定するが、Trackastra全体の再現や重みの互換性は主張しない。画像特徴・教師・lossはexp016を継承する。

## 親実験からの差分

- 変更するもの: trackerの入力時点数と集約構造。追加時点の有無を同じ構造でも比較し、モデル容量と時間情報の効果を分ける。
- 固定するもの: 公開画像側の重み・正規化統計、元の画像入力窓・前処理、中央ペアの候補ID・座標・教師・loss mask、胚split、学習量・設定選択規則、secondary trackerと最終復号。追加層の初期化と既存重みの移植は対照と揃える。
- 再利用するコード / config / 生成物: exp015 cache、exp016の教師対応・単体診断・graph replay・公式評価。保存特徴は抽出窓に依存し、単一フレーム特徴と読み替えない。
- 新しく作るもの: 実験化後に窓間の候補対応、時刻付き入力の集約、追加時点を隠す対照、窓端の処理を実装する。

## 最小の反証可能な検証

- 検証方法: 保存済み2時点基準を参照し、同じ新tracker構造で中央2時点だけを有効にする条件と3時点条件を比較する。先に候補ID・座標・特徴の出所を照合し、全graphより先に同じ中央ペア・教師対応で既知接続recall、判定可能な誤接続、分裂親・娘の指標、有効件数を両胚別に測る。
- variant / config / fold / booster数: 提案は学習2条件×胚を入れ替える2fold、保存済みexp016を別参照、booster 0。初回は3時点。`t−1, t, t+1, t+2`の4時点は娘の次の観測を加える後続比較で、同時の窓長探索は行わない。
- control再学習: 新構造の2時点対照は同じ初期化方針・学習量・教師対象で学習する。保存済みexp016と公開trackerは再学習しない。
- 想定runtime / resource: Kaggleのみ、週30 GPU時間以内、提出推論12時間以内。点数増によるattentionの最大メモリ、cache読込、下流学習、graph推論を別計測する。特徴再抽出が必要なら費用と比較条件を更新してから実行する。
- 全graph推論への進行条件: 両胚で接続診断が改善し、判定可能な誤接続と分裂を悪化させず、候補対応・予算検査を通ることを提案する。指標・閾値は実装前の契約へ固定する。単体では長い軌跡やILP後の効果を測れず、単体値を公式scoreと呼ばない。

## 成功条件と停止条件

- primary指標: 現行公式combined score。adjusted edge Jaccard、division Jaccardと両胚別の結果も記録する。
- 成功条件: 3時点条件が2時点対照より両胚の公式combined scoreで改善し、分裂成分が悪化せず、全対象で有効かつ予算内。exp016との差も別に示す。
- 必須guard: 画像側固定、同じ中央ペアの教師・候補、抽出窓の保持、時点順序、動画境界、有効件数を検査する。未来画像は推論時に渡される同じ動画内だけを使い、正解は入力しない。
- 成功時の次段階: 証拠と未解決事項をユーザーへ示し、採否・完了と4時点化または位置履歴との比較を判断してもらう。
- 失敗時の停止範囲: 単体診断不成立なら全graphを自動実行せず公式score未測定と記録する。失敗を根拠に検出器学習や新しい教師へ切り替えない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 正解対応で点を軌跡へ並べる、別動画の特徴を混ぜる、画像側の再学習、未知点の一律負例化、外側胚で窓長・設定を選ぶ、時間を飛ばす辺の提出は行わない。
- 壁打ちで採らなかった案と理由: 逆方向採点だけでは既存処理と重複する。[long_window_links](long_window_links.md)の2時点対5時点の画像モデル比較とは別設計で、同案のP4を解除しない。[frame_self_attention](frame_self_attention.md)の同一フレーム内の文脈化とも別比較。候補制限・位置履歴・分裂組モデルを同時に追加しない。

## リスク

- leakage / validation: 公開画像重みを含む条件付き評価で、独立CVとは呼ばない。重なる窓を別foldへ分割せず、追加時点も同じ動画・fold内に閉じる。
- hidden test: 動画の最初・最後、短い動画、空の検出集合を扱う。前後が必ず揃う設計にしない。
- runtime / memory: 全点attentionの計算増を測る。候補を黙って削って予算を通さず、必要なら比較の変更として分離する。
- 再現性: 中央ペアと参照窓、候補ID、特徴の抽出窓、初期化、mask、設定、重み・生成物SHAを保存する。
