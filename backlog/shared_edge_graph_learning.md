- 仮定: Assumption: 1娘と2娘の接続得点を共有し、既知2娘が自身の1娘・空集合より高得点になるよう学習すると、独立集合headと現在の周辺化損失より分裂が学習される。未知部分で誤分裂が増える可能性もあり、効果は未実証。

## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 部分注釈と親子の構造制約を保ちながら、直接graph予測の得点表現と比較損失を変更したときの接続・分裂の選択。
- この候補の具体的な仮説: 共有接続得点に母と2娘の相互作用を加え、既知分裂を落としたgraphに対する得点差を学習すると、誤接続を抑えながら分裂を回収できる。
- 仮説が正しい場合に期待する観測: 学習内の小例で正解2娘が自己部分集合に勝ち、graphとして選ばれる。その後、同条件の対照より別胚での分裂回収が増え、既知edgeと観測可能な誤接続の前段条件も満たす。
- 仮説を棄却する観測: 小例でも分裂を学べない、分裂の損失配分だけで表現・graph比較の差が消える、全母を2娘に寄せて誤接続が増える、または改善が学習内だけに留まる。どの変更が失敗したかを分ける。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 対応なしの教師、合成系譜からの学習、前後軌跡による追加情報、異なるgraph表現は別比較。1候補の失敗で直接graph予測全体を閉じない。
- 既存候補との差: [sample_loss_balance](sample_loss_balance.md)は動画間の寄与調整、[contrastive_parent_child](contrastive_parent_child.md)は親子特徴の対照学習、[division_triplets](division_triplets.md)は分裂組の合成事前学習、[whole_graph_choice](whole_graph_choice.md)は複数trackerの完成graph選択。本候補は同一モデル内の共有接続得点と部分graphの比較学習であり、それらを置き換えない。

## 入力・予測対象・出力・推論方法

- input: exp043と同じ固定検出点・補正座標・元の時間窓に対応する固定画像特徴と得点、同じ接続候補集合。初段は隣接2時点とし、画像encoder・座標headを更新しない。旧exp015 cacheを新入力と同一視しない。
- target / objective: 既知edgeを含み、既知の矛盾を除くgraphを選ぶ。未知edgeは正負を決めず許容graph内の潜在部分として残す。既知1本の母を非分裂の完全教師としない。
- output: 母ごとの空・1娘・2娘の選択得点。1娘の接続得点を2娘にも共有し、2娘のときは順序に依存しない相互作用を加える。graph得点は選んだ集合の得点和とする。空・出次数項の具体的な構成は未決事項。
- loss: 現行の部分周辺化、既知2娘の別平均、共有得点表現、graph比較を段階比較する。局所比較では正解2娘とその1娘・空集合を比べ、他の母の選択を揃える。競合graph比較では既知正解に整合する最高得点graphと、既知誤りの損失を加えて選んだgraphの差を使う。具体式・損失配分・併用範囲は未決事項。
- decode / 推論方法: 母ごとに1集合を選び、娘の親は最大1、母の娘は最大2、次時点向きの制約で最大得点graphを選ぶ。ILPを保持し、同じ候補・実行可能解集合・solver条件で得点と学習目的を比較する。2娘相互作用に新しい変数が必要なら、その拡張と同等の対照を契約へ記し、元のexp043 ILPと同一とは呼ばない。既存ILP予測を正解教師にしない。候補距離・件数・絞り込みの変更を同時に含めない。
- 処理単位: 隣接2時点の候補graphと、同じ娘を候補に持つ母を推移的に結んだ競合成分。成分を分割する場合は、目的と制約が成分間で独立な範囲だけ分ける。
- 実装区分: 共有得点と部分graphの比較という中核を、小例・局所比較から競合graph比較へ段階的に検証する。リポジトリ内の管理用ラベルでは提案に対して`staged-faithful`。局所marginだけの結果を全graph競合の学習効果とは呼ばず、参照論文全体の再現とも扱わない。

- 再利用するコード / config / 生成物: exp029の教師・復号・追加診断とexp043の入力・後処理・モデル版。exp015/016は診断手順の参考で、旧cacheや数値を新入力対照にしない。実験化時は親requirementsとconfigを先に読む。

## 最小の反証可能な検証

- 検証方法: 学習側から既知2娘と確認済み矛盾を含む小集合を固定し、得点差・勾配・実際のgraph選択を確認する。学習成立後に内部検証で設定を固定し、同じ候補を用いて両胚へ適用する。小例への適合を別胚への改善とは呼ばない。
- variant / config / fold / booster数: 現lossの対照、分裂の損失配分だけを変える対照、共有得点表現の追加、局所graph比較の追加、競合graph比較を段階的に切り分ける案。最小条件の組み方・同時実行数は未決事項。外側は既存2fold、booster数0。
- control再学習: 損失・表現以外を揃えた対照が必要。既存exp029重みは再現確認には使えるが、異なる更新数やcheckpoint規則を持つ新条件の対照と同一視しない。同条件の保存済み対照がない場合はtrackerのみ再学習する。
- 想定runtime / resource: [現在方針](KAGGLE_DIRECTION.md#今後の学習方針)のKaggle・週次GPU枠・課金なし・提出推論12時間を引き継ぐ。新入力の必要特徴を保存して再利用する。競合graph損失は原則1窓2回の制約推論を要し、CPU solver時間・GPU待ち・最大成分のメモリを実測する。所要時間と残量は実行時の確認事項。
- 候補の回収と実選別: 正解が候補内にある件数、絞り込み後に残る件数、自己部分集合との得点差、GTなしで選ばれる件数を分ける。GTによる候補補充・有利な例だけの外側評価は行わない。

## 成功条件と停止条件

- primary指標: 最終的には現行公式combined scoreと接続・分裂成分。先行判断はexp029と同じ隣接2時点の既知edge、観測可能な誤接続、既知分裂、構造違反で行う。
- 成功条件: 小例の候補内既知2娘が自己部分集合より高得点になり、正しい分裂として選べること。その後、exp043と同入力の対照より両胚の分裂回収を改善し、既知edgeと観測可能誤接続の事前条件を満たすこと。旧exp016の数値を新入力の合否基準にしない。公式scoreの改善は全graph評価後にだけ主張する。
- 必須guard: 未注釈を負例化しない。分裂を増やすだけの退化を既知誤接続と併せて確認する。外側130件を重み・候補・checkpoint選択に使わない。全未知edgeの誤接続率を観測できたと主張しない。
- 成功時の次段階: 前段条件と費用を記録して全graph評価へ進む判断材料を示す。採否・完了とsubmissionはユーザー判断に従う。
- 失敗時の停止範囲: 小例を学べない場合は大規模学習を止める。前段条件を満たさない場合は全graph推論を自動実行せず、失敗した得点表現・損失・モデル選択の範囲を記録する。
- 再開条件: 失敗した具体的な段階の教師・表現・最適化・計算上限を改善する根拠が得られた場合に再検討する。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 既知1本の母を非分裂教師にする、未知の第2娘をNULLに固定する、既存ILP graphを擬似正解にする、外側で重みを調整する、検出器・画像encoderを更新する、を行わない。候補数・edge費用の調整だけへ本案を縮小しない。
- 壁打ちで採らなかった案と理由: topK解除だけでは保存済みscoreの障害を解消しない。後続2軌跡、合成事前学習、娘側と母側の融合は有望な別比較だが、主案の原因分離のため同時投入しない。12案全体を今回の依頼で一括登録しない。

## リスク

- leakage / validation: 公開画像encoderの学習来歴を引き継ぐ条件付き比較。内部の既知分裂が3件・9件と少ないため、多数の設定探索を避ける。内部選択の規則は実験前に固定する。
- hidden test: 画像と固定予測だけを使用する。GTの分裂数、動画間の同一細胞、公開testと同じ密度・長さを前提としない。
- runtime / memory: 1窓2回の推論と高密度窓の大きな競合成分が律速になり得る。GPU消費とNotebook経過時間を区別し、提出推論12時間以内か確認する。
- 再現性: source、初期値、分割、候補・教師mask、cache、loss・checkpoint規則、solverと同点処理の版・SHAを記録する。
