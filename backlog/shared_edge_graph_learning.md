## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 部分注釈と親子制約の下で、共有得点と構造を比較する学習によって継続・分裂を選ぶ価値。
- この候補の具体的な仮説: 母と娘候補間で特徴を共有し、接続得点を1娘・2娘で共用し、既知2娘が自身の1娘・空集合より高得点になるよう学ぶと、両胚の最終接続・分裂が改善する。
- 仮説が正しい場合に期待する観測: 正解分裂が最終graphへ残り、誤接続を増やさず両胚の公式指標が改善する。
- 仮説を棄却する観測: 2娘を学べない、全母を分裂に寄せる、学習例だけの改善、または後処理で改善が消える。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 対応なしの教師、合成教師、多時点経路、構成要素の寄与。締切前の1設定比較では個々の要素の効果を切り分けたと主張しない。
- 既存候補との差: [sample_loss_balance](sample_loss_balance.md)は動画間の寄与調整、[contrastive_parent_child](contrastive_parent_child.md)は親子特徴の対照学習、[division_triplets](division_triplets.md)は分裂組の合成事前学習、[whole_graph_choice](whole_graph_choice.md)は複数trackerの完成graph選択。本候補は同一モデル内の共有接続得点と部分graphの比較学習であり、それらを置き換えない。

## 入力・予測対象・出力・推論方法

- input: exp043の補正後座標・固定画像特徴と、隣接2時点の母・娘候補graph。
- target / objective: 公式注釈と整合する接続・分裂。娘1つだけの注釈を完全な非分裂教師にせず、未知の第2娘を接続なしに固定しない。
- output: 母ごとの接続なし・娘1つ・娘2つの得点。接続得点を通常継続と分裂で共有し、2娘には順序に依存しない相互作用を加える。
- loss: 既知接続の部分教師損失に、正解2娘とその1娘・空集合の得点差を学ぶ損失を加え、分裂例の寄与を確保する。元案の競合graph比較を含める範囲、具体式・配分は未決とし、小例→局所→競合の段階実験を必須にしない。
- decode / 推論方法: Graph Neural Network（GNN、候補間で情報を集約するニューラルネットワーク）で母・娘候補の特徴を更新する。娘の親は最大1、母の娘は最大2という制約の下で集合を選ぶ。整数線形計画法（ILP）で制約付きの選択を行う。exp043への組込み位置・変数拡張は未決。
- 処理単位: 隣接2時点の母と娘候補、および同じ娘を取り合う候補集合。
- 実装区分: 特定論文の忠実再現ではない独立案。GNNの情報交換、得点共有、既知分裂の比較学習を中核とする。

## トラッカーの学習で変える具体的な処理

- exp029の共有backboneから別々の1娘・2娘headへ分ける方式に対し、親Aと娘候補Bの接続得点を一度計算し、1娘集合と2娘集合の両方で同じ得点を使う。特徴の共有だけではない。
- 1娘の得点はA→Bの接続得点と1娘用の補正、2娘の得点はA→BとA→Cの同じ接続得点の和に母・2娘の相互作用と2娘用の補正を加える。空集合には別の得点を持たせる。2娘相互作用は娘の順序を入れ替えても同じ値にし、特徴の和・差の絶対値などで表す案を基本とする。層構成と初期化は未確定。
- 既知の2娘B・Cでは、正しい2娘をBだけ・Cだけ・空集合と直接比較し、分裂例の損失を別平均して希少な信号が通常接続に埋もれるかを調べる。既知Bだけの母ではBを含む集合を許容し、未知のCがいないという教師を作らない。
- まず既存の部分注釈損失と分裂の別平均だけの対照、共有得点、局所比較を切り分ける。競合graph全体の比較は後段。推論では母ごとに1集合、娘の親は最大1という制約で整合する選択を行う。
- これはtrackerの採点構造・損失と、その出力の選択を変える案である。後処理の閾値変更だけではない。exp043で候補が欠けているなら、この採点学習を先行させない。座標補正の成功や本案の仮説から、exp041の失敗原因を断定しない。
- [exp043要件](../experiments/exp043_x138_self_trained_head/requirements.md)・[config](../experiments/exp043_x138_self_trained_head/config.yaml)・[metrics](../experiments/exp043_x138_self_trained_head/metrics.json)を新入力の正本とする。旧診断の128件・外側130件・内部3件/9件はexp029の母数で、新入力では再集計する。
