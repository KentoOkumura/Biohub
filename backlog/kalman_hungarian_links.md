## 入力・予測対象・出力・推論方法

- input: 窓に対応した固定中心、物理座標、既存画像由来の接続得点、自分の過去の予測対応。正解の軌跡・分裂情報を推論へ渡さない。
- target / objective: 隣接時刻の通常接続を一対一で選ぶ。運動モデルの校正は学習側内部だけで行う。
- output: 通常接続、対応なし、各trackの位置・速度・共分散。提出する検出中心座標は変更しない。
- loss: 新しい接続モデルの学習はなし。運動雑音・観測雑音と費用の校正方式は未決事項に分離する。
- decode / 推論方法: 位置と速度の6次元状態、6×6共分散による3次元等速カルマン予測。単位はµmとµm/frame。画像費用に予測観測の負の対数尤度を加え、対応なしを表す行・列を含むHungarian割当を行う。共分散の広がりの項も考慮し、Mahalanobis距離だけで不確かなtrackを優遇しない。
- 処理単位: 隣接時刻で割当し、動画内のtrack IDへ状態を継承する。node IDだけに状態を保存して毎時刻初期化しない。
- 実装区分: このリポジトリ内の管理用語では`staged-faithful`。カルマンの状態・共分散と対応なしを保持し、分裂再選択のみ後続へ分離する。単なる一定速度の外挿をカルマンフィルタと呼ばない。

## 親実験からの差分

- 変更するもの: 通常接続の割当と、運動履歴を使う費用。
- 固定するもの: 公開検出器・画像特徴抽出器・primary/secondary trackerの重み、候補中心・辺の支持集合、画像得点、評価対象、後処理。2つのHungarian条件ではexp016が予測した同じ母・2娘を予約し、使用済みの入出力容量を通常割当から除く。正解分裂で対象を選別しない。
- 再利用するコード / config / 生成物: exp016のcache再生と公式評価、exp015の窓・物理座標対応。予約分裂が修復後に変わらないかも検査する。
- 新しく作るもの: 実験化後に状態管理、対応なし付き割当、校正、比較診断。今回は文書だけ。

## 最小の反証可能な検証

- 検証方法: exp016の既存graphを外部対照に残し、同じ分裂予約を使う「画像費用のみのHungarian」と「画像費用＋カルマンのHungarian」を主比較にする。履歴なし、分裂直後、交差、動画境界を小規模で検査後、199動画を胚を入れ替える2方向で評価する。
- variant / config / fold / booster数: 主比較2条件＋保存済みexp016参照、外側2方向、booster 0。設定選択は学習側内部のみ。
- control再学習: なし。画像側も既存接続得点モデルも固定。
- 想定runtime / resource: [現在の方針](KAGGLE_DIRECTION.md#今後の学習方針)に従いKaggleのみ、週30 GPU時間、提出推論12時間以内。割当はCPU中心。cacheから得点を再計算する費用も小規模実測に含める。
- 候補の回収と実選別: 主比較では候補辺を増減せず、既知辺の支持集合を照合する。実際の選択精度と、正解履歴を使う診断上限を別々に報告する。

## 成功条件と停止条件

- primary指標: 現行公式combined score。adjusted edge Jaccard、division Jaccard、胚別・履歴長別・密度別の結果も記録する。
- 成功条件: カルマンあり条件がなし条件を両胚のcombined scoreで上回り、分裂成分が悪化せず、全件有効かつ予算内。exp016本体との差は別に示し、主比較の成功だけで提出モデルを置き換えない。
- 必須guard: 同じ候補・得点・分裂予約、状態継承、有限共分散、対応なし、修復前後の比較を検証する。新しいhard gateで正解候補を落としたら同じ支持集合の比較として扱わない。
- 成功時の次段階: 結果をユーザーへ示し、候補絞り込みと分裂の局所再選択へ渡すか判断を求める。
- 失敗時の停止範囲: 主比較が片方の胚で悪化、予約制約違反、予算超過なら後続統合を自動実行しない。軌跡を使う手法全体の棄却とはしない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 正解履歴を推論へ注入、検出器更新、中心の平滑化出力、欠測nodeの生成、時刻を飛ばすedge、外側胚での費用調整は行わない。
- 壁打ちで採らなかった案と理由: 分裂モデル・候補追加・局所最適化を同時導入すると運動予測の寄与が分からない。組織移動補正は既存のmotion_reference、軌跡断片の接続はtracklet_joinの別比較とする。

## リスク

- leakage / validation: 公開モデル下の条件付き比較であり独立CVではない。運動雑音を外側胚の正解軌跡から推定しない。
- hidden test: 短い履歴・分裂・画角境界での初期化が必要。対応なしを許すが、出生・消失の生物学的教師を持つとは主張しない。
- runtime / memory: 動画全体の密な費用行列ではなく候補の連結成分を扱う場合も、辺を暗黙に削らない。
- 再現性: 同点規則、track ID、座標単位、状態初期化、得点とsolverの版を記録する。
