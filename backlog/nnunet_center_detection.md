- 上位仮説のうちこの候補が検証する範囲: nnU-Netの設定・学習・推論を中心マップへ適応し、同じ方式の接続器を通した公式指標まで改善が残るか。

## 入力・予測対象・出力・推論方法

- input: 3D蛍光画像、物理間隔、学習側の疎な中心座標。時間窓は現行の2時点を参照し、nnU-Netへの入力方法は未決。
- target / objective: 注釈中心から作る、中心ほど値が高い3Dマップ。Gaussian形状と距離変換由来の形状、物理単位での広がり、重なった教師の集約は実験化前に1案へ固定する。細胞の実際の領域教師とは扱わない。
- output: 各時点の中心マップ、物理座標へ戻せる検出位置と得点、接続・分裂を表すgraph。
- loss: 未知領域を除外する重み付き二値交差エントロピー（BCE）を検討する。信頼できる背景、正例周辺の有効領域、連続値教師とmaskの整合は未決。正例以外をすべて背景とする実装や、正例だけで全前景への退化を防げるとの仮定は採らない。
- decode / 推論方法: nnU-Netで重なりのある3Dパッチを予測・統合し、中心マップの局所最大から複数の細胞を得る。現行と同じ方式で接続を採点し、整数線形計画でgraphを選ぶ。得点の意味が変わるため、現行の検出閾値0.99は流用を前提とせず、学習側内部だけで閾値を固定する。
- 処理単位: 学習は動画内の3Dパッチまたは複数時点のパッチ、予測保存は1動画、外側の分割は胚単位。
- 実装区分: nnU-Netのデータ解析・前処理計画・学習・パッチ推論を保持した拡張を意図する。具体案と省略点を確定後に、[用語集](../docs/glossary.md)のこのリポジトリ内の管理ラベルを選ぶ。既存U-Netの名称変更や層数変更だけをnnU-Net実装とはしない。

## 親実験からの差分

- 変更するもの: 検出の前処理・パッチ計画・ネットワーク・中心教師・損失と、追跡器へ画像特徴を渡すために必要な接続部分。追加学習が必要な範囲を実験契約へ明記する。
- 固定するもの: 胚を分ける評価方針、固定公式評価器、対象動画、物理単位、接続と分裂の推定方式。追跡器の重みまで固定できるとは断定しない。疎教師の効果を切り分ける対照では教師mask・画像露出量を揃える。
- 再利用するコード / config / 生成物: exp005の分割・graph評価・候補保存・hidden test列挙・提出形式検証。共有特徴の差があるので、既存追跡器の重みを新しい特徴へ無条件に接続しない。
- 新しく作るもの: nnU-Net入力変換、学習胚だけからの前処理計画、中心教師と有効mask、特徴の接続方法、座標復元、推論費用の測定記録。

## 最小の反証可能な検証

- 検証方法: exp005と段階別診断で検出不足を確認する。実験化後は、学習側の小領域で教師変換・背景の妥当性・座標復元・接続器との整合・メモリを確認し、仕様を固定して胚を入れ替える2方向で比較する。各胚の既知中心回収率、検出数、接続・分裂指標、公式総合スコア、学習時間と推論時間を保存する。
- variant / config / fold / booster数: 最初の提案はnnU-Net構成1種と対照、外側2fold。複数モデルの平均や別の学習器は初回に加えない。必要な学習回数は対照再利用の可否を確認して確定する。
- control再学習: exp005と同じ教師・学習条件を保てない場合は、変更した教師条件を揃えた現行検出器の対照が必要。exp005だけとの差は構成全体の比較として記録し、nnU-Net単体の効果とは呼ばない。
- 想定runtime / resource: 未実測。Kaggle無料枠内、課金なし、提出推論12時間以内。nnU-Netと現行のepochの定義は異なり、同じ3 epochsで同じ学習量とはみなさない。更新回数・画像露出量・総GPU時間を別々に見積もる。

## 成功条件と停止条件

- primary指標: exp003で照合した固定公式評価器の総合スコア。接続・分裂成分と胚別結果を併記する。
- 成功条件: 同じ評価動画で両胚の公式スコアが対照を上回り、実行失敗が増えず、推論費用が12時間以内に収まる証拠を得る。小領域の中心回収率だけでは成功としない。
- 必須guard: 学習から除いた胚の注釈を、教師生成・前処理計画・閾値・checkpoint選択に使わない。未知の細胞を誤検出と決め付けない。評価胚や公開testを使った反復選択を独立検証としない。
- 成功時の次段階: 根拠と費用を提示して採否をユーザーへ確認する。今回の依頼はバックログ反映であり、実験化・Kaggle実行・submissionの承認を含まない。
- 失敗時の停止範囲: 背景を識別できない、全前景へ退化する、片側胚が悪化する、または予算超過の場合は本比較を止めて原因を記録する。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 単なるU-Netの置換をnnU-Net全体と呼ぶ、時間入力を黙って単時点へ縮小する、未知領域へ強い背景損失をかける、評価胚で閾値を選ぶ、正解中心を推論へ渡すこと。
- 壁打ちで採らなかった案と理由: 領域予測は教師と出力が変わるため[別候補](nnunet_instance_segmentation.md)に分けた。BYU解法の半径・TopK損失・学習量は転用を確定していない。Biohubの疎注釈、密な細胞数、時系列、計算制約の適合確認が先に必要。
- 既存候補との差: [sparse_det_mask](sparse_det_mask.md)は未知領域の扱い、[subvoxel_offset](subvoxel_offset.md)は検出後の座標補正、[direct_center_set](direct_center_set.md)は可変個数の中心集合の直接出力を検証する。本候補はnnU-Netによる中心マップの学習である。

## リスク

- leakage / validation: 同じ胚の別動画・隣接時点の混入と、全胚で作った前処理計画による評価条件の混同。分割を教師生成前に固定する。
- hidden test: 画像と利用可能なmetadataだけで全動画を処理し、中心座標を元のvoxel座標へ戻す。nnU-Net単体の出力から提出graphが自動的に完成するとはしない。
- runtime / memory: 高解像度パッチ、時間入力、重複パッチ推論、既存特徴抽出の併用で費用が増え得る。自動設定だけでT4上の完走を保証しない。
- 再現性: nnU-Net本体、拡張trainer、前処理計画、教師生成、分割、依存packageを固定し、オフラインでの実行を検証する。
