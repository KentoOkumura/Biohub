## この候補が直接検証する仮説と範囲

- 上位仮説のうちこの候補が検証する範囲: 過去の予測位置から計算した3次元速度と、次候補の位置との整合性を要約特徴として追加する。位置列をシーケンスとして直接入力するposition_history_trackerは置き換えない。
- この候補の具体的な仮説: 予測履歴から求めた速度と予測位置のずれを追加して学習すると、同構造で速度情報を隠す対照より両胚の公式接続・分裂指標が改善する。
- 仮説が正しい場合に期待する観測: 自己予測履歴でも候補の取り違えが減り、短履歴・誤履歴・分裂直後に悪化せず、履歴を入れ替えた診断では効果が失われる。
- 仮説を棄却する観測: 正解軌跡の場合だけ改善する、誤履歴で取り違えが連鎖する、片胚が悪化する、または現在の座標差だけの対照を上回らない。
- この候補だけで上位仮説を判断できるか: いいえ
- 上位仮説の判断に残る検証: 位置列の直接学習、未対応点の複数時点入力、周囲の運動、長い欠測・軌跡断片接続。今回の結果だけで時間情報全体の採否を判断しない。

## 入力・予測対象・出力・推論方法

- input: 過去の予測接続から求めた3次元移動ベクトル、時間差で正規化した速度、予測位置と次候補のずれ、履歴の有無・長さ・信頼度を候補とする。速さの大きさだけではなく方向を保持する。
- target / objective: 主催者GEFFの既知中心・接続・分裂に対応付けた、隣接時刻の候補間の通常接続と母娘接続。
- output: 既存と同じ隣接候補ペアの接続logit。検出点や新しい細胞IDを生成する出力へ変更しない。
- loss: exp016の接続損失と教師maskを固定する。未注釈を追加の真の負例とみなさず、今回の特徴量の有無と教師・損失の変更を混ぜない。
- decode / 推論方法: 速度と整合性を既存trackerの点・ペア特徴へ追加する。履歴を固定trackerの初回予測から作るか逐次更新するか、逆方向採点の履歴は未決。物理距離と時間の単位を揃え、時間間隔不明時に物理速度と呼ばない。 最終的なsecondary trackerの寄与・整数線形計画（ILP）・修復は対照と揃える。
- 処理単位: 同じ動画の隣接2フレームの固定候補と候補ペア。追加情報も同じ候補IDと画像窓へ対応付ける。
- 実装区分: 特定の追跡論文全体の再現ではなく、上記特徴を実際に入力して接続を学ぶ比較。このリポジトリ内の管理用語では中核を省略しない`faithful`を想定する。方式が未決の部分は実装前に確定する。

## 成功条件と停止条件

- primary指標: 現行公式combined score。adjusted edge Jaccard、division Jaccard、両胚別の結果と有効件数を併記する。
- 成功条件: 追加情報ありの条件が同構造対照より両胚の公式combined scoreを改善し、分裂成分を悪化させず、全対象で有効な出力を予算内に生成する。exp016に対する差も別報告する。
- 必須guard: 候補ID・時刻・座標・画像窓の一致、学習側だけでの設定選択、未知教師の扱い、追加特徴の欠損・非有限値、両胚・分裂・境界での悪化を確認する。

- 失敗時の停止範囲: 単体診断・予算条件未達では全graphへ進まない。公式score未測定と記録してユーザーへ示し、外側評価を見た救済探索や検出器更新へ切り替えない。

## リスク

- leakage / validation: 特徴の正規化・方式・checkpointの選択は学習側内部に限定する。公開画像モデル・初期重みの学習来歴による条件付き評価であり、独立した交差検証とは呼ばない。予測履歴を使う場合は対象動画をtracker学習から除き、外側胚の教師を生成・校正に使わない。
- hidden test: 動画開始、履歴不足、空フレーム、分裂後、逆方向の採点でも正解なしで生成できる特徴を使う。動画境界をまたいで状態を継承しない。
- runtime / memory: 履歴の誤接続による速度汚染、学習時と推論時の履歴品質差、分裂時の急な運動、時間・物理座標の尺度、追加passの費用。 抽出・読出し・学習・全graph推論の費用を分けて記録する。
- 再現性: 元画像・cache・重みの版、候補ID・窓、特徴の定義・正規化・単位、split・seed・設定と追加生成物のSHAを記録する。
