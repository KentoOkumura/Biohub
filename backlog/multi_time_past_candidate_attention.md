## 入力・予測対象・出力・推論方法

- input: 対象隣接2時点の固定候補・既存画像特徴は基準どおり。追加するのは同じ動画の過去数時点の候補座標、実時刻、有効maskのみ。初回案は対象2時点と過去3時点、合計5時点。過去画像特徴・正解軌跡・予測接続は入力しない。
- target / objective: 対象の隣接2時点の既知接続・母娘接続。過去点の対応を確定する教師や非隣接対応損失は追加しない。
- output: 接続候補A→Bごとに過去候補を集約し、追加logitを既存の接続logitへ加える。点ごとの特徴更新に置き換えず、候補点・中心座標は変えない。
- loss: 1時点版と同じexp016由来のsource軸softmax後のfocal-weighted binary cross entropy、教師対応、正例行OR正例列mask、分裂重みを維持する。この教師上の負例をすべて真の負例と保証する意味ではない。
- decode / 推論方法: 共通ペアの単体評価を先行し、進行条件とユーザー確認後の全graphではexp016系のsecondary tracker・候補生成・ILP復号・修復を維持する。正逆方向採点における過去時点と時間差は実装前に確定する。
- 処理単位: 対象ペアA→Bごとに、複数の過去frameの未対応候補Pを参照する。参照する点は一つに確定せず、過去を使わない選択肢も残す。出力と教師は対象隣接2時点。
- 実装区分: 時刻差を扱う複数時点の座標集約を省略せず、全graph評価だけを後段にする`staged-faithful`を想定する。本リポジトリ内の管理用語であり、実装済みという意味ではない。

### 1時点版から維持するものと追加判断

- 1時点版ではP→AとA→Bの3次元変位、その差、各ノルム、方向の一致度を用いて、全Pと過去なしの選択肢をsoftmaxで重み付けし、接続候補ごとの追加得点を作る。初期の追加得点をゼロにする設計も比較境界として維持する。
- 数時点を混ぜる場合、P→Aの経過時間が異なる。実時刻差で正規化した変位と時間差の明示を推奨案とするが、具体的な入力表現は未決。単なる座標の連結で全候補を同じ時間間隔とみなさない。
- 時点をまたぐ全候補を一度に正規化するか、各時点で集約してから合わせるかを設計時に選ぶ。候補数の多いframeが重みを集める影響と、過去なしの選択肢の定義を明示する。後者は集約構造も変えるため、「時点数だけ変更」とは報告しない。
- 過去各frameの全候補を基本とし、確定した軌跡や距離上位の候補だけに無断で絞らない。分割計算でもsoftmaxの正規化範囲と出力・勾配を保つ。
- 対象ペアの画像特徴は2時点窓に依存する。過去座標も取得元窓・candidate ID・物理単位・時刻を保存し、別窓で生成された同時刻候補を無条件に同一視しない。

## 成功条件と停止条件

- primary指標: 初段は両胚別の既知接続recall。公式精度は全graphの公式combined scoreとその成分で確認する。
- 成功条件: 推奨は両胚で1時点版より既知接続recallが厳密に改善し、同じmask内の教師負例予測増加が各胚5%以内、分裂親回収数が非減少。全graphへ進む条件には保存済みexp016を両胚で上回ることも含め、固定閾値0.5を基本に実行前に確定する。
- 必須guard: 正解親1位率、教師負例予測、分裂親回収と有効分母、時点別候補数、開始・欠測・密集度別の結果。未知部分の誤接続全数は測れないことを明記し、分母なしを非悪化とみなさない。
- 成功時の次段階: 両対照との差と費用を提示し、全graph・公式評価へ進むかユーザーへ確認する。採否・完了・submissionは別の明示判断。

## リスク

- leakage / validation: 胚分割を維持し、GTや注釈の有無で過去候補を選ばない。公開画像重み由来の条件付き比較であり独立CVとは呼ばない。
- hidden test: 動画開始・履歴欠落・実時間差・検出数変化への対応が必要。過去候補を増やしても現在の正解候補がなければ接続を回収できない。
- runtime / memory: 接続候補数と過去候補数の積が大きい。chunkingはピークメモリを下げても演算量は減らさない。1時点版の費用から単純に一定倍と保証しない。
- 再現性: 入力元窓、candidate ID、時間差、各時点mask、集約規則、過去なしの定義、seed、初期化、学習設定、生成物SHAを記録する。
