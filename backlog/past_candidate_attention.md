## 入力・予測対象・出力・推論方法

- input: exp016と同じ中央2時点の固定画像特徴・候補座標に、直前1時点の全検出候補の物理座標と有効maskを追加する。追加部分は座標特徴のみで、過去画像特徴・検出得点・予測接続確率を同時追加しない。
- target / objective: 主催者GEFFに基づく、中央の隣接2時点間の通常接続・母娘接続。過去候補の対応を確定する別の教師は不要。
- output: exp016と同じ全中央ペアの接続logitに、集約した過去情報からのdelta logitを加える。検出中心や候補を変更しない。
- loss: exp016と同じsource軸softmax後のfocal-weighted binary cross entropy、既存の教師mask・division weight。追加部分とprimary trackerを同時学習し、attention重みへの対応教師・補助損失を加えない。
- decode / 推論方法: 初段は固定閾値0.5の単体診断まで。全graphは進行条件の成立とユーザーの実行承認後に追加し、exp016のsecondary tracker・候補生成・整数線形計画による復号・graph修復を維持する。
- 処理単位: 同一動画の連続3時点を入力文脈とし、教師・出力・単体評価は中央の隣接2時点。集約は中央ペアごとに行う。
- 実装区分: `staged-faithful`（このリポジトリ内の管理用語）。初段でも合意した特徴・全候補・MLP・attentionを省略せず、全graphと公式評価だけを進行条件の後へ分ける。単体診断では公式score改善を主張できない。

### 合意したネットワーク

時点 $t-2$ の各候補を $P$ 、時点 $t-1$ の検出を $A$ 、時点 $t$ の検出を $B$ とする。過去の移動候補は $u=A-P$ 、今回の移動は $v=B-A$ 、移動の変化は $d=v-u$ とする。過去移動候補 $u$ は確定した速度ではない。

| 入力特徴 | 次元 |
| --- | ---: |
| 過去の移動候補 $u$ | 3 |
| 今回の移動 $v$ | 3 |
| 移動の変化 $d$ | 3 |
| 上の3ベクトルそれぞれの長さ | 3 |
| $u$ と $v$ の方向の一致度（cosine） | 1 |
| 合計 | 13 |

1. 物理座標はµm単位を使う。実装細部として、変位と長さはexp035と同じ5 µmで割り、cosineは無次元とする。全候補の差を保持するため特徴のclipはしない。ゼロ移動のcosineは0とし、分母の数値保護は`1e-8`とする。これらの値は実験化時の`config.yaml`へ明記し、外側評価を見た変更・探索はしない。
2. 全組み合わせに共有するMLP（全結合層を重ねたニューラルネット）を`Linear(13, 32) → GELU → Linear(32, 32) → GELU`とする。両全結合層はbiasあり、追加のdropout・正規化層は設けない。出力を32次元の候補特徴 $z_P$ とする。添字では固定した中央ペア $A,B$ を省略している。
3. 候補特徴にbiasありの`Linear(32, 1)`を適用してattention用スコア $s_P$ を得る。過去情報を使わない選択肢を1個加え、そのスコア $s_0$ は全ペアで共有する学習可能なスカラー、初期値0とする。同選択肢の特徴は常にゼロで、学習可能なベクトルにはしない。
4. 全有効候補と「使わない」選択肢にsoftmaxを適用し、候補特徴を重み付きで集約する。

```math
\alpha_P = \frac{\exp(s_P)}{\exp(s_0)+\sum_{Q\in\mathcal{P}}\exp(s_Q)},\qquad
h_{AB} = \sum_{P\in\mathcal{P}}\alpha_P z_P
```

5. 集約した32次元特徴にbiasなしの`Linear(32, 1)`を適用し、既存の接続logitへ加算する。この最終層だけをゼロ初期化する。追加パラメータは1,570個で、base trackerは含まない。学習開始時の元モデルとの出力一致を保つが、学習後の非悪化や保存済みexp016との一致を保証するものではない。
6. 過去候補がない場合は「使わない」の重みを1、集約値と追加出力を厳密に0にする。動画開始も同じ扱い。学習後もbiasによる非ゼロの追加出力が生じないことを検証する。

同じ $A$ でも $B$ が違えば候補特徴・重みが変わる。重みは過去対応の正解確率ではなく、現在の接続を判断する内部重みとする。「過去情報を使わない」は最終出力の「接続なし」とは別である。

### 全候補・時点対応の契約

- 各中央ペアに、同じ動画の直前時点の全有効候補を保持する。距離上位候補への制限、半径制限、Pの一つへの確定、変位の先行平均を行わない。
- 同じframeの候補が複数窓に現れる場合は、sample・frame・candidate ID・物理座標の整合を検査する。異なる動画・非隣接frameを混ぜず、対応不整合は停止する。paddingは実候補に含めない。
- 全graphで逆方向の既存採点を使う段階では、走査方向に対してsourceの一つ前の時点を過去候補とする。正逆で同じ式・重みを使い、逆方向で正方向の変位をそのまま流用しない。動画端は追加出力0とする。
- 分割計算でもsoftmaxの分母は分割をまたいだ全候補と「使わない」を含む。分割ごとの独立softmax・分割平均に置き換えない。分割はピークメモリ対策であり、3時点の候補数の積に比例する演算量を減らすものではない。

## 成功条件と停止条件

- primary指標: 初段は両胚別の既知接続recall。全graph段階はexp016と同じ公式combined scoreとその成分。単体指標は公式scoreの代わりではない。
- 成功条件: exp035で合意した基準を引き継ぎ、両胚で保存済みexp016より既知接続recallが厳密に改善し、active pair内の教師負例予測の増加が各胚5%以内、分裂親回収数が各胚で非減少となる。最終的な精度改善は全graphで両胚の公式scoreが改善した場合に限る。
- 必須guard: 正解親1位率、教師負例予測数、分裂親回収数と有効分母、開始窓・過去候補なしの件数も記録する。疎い注釈由来の教師負例予測を真の誤接続全数とは呼ばない。分割・教師・入力の一致、非有限値なし、時間・メモリ制約を確認する。
- 成功時の次段階: 単体結果と費用を提示し、ユーザーに全graph・公式評価への進行を確認する。採否・完了・submissionは別の明示判断とする。
- 失敗時の停止範囲: 片方でも進行条件に届かなければ全graphを始めず、公式score未計測として提示する。不整合・非有限値・メモリ不足・予算超過では実行を止める。fold・epoch・候補数を無断縮小しない。

## 実行しないこと

- 禁止する代替実装、proxy、同一OOF上の救済探索: 正解軌跡や前段接続予測の入力、Pの一つへの確定、全候補の無断近傍制限、外側評価を見た閾値・層幅・正規化・epoch探索、教師・loss・検出器・復号の同時変更、追加比較モデルの必須化。単体診断だけで公式精度向上を断定しない。
- 壁打ちで採らなかった案と理由: 変位の単純平均は逆方向の候補を打ち消すため採らない。等速移動に最も近いPを選ぶ方式は、偶然整合する別細胞へ確定しかねないため採らない。実候補だけのsoftmaxは、適切なPがなくても実候補へ全重みを配るため採らない。別Transformer、過去画像特徴、補助の過去対応学習は合意した座標追加とは別比較なので含めない。

## リスク

- leakage / validation: 正解接続は教師以外に使わない。接続履歴がないため履歴生成器の分割外予測は不要だが、公開画像モデル・初期trackerの来歴による条件付き評価の制約は残る。外側胚で設定を選ばない。
- hidden test: trainと同じ候補座標から特徴を作り、正解を要求しない。動画開始・空frame・padding・逆方向の端点を扱う。固定画像特徴の窓依存性はexp016と同じで、厳密なオンライン因果予測とは主張しない。
- runtime / memory: 全候補の計算は3時点の候補数の積に比例する。全候補softmaxを保つ分割処理と学習時の中間値保持が必要で、約1,600パラメータでも低コストとは限らない。
- 再現性: 初期値・seed・候補順序・mask・時点対応・正規化・分割計算・モデル/予測SHAを記録する。GPUのbitwise一致は保証しない。
- 表現上の限界: 座標だけで真の前身を識別できない場合がある。候補数で「使わない」の重みが変わり得る。32次元への集約による情報損失や、本体との同時学習による悪化もあり得る。
