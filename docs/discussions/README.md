# ディスカッション

Kaggleディスカッションの本文とコメントを、出典URL・取得日時とともに保存します。API取得では1ディスカッションにつきMarkdownと未整形responseのJSONを1本ずつ保存します。取得・再取得・HTML変換の手順は[kaggle-discussion-archive](../../.agents/skills/kaggle-discussion-archive/SKILL.md)を参照してください。

原文と調査上の解釈を区別し、複数資料をまとめた調査結論は[docs/surveys](../surveys/README.md)、実験候補は[バックログ](../../backlog/KAGGLE_DIRECTION.md)で管理します。
