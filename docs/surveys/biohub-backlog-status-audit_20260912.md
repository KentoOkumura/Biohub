# Biohub バックログ64候補の状態分類監査

作成日: 2026-09-12

## 結論

全64候補を、公開検出器を固定してトラッカーを学習する現在方針と、各候補の入力・教師・損失・比較案・未決事項から確認した。9件を「設計可能・実験化未承認」へ訂正し、既に訂正したpublic_detector_selectionと合わせて10件となった。残る54件は具体的な方針・教師・出力・比較方式の未定があり、理由を各詳細に記した。内訳はP1〜P3の25件とP4の29件である。

今回の状態は実験の完了・採用や実行承認を表さない。P1〜P4の優先度、公開検出器固定・Kaggleのみ週30時間の方針、実験のstatus・系譜は変更していない。設計可能でも先行入力が揃うまでは依存する実行を開始できない。

## 調査目的と判定方法

依頼は「他のバックログも同様に分類が合っているか見てください」。public_detector_selectionで起きた、調査で得る答えを調査開始前の条件とする誤分類が他にもないかを確認した。

- 調査・実験で求める精度、回収率、件数、速度、容量、校正の品質、SHAは結果または実行時の確認事項として扱った。
- 先行候補から受け取る重み・予測・特徴は入力の依存として分離した。入力の実体が未取得であることと、入力の意味や比較方式が未定であることを区別した。
- 教師を何から作るか、何を出力するか、どの損失・復号・比較方式を用いるかが複数のまま残る候補は、実験の意味を変える設計判断として残した。
- 既に記載された最初の比較案が単位・分布・損失・学習有無を決めている場合は、古い「未決」の記述と整合させた。新しいモデル構造や教師を発明して設計可能にすることはしていない。
- P4であることだけでは設計不可と判断していない。29件はそれぞれ現在の固定方針との不一致、教師・情報源・出力・方式の未定を確認した。測定前の予想スコアでは分類していない。

状態の定義は[AGENTS.md](../../AGENTS.md#仮説とアイデアバックログの引き継ぎ)、現在の状態は[バックログ索引](../../backlog/KAGGLE_DIRECTION.md#未着手バックログ)を正とする。以下はこの監査時点の記録である。
