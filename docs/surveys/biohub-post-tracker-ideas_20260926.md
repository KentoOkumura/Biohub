# Biohub tracker後の接続・分裂・修復処理の改善案

確認日: 2026-09-26。依頼は「trackerや公開ノートブックの結果からtrackerより後の処理の改善に注力したい。その前提で改善アイデアを考えてください」。

本書の提案と「進行中」「未測定」は確認日時点の記録である。その後の実験化は[exp052の契約](../../experiments/exp052_x138_relink_candidate_scores/requirements.md)と[exp053の契約](../../experiments/exp053_x138_postlink_division_score/requirements.md)、exp050・051を含む実行結果・ユーザー判断は各実験の`result.md`を参照する。現在の未着手候補と比較基準は[方針とバックログ](../../backlog/KAGGLE_DIRECTION.md)を正とする。

- 対応する上位仮説: `HYP-20260910-03`（分裂）、`HYP-20260910-06`（予測誤りからの学習）、`HYP-20260910-09`（複数候補の選択）、`HYP-20260910-10`（時間情報・欠落）、`HYP-20260910-11`（最終graph選択）、`HYP-20260910-12`（公開構成と計算）。今回の整理は各仮説の下流側での検証案を示すものであり、支持・棄却・終了の判断ではない。

## 提案の結論

最初の追加比較には、**ILPで選ばれなかった候補のtracker得点も、後段の再接続へ渡す案**を推奨する。整数線形計画法（ILP）の目的関数と、ILP後の接続選び直しを分けて調べられるからである。次の大きな変更は、**分裂前後の接続を一緒に選ぶ案**と、**欠落区間を点単位でなく経路全体として選ぶ案**とする。

検出器・画像特徴抽出器・座標head・公開trackerの重みを固定する。新しく学習する場合も、固定予測から最終graphを選ぶ下流部分だけとする。候補回収案ではnode集合が変わるため、固定nodeの接続選択案とは対照を分ける。

これは発想と証拠の整理であり、未検証の改善案を採用済みとしない。バックログ、実験契約、実験statusは変更していない。既存の[学習方針](../../backlog/KAGGLE_DIRECTION.md#今後の学習方針)に対し、今回の依頼ではtracker内部の学習より後段の処理を優先する。

## コードで確認した改善対象

保存済み[x138抽出コード](../../studies/biohub_public_notebooks_20260923/anvithpothula__biohub-x138.code.py)の処理は、概ね次の順序になっている。

1. 固定trackerの候補得点からILPでnode・edgeを選ぶ。
2. ILP後に残ったedgeから得点辞書を作る。
3. 近傍運動を使うハンガリアン法で接続を選び直し、edge集合を置換する。
4. 未使用検出点を再追加し、必要に応じて再接続する。
5. 欠落補完、分裂追加、短軌跡処理、座標平滑化を行う。

`motion_relink_edges`は2221行付近、得点辞書構築は3633行付近。辞書にない組の参照値は0。ここでの0は「trackerが確実に誤接続と予測した」ことを意味しない。未計算、保存範囲外、ILP不採択、後処理で新しく作った点への接続を区別する必要がある。

exp050実装（作業中のローカル資料: `experiments/exp050_shared_edge_graph_learning/exp050_shared_edge_graph_learning_inference.py`）でも、4238行付近に選択辺から得点辞書を作る同じ構造を確認した。これは選択前の全候補得点を再接続で直接参照する契約ではない。以後コードが変更された場合は、その版に対して読み直す。

また、この再接続は一対一の対応を選ぶ。**得点の受け渡しを改善するだけでは2娘分裂の問題は解消しない。** 通常接続と分裂を区別して成果を測る。

## 優先する5案

### 1. 保存済みの候補得点を再接続まで渡す

- **入力:** 現行と同じnode、幾何的な接続候補、運動参照、およびILP選択前の保存済みtracker得点。
- **変更:** 再接続で使う得点辞書だけを広げる。初回はtracker、ILP、距離条件、費用係数、残りの後処理を固定し、新規学習なし。
- **最小比較:** 「ILP選択辺の得点のみ」と「同じ入力から保存された全候補の得点」を使う2条件。元得点が復元された候補数、割当変更、最後まで残った既知edgeを追う。
- **停止条件:** 必要得点が保存されていない、割当が変わらない、または両胚の最終公式scoreが改善しない。
- **未決事項:** 保存範囲外・新規回収点の得点は未取得のまま区別する。初回比較は共通に採点済みの候補へ限定できる範囲を確認し、得点を新規推定する案は混ぜない。

Assumption: 再接続が失っている情報に、元の最終graphの誤りを修正する情報が残る。exp049の228件では誤親の方が高得点なので、全候補の得点を渡すだけで必ず改善するわけではない。これは情報欠落の影響を測る比較である。

exp051（作業中のローカル資料: `experiments/exp051_x138_ilp_score_clipping/requirements.md`）の得点上限処理はILP内部の変更なので、処理段階が異なる。上限や費用調整を本案に同時追加すると比較が曖昧になる。

### 2. 分裂を前後の接続を含む小さなgraphとして選ぶ

- **入力:** 母の過去、2娘候補、さらにその後の候補点と固定得点・特徴。
- **出力:** 通常継続、分裂、および分裂時刻の異なる合法な局所graph候補。
- **学習と選択:** 部分注釈に整合する候補を周辺化する損失と、確定した競合への順位損失を候補とする。前後の接続も分裂と一緒に選ぶ。
- **最小比較:** 同じ候補集合で、隣接2時点だけの情報と前後の観測を使った選択を比較する。正解2娘が同じ合法graphに含まれる率と、正解なしでそのgraphを上位にできる率を分ける。
- **停止条件:** 正解構造を生成できない、前後情報が順位を変えない、通常edgeを壊す、片胚で分裂を落とす。

exp050（作業中のローカル資料: `experiments/exp050_shared_edge_graph_learning/requirements.md`）は隣接2時点の共有edge得点・2娘費用・集合ILPを扱う。本案は、その後続として**前後の接続も同時選択すること**が差分である。現在の誤graphから娘の軌跡を一本に固定して入力すると誤りを自己強化するため、複数の後続候補を残す。

動画端や視野外への移動では後続が短くなる。未来情報がないことを非分裂の証拠にしない。娘の距離が必ず増える、母の左右対称に分かれるといった制約は置かない。

公式分裂指標は、母の前後と娘・孫の局所的な枝構造を評価し、分裂時刻の1時点のずれを許容する。この仕様は本案を検討する理由になるが、精度改善の証拠ではない。[主催者metric仕様](https://github.com/royerlab/kaggle-cell-tracking-competition/blob/main/metrics.md)

### 3. 欠落区間を、両端までつながる経路全体で選ぶ

- **入力:** 途切れた軌跡の両端、未使用検出点、低得点の極大値、画像支持。
- **出力:** 間の各frameを通る経路候補と、追加しない候補。
- **学習と選択:** 確認できる継続経路を比較する部分教師を使い、経路全体の採択・不採択を決める。複数のgapが同じ点を使う競合も解く。
- **最小比較:** 同じ低得点候補集合で、現行の点追加と経路選択を比較する。正解の途中点が全frameに存在するか、隣接edgeだけで正解経路が構成できるかを先に測る。
- **停止条件:** 候補不足、判別できる教師不足、または追加node・公式FPによる損失が利益を上回る。

継続経路の費用と「一方の軌跡を終え、もう一方を開始する」費用を同じ基準で比較する。長い経路ほど得点が加算され有利になる目的は使わない。無観測の点を勝手に補い、時刻を飛び越すedgeでつなぐ案ではない。

[x138_detection_recovery](../../backlog/x138_detection_recovery.md)・[tracklet_join](../../backlog/tracklet_join.md)と関係する。既存候補の名称を変えて重複登録せず、採択された場合に経路単位の契約へ具体化する。exp047の閾値緩和と違い、既存tracker辺集合の外でも、両端と観測点から回収経路を作る。

### 4. 実際に起きる連続した誤りを再現してgraph修正を学習する

1. 学習側の固定予測で、判定可能な親取り違え・欠落・誤分裂について、持続長、密度依存、誤った高得点の分布を測る。
2. 正解が確認できる部分graphに、同じような相関した誤りを加える。未注釈領域を完全な正解graphとして扱わない。
3. 破損graphから複数の編集をまとめて選ぶ下流モデルを事前学習する。
4. 実際の予測graphへ短くfine-tuneし、反対胚で評価する。

入力は座標・固定得点・観測支持と破損したgraph、出力は接続交換・追加・削除・分裂修正の候補と編集得点。確定教師だけの損失と不要な編集への罰則を使い、最後に合法graphを選ぶ。

同じ補正器を使った「実予測のみ学習」「独立な破損」「実誤りを模した相関破損」を比較する。人工データの復元だけが改善、単なる入力コピー、実予測での誤修正増なら止める。graphから作る運動・軌跡特徴は破損後に計算し直し、正解graph由来の特徴を入力に残さない。

これは5案中、教師数と誤り分布の識別に最も不確実性がある。[final_graph_edit](../../backlog/final_graph_edit.md)や[real_error_finetune](../../backlog/real_error_finetune.md)に関係する。出力と復号がexp050と同じなら別手法とせず、学習データ生成の比較として扱う。

### 5. 競合する修復をまとめて選び、前後情報を使う計算余裕を作る

- **入力:** 元graphと、親交換・gap補完・分裂・現状維持の候補。
- **変更:** 逐次処理で確定する代わりに、共有nodeや境界接続で競合する候補をまとめて選ぶ。
- **計算方法:** 全候補と共有制約から競合成分を作る。境界をまたぐ候補は同じ成分へまとめるか、境界変数として保持する。既存graphだけから成分を作らない。
- **最小比較:** 小例で分解前後の実行可能解の対応・最適目的値・合法性を確認。時間切れの2解から同値性を主張しない。同点で辺集合が違う場合はそれも記録する。
- **採用条件:** 高速化だけでは足りない。その計算枠で案2の前後窓、または案3の経路候補を広げ、元処理より両胚の最終公式scoreを改善する。
- **停止条件:** 固定した短軌跡に誤りが閉じ込められる、境界で合法解を失う、密な動画で巨大成分になる、または最終精度の利益がない。

[x138_local_graph_choice](../../backlog/x138_local_graph_choice.md)を、計算可能な局所探索として具体化する方向である。単純な高得点辺の固定はしない。新しい候補で競合が生じたら、その内部接続も解放できるようにする。

## 進行中の実験との関係

確認したexp050 SESSION_NOTES（作業中のローカル資料: `experiments/exp050_shared_edge_graph_learning/SESSION_NOTES.md`）は21:24 JSTまで。pilotが通過しcapture中で、学習方式の公式精度は未測定。exp051（作業中のローカル資料: `experiments/exp051_x138_ilp_score_clipping/SESSION_NOTES.md`）は固定予測cacheを使うCPU比較の準備段階で、公式score未測定。

- exp050・051は、下流を重視する今回の方針と整合する進行中の比較として維持する。
- 費用調整や隣接2時点の分裂組学習を、新しい案として二重に作らない。
- 案1は固定保存出力から始められる追加比較。exp050で得点が改善しても再接続後に利益が消える場合には、特に関連が強い。
- 案2・3は、exp050/051後にも残る誤りの種類で順番を決める。分裂候補が存在するのに失われるなら案2、必要な途中点が欠けるなら案3。
- 案5は案2・3の探索に必要な場合に組み込み、独立した高速化実験を先に増やさない。
- 案4は判別可能な実誤りと編集教師が十分にあると確認してから検討する。

## 今回優先しないもの

- 同じ目的関数のままILP solverだけを交換する。exp049の調べた事象は、合法性より得点の問題が残る。
- 候補閾値を一律に下げる。exp047のfalse positive増加を扱えない。
- 近傍運動を単に追加する。x138に既存である。追加するなら参照数・分散・適用範囲・不足時のfallbackに価値があるかを測る。
- 短軌跡の長さ閾値だけを調整する。exp049の追加既知辺で、最初に短軌跡除去により失われたのは2本。主因とみなす証拠が弱い。
- score clippingや出現・消失・分裂費用の探索を新設する。exp050/051と重なる。
- GTを見た候補生成、真の細胞数・分裂数の固定、7 µmを重複除去半径に使う方法。推論時入力や2娘構造と整合しない。

## 検証と未解決事項

- 比較対象は、入力条件を揃えたexp043構成を基本とする。実提出の最高値はexp042の0.953として別に残す。採用されていない作者headへ自動で切り替えない。
- 公開モデルがtrain画像を学習済みなので、胚分離しても条件付き評価。20動画の詳細な診断を見て作った案を、その20動画で再評価して独立した検証と呼ばない。
