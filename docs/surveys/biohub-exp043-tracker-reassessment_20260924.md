# exp043を受けた過去のtracker改善実験の再評価

作成日: 2026-09-24

## 結論

**exp043によって再検討する理由が生まれた情報はある。ただし、過去の不採用実験を同じ方法のまま再実行すれば改善すると判断できるものはない。** 有望さは「exp043で使い道が具体的になった」という段階で、精度向上が確認されたという意味ではない。

1. **不採用6件の中では、exp036の検出得点を、欠落区間や途中で落ちた検出点の回収候補を選ぶために使う案を最初に検討する。** 旧実験はほぼ高得点の検出点同士の接続学習だった。exp043には、通常のtrackerとは別に候補を回収する処理が実在する。旧残差headの移植ではなく、候補を追加したときの接続を学ぶ新しい比較になる。
2. **改善しなかった関連実験まで含めるなら、exp035の自己速度を、近傍細胞の移動量に対する残差・信頼度へ組み直す案が次点。** exp035は採否未判断であり、正式な不採用とは分ける。exp025の等速Kalmanをそのまま戻す推奨ではない。exp043は既に近傍移動を使うため、同じ情報を使う現行ルールを上回る必要がある。
3. **exp039のDoG、フレーム内Self-Attentionは後順位。** 小さな部分的利点はあるが、修正座標によってそれが広がる実証はない。exp019の子列mask、exp024の学習回数延長、exp029の同じ集合得点学習を、座標が改善したという理由だけで再実行する根拠は弱い。
4. **最初の改善実験の中で、exp043入力の公開tracker対照と、必要なら同じ入力で学習した標準tracker対照を記録する。** exp016の旧入力の数値を新入力の合否基準にはしない。対照作成だけを細かな独立実験に分割する提案ではない。

標準tracker内部の変更に範囲を限定すると、今回の証拠から「これをまず再実行すべき」と強く推せる不採用手法はない。

### 1.2 入力と最終出力の間にある処理

実行した[exp043推論source](../../experiments/exp043_x138_self_trained_head/exp043_x138_self_trained_head_inference.py)を確認した。公開x138の説明だけから推定していない。

1. 通常の検出候補を作る一方、得点0.3以上の極大点を別の候補群へ保存する。
2. **通常候補**へ座標headを適用し、小数座標から画像特徴を三線形補間で取得する。公開trackerは変更された座標・特徴を受け取る。
3. 双方向・secondaryの接続得点を融合し、整数線形計画法（ILP）でgraphを選ぶ。
4. ILP出力を読み、近傍細胞の移動量を使って通常接続を組み直す。学習確率は補助費用に使う。
5. 切れた軌跡端の近くにある得点0.965以上の検出点を再追加し、再び接続を組む。別途、得点0.5以上の候補から最大3フレームの欠落を補う。
6. 分裂の追加・制約、短軌跡の除去、座標平滑化等を通して提出する。

再評価に直結する点は以下のとおり。

- **低い得点の候補群はそのまま学習trackerへ入らない。** 通常候補の座標補正より前に保存され、後の回収処理で使われる。「x138にすればexp036が低得点候補の接続を学べる」は成立しない。回収候補にtrackerを使うには入力・教師・呼び出し箇所の追加が必要。
- 再接続の`learned_edge_probs`は、ILP出力のうち距離等の条件を通った接続に限られる。全候補の確率ではなく、未登録の接続は0扱い。trackerは点の選択や残った確率を通して影響できるが、学習で増やした正解接続が最終出力に残る量は未測定。
- 全候補確率の保存用`BIOHUB_CACHE_EDGE_THRESHOLD`は実行sourceで1.0、保存条件は`probs > threshold`。この設定の候補確率配列から全候補得点を復元できない。最初のtracker比較では必要な確率を明示的に保存する。
- `motion_relink_edges`は近傍12点・40 µm内の移動量の中央値を使い、自己参照に近すぎる点を除く。近傍情報がない場合は自己移動等へ戻る。**単に速度を加えるだけでは既にある情報と重なる。**

コード位置と文字列パッチは[抽出結果](../../studies/exp043_tracker_reassessment_20260924/exp043_code_locations.json)を参照。

### 2.1 exp036を再検討する具体的根拠

旧exp036の2fold×2条件は同じ追加head・初期値で、得点入力と0入力を比較している。構造追加そのものとの交絡は抑えられている。[metrics](../../experiments/exp036_detection_score_pair_features/metrics.json)の得点別集計から、接続両端のうち低い検出得点について次の母数を確認した。

| 評価胚 | 既知接続総数 | 得点0.995以上 | 得点0.97未満 | 得点0.95未満 |
| --- | ---: | ---: | ---: | ---: |
| 6bba | 103,393 | 102,548（99.18%） | 61 | 16 |
| 44b6 | 18,949 | 18,527（97.77%） | 21 | 5 |

**高得点点同士の接続で利得がなかったことは、欠落区間の低得点候補を選ぶ有効性を十分には検証していない。** ただし、この少ない母数から候補選択の成功を示すこともできない。

得点は窓内のdetector出力を点位置で取得した値で、候補を初めて生成した窓の値と常に一致するとは限らない。exp043の回収用得点を旧cacheの得点と無条件に同一視しない。得点を取った時間窓・座標・融合方法を対応付ける。

旧モデルの負例予測も6bba 4,355→4,346、44b6 1,341→1,333と減るが、既知接続も減った。全体として確信を抑えただけの可能性は排除できない。[得点別CSV](../../studies/exp043_tracker_reassessment_20260924/exp036_score_bins.csv)、[再集計指標](../../studies/exp043_tracker_reassessment_20260924/pair_metrics.json)

### 2.2 Kalmanとmaskをそのまま再試行しない理由

- Kalmanは内部検証でも正の最小係数0.25が選ばれ、0.5・1.0は悪化。内部19動画の分裂予約0件に対し外側3,469件と、校正条件にも違いがある。座標改善だけを理由にすると、誤履歴、分裂後の状態、校正条件を残す。
- Kalmanの画像のみ対照と未変更exp016との差にはrepair・平滑化・短軌跡除去を外した影響が含まれ、差全体をKalmanの悪影響とはしない。それでも同条件の画像のみ対照に対して明確に悪化している。
- exp019はnode recall 0.982227→0.985826、通常edge Jaccard 0.899732→0.900131という利点を持つが、公式のadjusted edge Jaccardとdivision Jaccardは低下。exp043後処理がこの交換条件を有利にする実証はない。
- exp019でmaskに残る28,669,782 pairのうち27,432,958 pairに未知親が含まれる。座標headは注釈の欠落を埋めるモデルではない。

### 評価定義を混同しない

exp016由来でも100,230と100,497、分裂48と50のように異なる対照値がある。評価対象・確率処理が異なる読み出しを横断して差分を取らず、各実験の対応する対照と比較した。

`legacy mask`内の負例には未注釈候補が大量に含まれる。exp033の未知endpointを含むpairは6bba 97.20%、44b6 99.28%。全てを真の誤接続と呼ばない。既知負例の定義も異なるため、exp039の21/14件とexp040対照の14/4件を同じ指標として扱わない。

## 4. 再利用するなら何を変えるか

以下は候補の比較案で、実装承認済みの新実験ではない。旧実験から変える理由と、効果がないと判断する測定を示す。

### 4.1 第一候補: 検出得点で回収候補の接続を評価

- **情報:** exp036の検出得点、exp043の回収候補、固定画像特徴、軌跡端との位置関係。
- **変更:** 高得点点同士の接続logitへ加えるだけでなく、切れた区間で「候補を経由する接続」と「追加しない選択」を比較する。点の取り合いと分裂制約を保つ。
- **教師・出力:** 公式注釈で確認できる継続・分裂を教師に、候補経路または接続の得点を出す。未注釈点を非細胞・誤接続と断定しない。
- **損失の候補と未決事項:** 正解対応が確認できる競合候補の部分的な比較損失が候補。「追加しない」が正しい負例をどれだけ作れるかは未確認で、通常の二値分類へ自動決定しない。識別できる教師がほとんどなければ、そのまま実装できない。
- **対照:** 同じ回収候補集合に対するexp043の距離・得点閾値ルール。回収点の座標補正やDoGまで同時に変えない。
- **支持する事実:** 実際に2,320点の再追加と114点の低得点補完が動いている。旧exp036では低得点の既知正例がほぼなかった。
- **反証する測定:** train側で現行ルールが取り逃す既知接続がほぼない、識別可能な教師がない、再選択で誤接続・分裂欠落が増えるなら進めない。公開testの追加件数だけで判断しない。

**Assumption:** 現行回収には、得点・画像・接続の整合性で改善できる選択誤りが残る。未測定の仮定である。

予測対象・出力・接続選択の単位を変えるため、普通のtracker特徴追加より実装範囲が大きい。exp036の不採用判断と矛盾しないが、同じ実験の復活と呼ぶのは不正確である。

### 4.2 第二候補: 近傍移動からのずれと信頼度を学習

- **情報:** exp035の履歴生成・履歴品質と、exp043の近傍移動。exp025の失敗から、分裂後や誤履歴を同じ等速モデルで強制しない。
- **入力:** 補正後座標・固定画像特徴、自分の直前移動、近傍移動の中央値による予測位置と候補位置の差、参照点数・移動量のばらつき・自己履歴との不一致。
- **教師・出力:** 公式の正しい隣接接続を得点化。近傍流れを正解教師にはしない。通常接続と分裂を分けて、同じ教師・損失の標準trackerと比べる。
- **未決事項:** primary tracker内で使うか、再接続費用へ学習得点を直接使うか。後者はILP後の確率制限も変えるため、接続選択を変更する対照が別途必要。両方を同時に変えない。
- **対照:** 同じ近傍情報を使う現行x138ルール。画像だけの旧exp016に勝つだけでは不十分。
- **反証する測定:** 近傍参照が自己履歴より既知接続の位置残差を改善しない、競合相手との順位差が広がらない、誤履歴時に悪化、分裂を落とすなら学習を拡大しない。

**Assumption:** 組織の移動を参照して自己履歴の誤りを補い、残る局所的なずれを学習できる。exp043は既にこれをルールで使うため、学習の追加価値は未確認。中心誤差の平均改善は、この仮定の証明ではない。

### 4.3 DoGとSelf-Attentionを後にする理由

DoGは画像中の局所的な山の形を捉える。補正座標や回収候補で取り直す意味はあるが、exp039の利得は12万本超の既知接続に対し計6本で、誤り増加も伴った。複数seedや動画単位の安定した利得を確認した結果ではない。旧実測で特徴生成はCPU 6.23時間、4モデル学習・評価Notebookは約2.45時間。無料の追加特徴とは見積もらない。

Self-Attention Bには密な候補のrecallや6bbaの分裂に利点があるが、負例予測増と44b6の分裂減がある。x138で補正した後にも同じ混同が残る場合に、初期化・距離・近傍条件を明示した比較を検討する。

## 5. 新入力で公平に比較する方法

### 最初の改善実験に対照を含める

1. **exp043そのものの対照を記録。** 採用head、公開detector・画像encoder・trackerのSHA、窓、特徴取得、融合、閾値、後処理を固定。train側で必要な候補・特徴・確率を保存し、公開trackerの指標を取る。
2. **学習方法の比較なら、同じ入力で標準trackerを学習した対照を用意。** 旧exp016 cacheは補正位置・補間特徴を持たず代用できない。追加モデル数・費用と再学習が必要な理由を設計時に示す。一度記録できれば後続で再利用する。
3. **候補の方法も同じ入力で学習。** 旧重みの差し替えで結論を出さない。入力、教師対応、内部検証、初期化、確率の読み出し、融合・後処理を揃え、変更点を明記。
4. **比較母集団を保存。** 補正で注釈対応が変わるため、共通対応できた接続と新たに回収／失った接続を分ける。通常候補、再追加候補、欠落補完候補も区別する。

既存captureは20動画の座標head用で、採用headを適用した全trainのtracker比較用cacheではない。必要な画像特徴・教師対応を作り直す。exp015の全train cache生成には約6.67時間の画像予測を要したが、x138版の時間は未実測であり同じとは保証しない。現行方針のKaggle・週45 GPU時間・課金なし、1回12時間の条件にこの初回費用も含める。

### 残す評価指標

- 胚別の既知接続再現率と分母、正解親1位率、同じ定義のprecision、判定できる誤接続、legacy mask負例予測、分裂母の両娘回収と分母。
- 候補の注釈対応率・距離、補正前後の相手候補順位、密度、検出得点、通常継続／分裂、履歴品質別の内訳。
- 特徴・教師・graphの点を結ぶID・SHA。選択checkpointだけでなく各epochの学習曲線と内部検証。
- 動画別の対照との差。同じ動画内の大量のpairを独立反復とは扱わない。必要なら動画単位の再標本化でばらつきを示すが、胚2個から広い汎化を主張しない。
- 最終headの学習20動画とそれ以外の内訳。公開画像モデル・trackerの来歴も含むため、独立した交差検証とは呼ばない。

### graphへ進む判断

普通の特徴追加は、両胚の接続・誤接続・分裂の事前条件を隣接2-frameで確認してから全graphに進む。結果を見て条件を緩めない。

**回収候補の追加・接続選択が変更対象なら、固定候補2-frame指標だけでは効果を測れない。** 同じ候補経路での既知接続回収・誤接続・分裂保持と、現行ルールが失う正解件数を先に診断し、進行条件を実装前に定義する。

公式scoreはKaggle上の同じ199動画の全graphと公式評価器で、combined score、adjusted edge Jaccard、division Jaccard、胚別の値を記録する。「tracker確率→候補graph→ILP→再接続→回収・分裂→最終graph」の段階別に増やした正解がどこに残るかを確認する。隣接ペアで改善しても後で消えるなら、その段階を特定してから次の学習を考えられる。

Public LB 0.950は採用済み提出の基準だが、train接続指標との整合は未確認。新規submissionは必要な検証後、ユーザーの明示承認を得て行う。
